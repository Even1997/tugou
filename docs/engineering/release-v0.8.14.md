## Mac 与公开更新

Apple Silicon 已通过 [原生构建工作流](https://github.com/Even1997/tugou/actions/runs/42269216717) 的全部 752 项包内检查，渲染错误 0，DMG / ZIP、架构、临时签名及完整下载挂载检查通过；已查看 PPT 编辑和素材菜单窄窗口截图。证据 `app/test-results/release-v0.8.14-mac-arm64-final/` 及对应 summary。

Intel [单架构复验工作流](https://github.com/Even1997/tugou/actions/runs/42272178071) 已成功，752 项包内检查通过、渲染错误 0。复用已通过验收的 Apple Silicon 包体，只在独立 QA 分支重跑 Intel；该分支只调整构建矩阵与本架构校验清单，主分支仍保留双架构发版流程。证据 `app/test-results/release-v0.8.14-mac-x64-final/` 及对应 summary。两个 Mac 架构的原生程序启动、DMG / ZIP 完整性、临时签名、完整 DMG 下载与原生挂载均通过。

首轮 Mac 两架构 PPT MCP 29 项均通过，Intel 阴影边框 41 项、PSD 19 项通过。Apple Silicon 在撤销 / 重做后截图采到旧帧；补保存后的重做颜色断言和有上限的像素刷新等待。Intel 修图测试因云端运行器缺少 GPU 停在透视渲染；测试启动参数复用既有 SwiftShader 方式。`80f6b12` 仅修改验收脚本，应用源码未变；Windows 原安装包阴影复验 42 项通过。生产用户 GPU 与真实 Office / WPS 仍需另行验收。

第二轮两个 Mac 架构新增功能各 161 项通过：PPT MCP 29、阴影边框 42、PSD 19、修图 71。后续旧回归发现两处测试假设失效：设置分类仍断言 7 项，改为精确核对 10 个分类；局部生图测试在小屏幕点击屏幕外已虚拟化的节点，改为先概览两张图并断言第一张仍选中。`3fdd4ed` / `041b5fb` 仅修改测试，Windows 原安装包局部生图复验通过，不改变应用行为。

后续补充验收修正：Esc 检查向聚焦滑块发送按键，等待独立面板关闭、重开及参数 / 像素恢复；素材菜单等待原生窗口缩放稳定再打开。Mac CI 在独立图像测试间释放文件缓存，避免前一组测试留下的缓存使后续模拟生成触发低可用内存保护。生产内存校验保持不变；低内存失败未发出模拟模型请求。对应测试与 CI 准备调整为 `0e8f830` / `2c02616`，未改应用源码。

Intel 完整 MCP 的取消检查还发现固定 3 秒模拟延迟与第二个 MCP 进程启动存在竞争。`514a92d` 改为显式控制模拟响应，取消检查结束后再释放；Windows 原包 96 项通过。未修改生产任务取消逻辑。
