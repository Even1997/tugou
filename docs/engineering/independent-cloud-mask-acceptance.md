# 独立任意蒙版与画面选区验收

局部修改新增素材透明度/黑白亮度蒙版、反转、修改区预览，以及读取图层工作区当前选区。共用顶部组件、素材库和云端任务，原图及已提交任务不会随当前选区变化。

## 行为与完成定义

- 蒙版按透明度或乘以 Alpha 的亮度确定修改强度，支持灰度/半透明和反转。原始蒙版固定进入任务快照与处理历史；删除素材列表中的蒙版不破坏已完成记录和离线合成。
- 空蒙版、尺寸不符或资源缺失在请求模型前拒绝，不自动拉伸蒙版。API 蒙版与本地合成使用相同覆盖率，完全保护像素的 RGBA（含透明像素颜色）逐字节保留；半透明区域按预乘 Alpha 混合。
- 读取画面选区生成可复用素材，一次撤销/重做。支持原有多边形、减选、位图、反选及羽化的选区表示；本批桌面实际覆盖多边形、减选孔洞和羽化。读取需来源尺寸等于画布尺寸，按画布坐标应用；不代表自动转换单个图层的位移、旋转或透视。
- 历史恢复蒙版、读取通道和反转；错误尺寸原始图审阅与离线缩小沿用前批规则。没有新旧版本同步，没有自动重新发起付费请求。
- 修正图像工具页只筛选本地任务的遗漏：云端任务状态现进入顶部处理中/取消入口，防止同源处理时重复提交。

实现增量集中在 `cloud-settings`、`cloud-pixels`、原生任务输入及 `CloudControls`、`CloudMaskPreview`。预览最长边 1024，只用于辅助显示；实际任务使用原尺寸蒙版。选区读取沿用已有渲染，不重新实现选区算法。较大/100MP 选区读取的前端响应性仍待专门测试。
