# 独立图层特效验收

状态：本批 Windows 能力可交付评审，尚未更新用户运行窗口。按用户最新要求，继续完成后续功能，再统一更新桌面；不操作当前窗口。

## 范围与完成定义

独立实现描边、投影、颜色叠加、内阴影、内发光、外发光。图片、文字、形状和分组可叠加多项特效，保持原内容可编辑；顶部参数支持颜色、强度、混合、半径、距离/角度、扩展、描边位置、启停、重置、删除和撤销。特效跟随蒙版后的轮廓，分块导出与预览使用同一路径。

验收要求：六个真实入口均可操作；保存与新进程恢复一致；原素材/未知字段保留；透明度与边缘像素有断言；960px 参数可读；100MP 原尺寸导出与恢复成功。以上仅覆盖该批能力，不代表整体产品完成。
