### 1. 先修视觉可访问性：C1 / C2

**C1 [P1] 浅色搜索占位文字对比度不足。** 首页、画布、设置复现约 **1.8:1**；输入启用且可见，不能用已有 aria-label 代替视觉对比度。位置：[home.jsx:33](../../app/renderer/home.jsx#L33)、[canvas.jsx:637](../../app/renderer/canvas.jsx#L637)、[settings.jsx:30](../../app/renderer/settings.jsx#L30)，共用主题 [components.jsx:150](../../app/renderer/components.jsx#L150)。首页/画布样本为 `#bfbfbf` 对 `#ffffff`；设置为 `#b8b9ba` 对 `#f5f6f8`。建议补齐 placeholder 语义颜色，深浅主题均按普通文字至少 4.5:1 复验。命令：`$impeccable harden` / `$impeccable colorize`。

**C2 [P1] 设置版本号二次透明化后难读。** `Tugou 0.8.17` 在 `settings.css:10–11` 的 `.settings-nav footer small` 使用 opacity .8，浅色背景合成约 `#7f8795` 对 `#f5f5f7`，约 **3.3:1**。这不是禁用状态，影响版本识别。建议移除多余透明度或换用达标 token；业务影响低于 C1，仍按可访问性标准列 P1。命令：`$impeccable colorize`。

### 2. 给窄窗口保留可读的编辑对象：C3

**C3 [P2] 紧凑 PPT 窗口画面过小。** 1060×780 下，右侧两列共 440px、缩略列 120px、工具栏 48px；实际页面仅 **322×181.125px，约25%**。操作可以完成，但精细编辑需频繁缩放。证据：[浅色截图](../../app/test-results/impeccable/a-ppt-line-light-1060.png)、[深色截图](../../app/test-results/impeccable/a-ppt-line-dark-1060.png)；位置 `presentations.css:50,54,56`、`presentations.jsx:155,166`。属性标题的 × 是取消选择，不能当作收起面板。

建议保留已确认的固定竖栏和独立属性列，增加明确的面板折叠/恢复或专注画布方式，并设定紧凑窗口的主体可用面积要求。不得通过移回原右栏来取消用户已确认的布局。命令：`$impeccable adapt`。

### 3. 合并重复属性并解释作用范围：C4

**C4 [P2] 图层选择态有两套描边入口。** 上部工具选项和下部对象属性同时显示颜色与宽度；画板 W/H 也重复。源码表明选择现有形状时两处都修改该对象，并非一处仅设置下次绘制。证据：[选择态截图](../../app/test-results/impeccable/a-layers-line-dark-1440.png)；位置 `layers.jsx:2020–2023`、`shape-tools.jsx:31–32`、`layer-properties.jsx:289`。

### 4. 精简数字，提升重要说明的可读性：C5 / C7

**C5 [P2] PPT 几何值直接显示浮点长尾。** 实测 X 为 `109.83498349834983`、宽为 `971.6171617161715`，输入框视觉截断后难以比较。位置 `presentations.jsx:157–158`，证据 `a-ppt-line-light-1440.png`。建议仅格式化显示到合适精度，保留底层数值及输入编辑语义，不在渲染时改写工程；给线条粗细增加可见名称，px 作为单位。命令：`$impeccable clarify`。
