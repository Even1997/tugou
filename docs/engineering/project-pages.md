# 项目内多画布与多合成

开发版新增页面管理，尚未发布。一个工程分别拥有画布页面和合成页面；每份合成内部仍可有多个画板。素材、提示词模块、配方、任务和保存入口属于工程，共享使用。

## 使用

- 进入「画布」或「合成」，顶部文字页签切换页面；`+` 新建，`⋯` 重命名、复制、删除当前页。
- 删除前确认，至少保留一张画布与一份合成。共享素材不会随页面删除；画布有运行中的生成任务时拒绝删除。
- 左右方向键切换页签，Home/End 到首尾；页签过多时横向滚动，自动显示当前页。
- 切换页面不新增撤销步骤，不改变已有未保存状态。撤销沿用工程统一时间线，不是每页独立历史；跨页撤销自动显示受影响页面，其他页面保留对应时点的内容。
- 画布视口分别保存；合成的平移与缩放在切换时保留，保存工程时写入。仅切页不自动写磁盘，当前页选择随下一次工程保存持久化。
- 复制节点、连线与图层使用新 ID，并重接父子关系、输入顺序、角色、提示词节点和节点引用。素材与位图资源共享；复制不重新提交生成任务。

## 存储和兼容

旧工程无需立即重写，默认呈现「画布 1」「合成 1」。首次页面操作建立 `document.pages.canvas/layers` 目录。每个目录包含 `activeId` 和 `{id,name,content?}` 列表。

当前页的内容继续使用原来的编辑字段，避免重复保存；非当前页内容保存在 `content`。画布包含 `tugouCanvas`；合成包含尺寸、背景、图层、选区、布局和 `compositionView`。保存时校验全部页面，素材引用检查递归覆盖非当前页面。

生成占位和结果按全工程唯一的节点 ID 写回原画布，切页不改变归属。历史快照也接收相同结果，避免撤销后重复生成节点。若原页面已经不存在，迟到结果只收入共享素材库，不落入其他画布。旧工程生成台提示词整理与模块同步覆盖所有画布。

## MCP

`get_state.pages` 给出页面清单及当前页。`list_commands({domain:"page"})` 可发现：

| 命令 | 用途 |
|---|---|
| `page.list` | 读取 `kind:"canvas"` 或 `kind:"layers"` 的页面列表 |
| `page.activate` | 按 kind/id 切换并打开对应工作区，不增加历史步骤 |
| `page.create` | 新建并激活页面，可传 name |
| `page.rename` | 修改 kind/id 对应名称 |
| `page.duplicate` | 复制并激活页面，返回新 ID |
| `page.delete` | 删除指定页，可撤销，最后一页和运行任务受到保护 |

先切换目标页，再查询节点/图层、编辑或导出。现有 canvas/layer/artboard 命令针对各自当前页面；不能把单页对象查询结果当作整个项目。导航需要最新 revision，新建等编辑可进入本地 batch，切页不可进入 batch。

`ui.inspect` 与 `ui.capture` 返回 `activePages`。`ui.restore` 同时恢复原页，原页已删除则明确报错。截图等待合成画布完成渲染。输入框聚焦、弹窗或局部草稿存在时，MCP 切页或改变当前页的编辑会被拒绝。
