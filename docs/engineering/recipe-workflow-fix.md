# 配方输入漏传修复与批次保护排查

## 已确认与修复

`compileWorkflow` 原先仅取配方节点的 `snapshot.output`，遗漏模块绑定和参考图。复现中，配方自身编译包含 18 个模块和 1 张参考图，连接生成节点后变为 0 个模块、0 张参考图。

现在展开保存的模块快照、本地覆盖、输出要求、参考图及上游输入，适用于生成台、图片、文本和全景节点。相同模块去重，直连模块优先于配方副本，已绑定全局模块不再追加最新版；相同素材及职责去重，保留目标节点的职责覆盖。沿用现有提示词组装及长度、媒体类型、引用数量和循环检查。

本轮生产代码只修改 `app/core/workflow-nodes.cjs` 与 `app/core/prompts.cjs`，未修改用户工程、MCP 提交逻辑或已有界面改动。
