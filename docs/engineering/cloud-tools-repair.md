# 云端图像工具修复验收（2026-10-29，未发布）

## 范围与验收

继续修复 AI 局部修改、AI 扩图、AI 类别拆分及关联工具参数切换。沿用现有 Images API 和像素合成链路，不引入额外依赖或新模型，不更改用户项目、真实供应商和密钥。

- 缺模型、缺必填要求、无效尺寸、缺失或尺寸不符的蒙版在提交前显示原因。
- 生图与视觉识别按各自用途检查；没有视觉模型时，仍可手填对象并使用已配置生图模型拆分。
- 同来源切换工具保留各工具区域参数；更换来源仍按新图尺寸初始化。
- 局部修改保护区 RGBA 原样保持；扩图原图按指定偏移保留；类别拆分使用源 RGB 并与源透明度相乘。
- 同一后端通过 UI 与 MCP 执行，结果保存、重开正常。

## 修复

1. 必填的局部修改要求与类别方案移到右侧直接编辑；修改区域、原图位置和蒙版规则显示文字按钮。
2. 读取脱敏连接列表，显示用途对应模型和阻断原因，可直接配置、刷新；保存连接自动更新状态。已配置仅代表本机配置完整，不证明供应商支持编辑接口或指定尺寸。
3. 去掉工具切换时重置来源区域的调用，保留更换素材时的初始化。
4. 云端结果校验使用 EXIF 旋转后的显示尺寸；用户明确选择缩小对齐时，先旋转再缩放。修复前回归用例会误报“返回 6×4，请求 4×6”，修复后通过并逐像素验证保护区。
