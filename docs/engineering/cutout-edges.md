# 主体抠图边缘优化

## 范围与完成标准

在精细/轻量抠图共用链路增加边缘收缩与向内羽化，用于可控地减轻外圈白边。默认关闭，不自动牺牲发丝/薄纱来换取更锐利的轮廓。完成标准：零值逐像素不变；调整不改变原 RGB、不增加任意像素相对于模型原输出的 alpha；界面和 MCP 参数一致；任务重试、保存重开保留参数；真实图片及参数边界检查通过。

UI 复用 NumberField，显示原图像素单位和处理限制；输入边缘收缩 0–4 整数、羽化 0–4，可按 0.5 步进。修改后重新点击处理，非即时预览。素材仍保留原图与新结果，不覆盖输入。

## 处理方式

使用现有 [Pillow ImageFilter](https://pillow.readthedocs.io/en/stable/reference/ImageFilter.html) 的 MinFilter 收缩蒙版，然后 GaussianBlur 羽化，并取羽化前后较低的 alpha，保证向内处理。最后乘上原图 alpha。未增加依赖，不生成新 RGB，不推测背景颜色。

`image.process` 的 cutout 参数新增 `edgeShrink`、`edgeFeather`，范围和中文说明直接体现在 MCP schema。后端与 Python 双重验证。既有调用、任务快照以及 AI 主体选区缺少新字段时按 0 处理。UI 任务快照白名单、Python job 参数、重试和素材 toolResult 同步携带字段。

## 限制与自评

实际婚纱对比可见外轮廓收紧，部分白边减轻，但模型原有的柔化、较宽的背景污染仍保留。参数过大会损伤细发丝/薄纱，需人工选择；本功能不是精细抠图质量替代，也不是 RGB 去污染。精细模型沿用相同后处理函数但本轮未重新执行其大模型；Mac 原生、更多素材和大图长时测试未完成。未发布、未重启用户实例。
