# 画布显示尺寸与 AI 多角度验收

本批对齐旧版图片节点的自由比例和模型多视角生成。自由比例改变节点显示大小，不改素材像素；多角度由模型重绘，不以旋转图片代替。Agent 未补发任务或消息。当前用户窗口、正式构建和正式数据保持不动，完整目标仍在进行。

## 验收标准与结果

| 标准 | 证据 |
| --- | --- |
| 顶部统一入口与可替换组件 | 顶部“节点尺寸”提供锁定/自由比例及独立宽高；图片工具中的“AI 多角度”复用 FormDialog、Button、NumberField、主题和原模型配置 |
| 缩放只改变显示 | 数值输入、鼠标事件拖动边角、比例锁定、自由宽高通过；原素材字节、引用、角色和未知字段不变；新节点尺寸写入工程 |
| 连续拖拽可以一次撤销 | 5 次连续鼠标移动仅在结束时提交历史；撤销回到拖动前尺寸，重做一致。修复了保存刷新后 React Flow 测量尺寸丢失导致拖拽异常的问题 |
| 新视角参数真实进入请求 | 本机 HTTP fixture 收到原图 PNG 字节、共用模型、水平 30°、仰视 20°、距离 2.5、广角；镜头参数、原图和完整提示词独立落盘，密钥不进入请求日志 |
| 源图不可被任务覆盖 | 结果作为新素材及画布节点加入，源节点和原素材保留；输出 PNG 与接口返回字节完全一致；新节点避开已缩放源节点，多个结果留有间隔 |
| 有状态、可取消、不会自动重发 | 提交后立即刷新共享任务列表；从任务面板取消，迟到响应不入库；新进程恢复已完成与已取消状态，没有补发请求 |
| 可恢复与保留数据 | 保存、重启后尺寸、自由比例、源资源、未知字段和生成提示词一致；重复读取不产生重复素材 |
| 页面可用 | 960px 浅色与标准宽度深色截图检查，弹窗在可视区域内，参数与操作沿用共用控件；所有 QA 窗口禁止 show/focus |
