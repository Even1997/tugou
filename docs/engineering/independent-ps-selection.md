# 自由选区与图片 / 蒙版目标

## 参考与范围

参考 [Compositor](https://github.com/robbietilton/Compositor) 本地提交 `365b5745eda537f984f3d5bed1e53c361dbc9c91`：`NativeLayerList.swift` 的 selectMask 只切换图层编辑目标；`SelectionEdits.swift` 的 fillSelection 根据 isMaskSelected 选择图片色彩或蒙版灰度；`SubjectRemoval.swift` 将主体识别结果作为选区。参考其交互与操作语义，没有移植 macOS 实现。

## 当前行为

- 选区工具、选区内容、编辑图片 / 蒙版三个状态分开。点击缩略图不清空选区，不强制切换画笔或移动工具；边框标识当前目标。
- 无蒙版时，所选图层显示添加入口，点击创建全白蒙版并保留选区。蒙版黑色隐藏、白色恢复；切回图片后填充只改当前图片，不另建图层。
- 套索、多边形、椭圆、魔棒、颜色范围可选；新选区、添加、减去、相交明确分开。反选、取消与 AI 主体入口进入上下文工具栏。窄窗口换行。
- AI 使用已安装的本地主体抠图组件，仅把输出 alpha 映射为当前画板选区，不替换原图、不自动抠图、不调用云端。缺组件给出配置提示；取消、期间更改工程与过期结果有保护。
- 只在移动工具显示变换框，避免套索边界与图层尺寸框混淆。选区临时位图使用后释放。
