# 独立质感调整与平铺验收

本批继续完整复刻，所有构建和验收均隔离。未操作用户当前窗口，未覆盖正式 `app/dist`，未安装或热更新。

## 范围及完成定义

- 质感调整：顶部强度 0–100 与重置；局部细节和饱和度增强，原尺寸及 Alpha 保留。零强度、透明边缘、跨分块、实际人物样图均须通过像素参照。
- 图片平铺：顶部精确宽高；从原点按原尺寸重复，末行末列裁切、透明区域保留。与带缩放/镜像/间距的“重复图案”分别提供入口，验证逐像素位置而非只看尺寸。
- 两者均进入共用素材库和处理记录；参数恢复、单次撤销重做、入层、原图字节保留、未知字段及新进程重跑必须通过。

质感算法为独立实现：用 Alpha 加权的二项核亮度模糊计算细节残差，增强细节并小幅提高饱和度。透明邻域不贡献隐藏 RGB，Alpha 不改动。分块带 1px 邻域，计算临时数组跨块复用，降低分配峰值。不是旧图像库内部锐化算法的逐像素复刻，也不宣称 AI 增强。

平铺使用一次原尺寸重复图案填充，不创建成千上万个对象，因此没有沿用旧实现的 4096 块限制。输出仍受单边 30000、总量一亿像素边界约束，未降低分辨率。

独立二维标量参照与分离计算对照覆盖分数强度、单行/单列、透明边缘、不同尺寸及跨块。工作线程构造样本和人物图 Alpha 最大差值均为 0；人物图预乘 RGB 最大误差约 0.996/255，零强度构造样本解码像素完全一致。平铺逐像素相位及 Alpha 一致，包括比原图更小的输出。

已查看 `enhance-wedding-dark.png` 与 `tile-wedding-light.png`，两类参数沿用共享顶部组件，960px 无横向溢出。人物图仍保留原始文件，处理结果另存素材。

复用临时数组后，本机 100MP 质感样本约 4.62 秒，Tab 进程峰值约 1.51GiB、25ms 心跳最大间隔约 288ms；100MP 平铺约 0.87 秒、Tab 约 0.85GiB、最大间隔约 87ms。GPU/主进程峰值另见报告，不应相加当作同一时刻总量。样本为固定色、边界及透明区域，不代表复杂照片或低内存硬件。
