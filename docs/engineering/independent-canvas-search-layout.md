## 范围与验收标准

本批“节点搜索”指创建节点时搜索类型；左侧已有的画布内容搜索保留。整理仅作用于选中节点，不做整张有向图自动布局。

| 项目 | 验收标准 | 结果 |
| --- | --- | --- |
| 创建搜索 | 顶部添加、双击空白、拖线到空白共用搜索；文字、图片、生成台优先；中英文关键词和空结果可用 | 已验证 |
| 键盘与输入 | 画布焦点下 Tab 唤起；上下键选择、Enter 添加、Esc 关闭并返回焦点；输入框 Tab、中文输入法及画布删除/分组快捷键不冲突 | 已验证 |
| 拖线创建 | 根据现有连线规则筛选类型，选后自动连接；取消不残留连接；创建及连线一次撤销 | 已验证 |
| 多选整理 | 左对齐、顶部对齐、水平/垂直等间距、按行整理；保留未选节点、内容和连线；一次撤销/重做、保存恢复 | 已验证 |
| 组合 | 整组作为一个对象移动，避免重复移动子节点；组内整理保持所属组合，必要时扩大容器；混选不同容器提示原因 | 已验证 |
| 视觉 | 保留图标工具栏、两种主题；键盘高亮可辨；菜单在窗口边缘和 960px 宽度内可用 | 已验证并查看截图 |

完成定义是源码、独立包和原预览入口均更新，相关自动检查通过，真实工程不被测试改写。主要风险是快捷键冒泡、组合相对坐标、撤销粒度、菜单焦点与边缘溢出，均在本批专项验证中覆盖。

## 操作与边界

- 点击顶部“添加节点”图标，或在画布按 Tab、双击空白，输入“图片”“生图”“text”等关键词。拖线菜单只列可连接的创建类型，导入文件仍从普通添加菜单进入。
- 框选或 Shift 多选后，点击顶部“整理选中节点”图标。对齐与按行整理需要至少两个对象，等间距需要三个。
- 等间距按卡片实际宽高计算，最小间隔 40；按行整理按当前空间顺序排成近方形网格，间隔 64。不同尺寸的所选卡片不会因网格整理相互重叠。
- 组内节点可以一起整理；跨不同组合的子节点需要分开处理，或者选整个组合整理。容器扩展也包含在同一次撤销中。
- 拖动吸附线、全图自动布局、导航返回、连线重接及组合折叠不在本批范围。
