# 蒙版状态、删除与快捷键验收

## 交付范围与验收标准

按用户确认的 Compositor 对照顺序，修改独立桌面项目 `app`。验收要求：删除不会误删原图层；快捷键含义明确；停用蒙版可识别且不能落笔；单独查看不修改工程；载入选区使用真实 alpha；撤销、保存重开一致。未扩展 AI 或缓存架构。

## 行为

| 操作 | 结果 |
| --- | --- |
| 有选区时 Delete | 清除当前图片的选区像素，或将当前蒙版选区隐藏；保留图层 |
| 无选区、选择蒙版时 Delete | 仅删除蒙版，保留原图与图层 |
| 无选区、选择图层时 Delete | 删除所选图层，沿用锁定保护 |
| Ctrl+D / Ctrl+Shift+I / Ctrl+J | 取消选区 / 反选 / 复制图层 |
| X | 处于蒙版目标时切换黑色隐藏与白色恢复 |
| 单独查看蒙版 / Alt+点击蒙版缩略图 | 切换黑白查看；点击图片缩略图或完成蒙版后退出 |
| 蒙版载入选区 | 将当前蒙版有效 alpha 作为选区，保留反相、浓度、羽化与变换结果 |

蒙版停用时，缩略图显示叉号、属性和底部显示停用状态；落笔前阻止编辑，可显式启用。停用不等于正在保存笔触。停用的蒙版仍可查看和载入选区，此时不会顺带启用。单独查看只切换预览，导出和源图片不写入黑白预览。

快捷键限定在合成编辑器；输入框与可编辑文字不拦截。Mac 对应修饰键映射有逻辑测试，但未做 Mac 实机验收。
