# 独立图像工具后台批量任务验收

本批把非 AI 图像工具接入持久任务队列，保留现有算法、顶部参数和素材流转。测试使用临时数据目录及隐藏窗口；没有操作用户窗口，没有覆盖正式 `app/dist`，没有安装或热更新。全量目标仍未完成。

## 完成定义与实现

- 单图与 1–64 张批量共用处理入口，提交时固定参数、原图及第二张素材快照。整批输入先验证，逐张处理；全部成功才写入完整结果记录。失败或取消不发布半批结果。
- 图像计算使用独立、无可见窗口的沙箱 WebContentsView，继续使用现有工作线程算法。切换页面、切换工程不取消任务；结果只交给所属工程。没有建立新旧版本同步。
- 共用任务面板提供状态、取消和按原参数重试。关闭应用时等待本地处理收尾，运行任务成为中断；重启不自动计算。完整结果记录可恢复，取消任务不会被恢复成成功。
- 一批结果一次撤销；同次轮询收到的不同任务分别撤销。接收记录随撤销和保存保留，重启不把已撤销结果重新加入。原图资源、未知字段和模型配置保留。
- 批量选择复用共用弹窗、搜索和按钮；图像工具顶部直接提供入口。完成预览按当前原图匹配，第二张原图也能显示对应结果。

处理过程中生成的资源是内容寻址的暂存文件，完整结果记录才是发布边界。未完成任务可能留下未被素材列表引用的文件；本批没有增加自动清理，以免误删仍被快照引用的原图。文件残留与半批入库是两件事。

逻辑测试中的 PNG 头桩只验证存储事务，不作为图像质量证据；桌面测试实际解码 PNG 并采样。批量使用两张 4096×4096 色块/透明角构造图，原色 #4080c0 的 100% 质感结果为 [56,129,203,255]，透明角 Alpha 为 0。

一亿像素后台质感任务本机约 12.76 秒（含队列、编码和持久化），编辑页面 25ms 心跳最大间隔 27ms。计算 Tab 峰值约 1.34GiB，编辑 Tab 约 0.47GiB，GPU 约 1.09GiB；各进程峰值时间不一致，不能相加作为同一时刻总量。这是固定颜色/透明角样本，不代表复杂照片、低内存机器或长期压力达标。首次大图测试将 (1,1) 错当作不透明点，修正为按坐标判断 64×64 透明角后重跑；原失败报告留存，未修改产品算法迎合断言。

已查看 `raster-batch-dialog.png`：960px 隐藏窗口下选择列表、数量、提交操作可读，沿用当前主题和共享组件。未宣称原生多 DPI、Mac 和完整键盘/读屏通过。
