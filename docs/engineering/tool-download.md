# 工具手动按需下载

范围：AI 超分辨率与主体抠图的模型/运行组件。基础裁剪、旋转等已包含在应用内，不另行下载；AI 局部修改、扩图仍调用配置的在线 Images API，不伪装为可离线下载的模型。

## 行为和位置

- 未安装的工具显示云端图标、大小、下载位置与来源；只点击“下载工具”或“继续下载”才调用安装器。选中工具、刷新、重新进入、重启均不会触发下载。
- 直接下载落在当前应用 profile 的 `components/tugou-components/`，不弹系统目录选择框。具体完整路径可展开“下载位置与来源”；既有“管理本地组件”保留自选位置和使用已有组件。
- Windows 正式版通常是 `%APPDATA%/TugouIndependent/components/tugou-components/`；开发预览使用 `app/preview-data/components/tugou-components/`；Mac 使用当前 Electron 用户数据目录下相同的相对路径。不能把开发预览目录当成正式安装路径。
- 云端来源是现有清单中的固定版本 GitHub/Hugging Face 项目；抠图还下载独立 Python/PyPI 依赖。本轮没有发布自建下载服务器或推送 release。
- 圆形进度表示整个下载、安装、验证流程的阶段进度，不是所有网络传输字节总和。校验和验证通过才显示“已下载 · 离线可用”，云端图标消失；内存/显卡限制仍单独显示。
- 下载取消、失败或重启中断后保留缓存；必须再次点击才能继续。不同组件串行安装，当前卡片不会误显示另一个工具的进度。
- 超分 Win 45.5 MB / Mac 51.8 MB，包含三种模型，无需 Python；抠图双模型约 494.2 MB 加运行环境，预留 3 GB。它不是仅下载轻量权重的 4.6 MB 包。

## 实现

`tool-download.jsx` 负责只读状态轮询与显式按钮操作；沿用 RuntimeInstaller、TaskQueue、verifiedDownload。任务 context 增加组件标识用于区分进度；localToolsStatus/MCP tools.status 返回默认下载路径。默认位置与自选目录使用同一个校验/原子启用路径，不改变推理参数或已有工程。

不新增 npm 依赖。模型不放入安装包；runtime 目录只包含现有脚本、锁定清单、许可证等文件。圆形进度复用字体下载所用 Ant Design Progress 与云端图标。
