# 三类节点原型接入实际项目

2026-10-23。按已确认的第 3 版原型修改独立桌面应用 `app/`，完成源码、实际构建与原 Windows 预览程序更新。

## 完成标准与范围

- 图片节点：内置标题、大图、参考用途与实际尺寸；选中或悬停展示预览、替换和用途操作。使用工程原始素材，保持图片比例。
- 生成台：标题与状态、紧凑提示词、真实来源缩略图、大结果预览、结果缩略图与当前引用、底部模型/参数/生成。模式切换收入标题菜单；尺寸、质量、自定义值、数量、失败重试、取消、文本编辑及参数继承保留。
- 全景节点：独立 2:1 预览与 360° 标识、场景描述、真实输出尺寸、环视与重新生成；模型等配置放入标题设置及侧栏。沿用既有全景查看器。
- 侧栏：来源及定位、可折叠生成参数、质量/负面提示词/镜头、输入顺序与职责、合成提示词。生成台不再重复展示提示词编辑器和整套结果图片。
- 无工程数据迁移；保留节点 ID、连线、组合、缩放和已有参数。生成台的当前结果确实传递给下游；未生成的旧参数节点保留原有继承行为。显式上游文字引用和可编辑文本生成结果也有回归检查。

主要风险是结果引用与下游请求不一致、继承参数被误改、布局改变影响拖拽或连线，以及运行时覆盖用户数据。通过请求/编译检查、实际指针事件、持久化与重载、源码及包内双重桌面验证、更新前后数据哈希核对验收。
