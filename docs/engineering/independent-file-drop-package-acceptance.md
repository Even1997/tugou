# 系统图片拖入与构建体积验收

本批补齐系统图片拖入素材库、无限画布、图层画面，并减少桌面包中的重复前端依赖。当前用户窗口未操作，Agent 未补发任务或消息，正式桌面尚未更新；整体功能补齐与双端全量验收继续进行。

## 完成标准与证据

| 标准 | 验证 |
| --- | --- |
| 三个工作区可接收本机图片 | Electron `webUtils.getPathForFile` 获取真实 File 路径，素材库/画布/图层复用导入逻辑；文件悬停顶部可切换工作区；画布按落点、图层按缩放后的落点中心插入 |
| 原文件与数据保留 | PNG 原始字节完全相同，素材与节点/图层一次加入；单次撤销同时移除整批新增引用，重做及重启一致，工程未知字段保留 |
| 导入失败不发布半批 | 限 PNG/JPEG/WebP、本机普通文件、1–64 张、单张 64 MiB；检查磁盘空间；重复路径去重；整批先暂存验证，损坏成员拒绝整批并清理暂存；重复内容复用资源文件 |

| 精简不删除许可证 | esbuild 输入清单决定打包前端依赖的声明，连同运行依赖许可证写入产物；包内核对 React、Ant Design、sharp 正文，未删除 Electron 自带声明 |
| 控制新增磁盘占用 | 新构建、候选目录包和本批截图/profile/日志直接写 D 盘，重复构建使用同一输出目录；只带中英 Electron 语言，压缩设为 maximum；Mac 默认只产双架构 DMG，不重复 ZIP |
| 正式环境保护 | 原有正式构建/工作区 27 个文件哈希不变；隐藏测试窗禁止 show/focus，未安装候选包到正式位置 |

## 体积实测

同一 Electron 版本、本批同功能候选目录包对比（两次均已只保留中英语言）：

| 项目 | 调整前 | 调整后 |
| --- | ---: | ---: |
| 未压缩桌面目录包 | 429,407,417 B，约 409.5 MiB | 350,172,576 B，约 334.0 MiB |
| app.asar | 83,869,229 B，约 80.0 MiB | 4,634,388 B，约 4.4 MiB |

减少 79,234,841 B，约 75.6 MiB（18.45%）。前端/worker/声明等构建输出合计约 1.23 MiB。这里测量的是目录包，不是最终 NSIS/DMG 安装包；maximum 压缩的最终安装包收益尚未测量。包体剩余大头是 Electron，不通过删除运行文件或许可证冒险压缩。

迁移并清理 C 盘旧测试目录的命令被自动审批以“策略阻止”拒绝，未执行；没有释放该目录约 488 MiB 的旧占用。采用后续产物转 D 盘的方案，未改旧回退包、工程、素材或配置。后续命令必须继续设置输出路径：

```powershell
$env:TUGOU_BUILD_DIR='D:/TugouIndependentQA/shared-build'
$env:TUGOU_PACKAGE_DIR='D:/TugouIndependentQA/lean-package'
```

这两个路径只用于本机隔离验收，未硬编码进产品默认构建/用户数据目录；Mac 可指定本机路径。原测试脚本保留默认行为，并允许环境变量选择共享构建，避免额外复制。
