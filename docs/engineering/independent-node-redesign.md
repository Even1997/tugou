# 节点重做与旧源码移出

## 验收范围与完成定义

按照用户参考图替换旧节点 UI，保留独立 app、工程数据、引用、曲线连线和既有生成能力。通过节点内交互、保存重载、四类生成与结果入库回归，以及移出旧源码后的独立构建和包内检查，才更新预览。

## 交付内容

- 共用 ContentNode / GenerationDesk 组件：外置标题；文本双击编辑并支持撤销；空图片节点点击／拖入图片，保留原节点与连线；导入后尊重图片比例。
- 生成台内模式、模型、尺寸／数量等参数、镜头和生成／取消入口。模型留空沿用共享连接。“编辑提示词”包含补充要求、按来源展开的文本／参考图及完整提示词复制。繁杂内容收进浮层。
- 原有媒体、导演台、模块引用、工作台与顶部工具仍可使用。生成入口复用同一提交函数并防重复提交。
- 移出 web、desktop、canvas-agent、Go 服务目录、旧 CI／容器配置。根目录文档更新为 app 入口。
- 用户预览工作区 4 个文件移出前后 SHA256 一致；data／.tools／release 根链接保留；示例图片单独保留，旧模型许可保存在 docs/licenses/retired。
