# 删除入口检查与验收

## 本次补齐

| 对象 | 入口与行为 |
|---|---|
| 项目 | 顶部项目选择旁的「管理项目」，逐项删除；当前工程未保存时明确提示；删除当前项目清空编辑现场，删除其他项目保持现场和撤销记录 |
| 自定义字体 | 我的字体卡片、字体详情均可删除；从项目列表和已发布字体选择器移除 |
| 字体发布 | 字体详情「取消发布」，保留字体工程和已有文字资源，可重新发布 |
| 导入图集 | 导入图集页「移除图集」，移除列表记录，保留已保存字形和处理记录所需的原图 |

检查过已有入口：素材库选择后移除、画布节点删除、图层/画板/蒙版删除、提示词模块删除、配方删除及参考图移除、供应商删除、Key 和模型移除。本次不重复重写这些操作。

系统安装字体不在应用内卸载；处理任务记录仍用于字体版本和结果追踪，未增加破坏依赖的整表清空。按需下载字体目录仍完整保留。

## 数据保护

- 所有新增前端删除入口均先确认，默认聚焦取消；后端失败留在弹窗显示原因。
- 项目按持久化 revision 校验，字体按 fontRevision 校验。进行中及已取消但尚未退出的任务均阻止删除。
- 项目文件与备份移至工作区 `deleted-projects/<id>/`，字体工程移至 `deleted-fonts/<id>/`。不删除共享 `resources`，不修改用户导出的外部文件。不提供 Ctrl+Z 恢复，不声称立即释放磁盘容量。
- 字体删除、取消发布、图集移除接入 MCP：`font.project.delete`、`font.unpublish`、`font.atlas.remove`，保留 requestId 幂等和版本冲突保护。工程删除目前是界面操作，已记录在 MCP 覆盖清单。
- 使用现有 Electron/Node 跨平台文件及 UI 接口，无平台 shell 删除命令。
