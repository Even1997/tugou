# 多连接与用途分配验收

## 交付范围

- “连接配置”：新增、命名、切换、编辑与删除多组连接，每组 URL、Key、模型、协议独立保存。
- “用途分配”：图片生成、视觉分析、文本、视频、语音可分别指定连接；空分配跟随默认连接，无默认则保持未配置。
- 测试连接、拉取模型使用当前连接的草稿。只请求模型列表，不提供逐模型生成测试按钮。
- 空白 Key 仅保留同 ID 已存密钥；新连接不会借用默认 Key。密钥通过既有系统加密存储，不返回渲染端。
- 切换连接保留草稿并清空旧探测结果，迟到响应丢弃。删除提示用途回退规则；删除默认后需重新选择默认。所有变更保存后生效，取消完全丢弃草稿。
- 保存校验用途指向、重复 ID、名称、地址，并以修订号阻止过期编辑覆盖。旧单连接只读呈现，首次保存才写入多连接结构。
- 生成台、视觉分析、语义分析、云任务及工作流服务按用途取得连接。保存事件刷新画布与配方默认模型。

## 验收与证据

1. `app/test/multi-connection.test.cjs`：6 项专项，覆盖旧配置保留、用途路由、Key 隔离、原子校验、删除和实际 HTTP 服务链路。
2. `node --test test/*.test.cjs`：223/223 通过，日志 `app/test-results/multi-connection/unit-tests.txt`。
3. 两个独立本地 HTTP 服务接收实际服务类请求，检查图片、视觉、文本、视频、语音各自的地址、Authorization 与模型；任务输出无密钥。此证据不等于真实云服务商验收。
4. `app/test/multi-connection-desktop.cjs`：源码和包内各 44/44 通过，零渲染错误。覆盖真实鼠标/键盘输入、保存重开、切换、删除、取消、迟到响应、错误状态、深浅主题和小窗口滚动。
5. 5000 项模型列表使用虚拟滚动，包内记录约 293ms（此为本机测试样本，不作为公网耗时保证）。
6. `app/test-results/multi-connection/delivery.json`：19 个核心/构建文件与 ASAR 哈希一致；实际 dist 同步；交付期间 22 个工程 JSON 不变。运行中旧窗口未重启。

## 使用与限制

原启动入口 `启动图构预览.cmd` 已指向 `app/release/multi-connection/win-unpacked/Tugou.exe`。当前旧版窗口保存并关闭后，从原入口重开即可使用多连接。

本轮使用隔离测试资料，没有发送真实付费生成请求。真实服务商鉴权、限流和具体模型能力，Mac、系统 DPI 变化仍待实机确认。旧版本不支持新保存的多连接配置，后续请使用新版入口编辑连接。
