## 范围和完成定义

接入本地模型、统一顶部参数与组件设置；后台任务可取消，切换页面继续处理；结果进入共享素材库且可撤销/重做；保存与重启不重复插入。原图、未知字段和现有编辑功能保留。只有实际模型输出、像素检查、隐藏桌面操作和新进程恢复均通过，才计为本批可评审。

应用适配器和 Python 工作脚本为独立实现，没有复制旧应用的工具代码。模型与计算运行时仍为外部依赖，保留它们的许可证。配置通过用户选择本地组件目录；本批验证使用本机已安装组件，不读取旧产品设置，不建设新旧版同步，也不调用线上 MCP 或模型 API。

## 已接入

- 通用/插画 4×，动漫 2×/3×/4×原生超分；输出尺寸校验，单边最多 30000、总量最多一亿像素，并按可用内存拦截。透明度采用原图 Lanczos 插值，颜色细节使用 AI 输出。
- 固定校验的完整主体模型；1024 双线性预处理、ImageNet 归一化、输出 sigmoid；保留原始 RGB，只乘减 Alpha，已有透明区域不会变实。Windows GPU、Mac Core ML、CPU 入口按实际组件能力检查，禁止初始化失败后静默切到不同设备。
- 任务串行执行、阶段状态、取消时终止本任务创建的进程树；本地运行任务在关闭前等待清理。启动后不自动重新计算；已落盘的完整结果可恢复。
- 结果通过同一任务结果库进入素材库，不自动增加画布节点。一次撤销移除结果但保留接收记录，重启不会重新插入。工程中保存最小原图快照；从素材库移除原图后，仍可在处理记录对照、重新运行，无需恢复被移除的素材条目。
- 共用组件、顶部工具栏、历史模型/倍率恢复、任务面板；缺少组件时有明确提示。组件目录与项目数据分开保存，不要求重复配置模型 API。

这不是自然照片通用精度：原图残留的边缘碎点会随透明通道保留，插画模型也会加强线条/简化细节；抠图不是恢复实底照片真实半透明材质的数学逆过程。可继续使用已实现的透明边缘工具处理原图已有轮廓。
