# 独立尺寸与区域工具验收

本批继续完整复刻目标，未操作当前用户窗口、未覆盖正式 `app/dist`，未安装或热更新。旧版只作行为参考，不增加新旧版同步。

## 范围、验收与实现

| 能力 | 行为与验收标准 |
| --- | --- |
| 精确尺寸 | 指定输出宽高；按原图比例联动或解除比例。保留原倍率方式；输出真实尺寸、历史恢复、撤销/重做均可核对 |
| 透明扩边 | 指定目标尺寸与原图左/上偏移，可居中；保留四边等宽模式。完整保留原图像素，无法容纳时拒绝，不静默裁掉原图 |
| 裁剪 | 预览框选或输入原图像素坐标，输出画幅缩小为选区尺寸，原素材保留 |
| 框选提取 | 输出保留原画幅和位置，选区外透明；支持向内羽化，不改变选中区域颜色 |
| 选区替换 | 第二素材缩放至选区，以透明度叠加，可向内羽化；选区外逐像素不变。透明替换像素保留底图 |

顶部采用共用按钮、浮层、数值输入，复用框选预览；尺寸控制单独组件化。几何运算移至现有工作线程，取消通过终止线程生效，不再在主线程同步缩放/旋转。纯尺寸处理同样保存最小原图快照，删除素材库条目后可以从历史原图重新运行。

区域透明混合为独立标量实现。替换图先在统一尺寸表面缩放，再分块读入、混合，避免将缩放分别裁到块内时出现采样差异。此次像素测试发现并修正了这一问题。

保持单边 30000、总量一亿像素上限。越界矩形、非法尺寸、无替换素材均拒绝；不会降低输出分辨率以通过测试。一次结果入库与加入图层分别为一次撤销事务，未知工程字段保留。

缩放参照使用相同浏览器的完整图幅原生采样，不能称为独立 Lanczos 实现或不同系统间像素一致性证明。区域混合与羽化另用独立公式对照：新增构造样本 Alpha 最大差值 0，预乘 RGB 最大差值低于 1/255；跨 512 像素分块测试通过，选区替换外部像素完全不变。实际人物样图也通过相同指标；已查看四列样图及 960px 深浅主题截图。

大图测试使用固定色与透明角落样本：缩放为 25MP 输入到 100MP 输出；扩边为 9998² 输入到 10000² 输出；裁剪为 100MP 输入到 9998² 输出；提取和替换保留 100MP 画幅。处理时间约 1.03、1.54、1.52、3.46、2.87 秒，25ms 心跳最大间隔约 99–311ms；Tab 进程峰值约 1.03–1.77GiB。各类报告另保存 GPU/主进程峰值，不应相加当作同时发生的总内存。
