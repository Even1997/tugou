# 画板右键与原尺寸图片保存

状态：本地实现与 Windows 自动验收通过，待用户确认，未发布。

## 操作

- 在合成页的画板标题、画板内部或图层列表的画板行上右键，可保存图片、批量保存、编辑、复制或删除画板。
- “保存图片”保存右键目标，即使它不是当前激活的画板。
- “批量保存画板”列出当前合成的画板名称与像素尺寸，支持逐个勾选、全选、清空。选择一次文件夹后逐张输出；同名自动编号，不覆盖已有文件。
- 删除仍需确认，复制与删除沿用工程撤销；保存不修改工程内容或清空历史。
- 渲染期间可取消。已完成图片保留，剩余停止；失败显示已保存数量，再次保存仅处理剩余选择。

## 分辨率约定

画板输出无损 PNG，尺寸等于画板宽高，保留画板透明／实色背景。预览缩放与屏幕 DPI 不参与导出尺寸。素材保存使用原始资源的自然宽高，后端原文件导出直接复制资源；不以缩略图或视口截图代替图片。原图本身的细节上限不会因导出被凭空提高。

沿用现有 Compositor 的尺寸保护：超过单边 32767 或总计一亿像素时报错，不自动降分辨率。批量上限 500 个画板，逐张渲染与写入，避免同时持有整批输出画布。

## 实现与验证

`composite-workspace.jsx` 负责右键入口，`board-export.jsx` 管理勾选、进度、取消与剩余重试；复用 `artboards.extract` 和 `Compositor.export`。桌面 `chooseExport` 对名称数组提供文件夹选择，返回一次性写入凭据。`image-export.cjs` 处理跨平台名称、重复编号和排他创建；写入前仍校验 PNG 与安全路径，取消后回收凭据。

完成标准：右键目标准确；批量仅保存选择项；尺寸与透明像素正确；同名不覆盖；取消不留残缺文件；失败可继续剩余；工程与撤销不受保存影响；两种主题和窄窗口可用。
