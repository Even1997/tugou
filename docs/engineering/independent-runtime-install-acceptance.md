# 独立本地组件安装验收

2026-10-22。本批补齐组件安装入口与安装事务；不是全平台完成声明。用户当前窗口未操作，正式桌面未更新。安装与打包验证位于 D:/TugouIndependentQA，界面使用隐藏窗口和独立数据目录。

## 验收目标与结果

| 目标 | 验证方式与结果 |
| --- | --- |
| 安装一次供本地工具共用 | 顶部“本地组件”内选安装位置、可选主体模型、已有目录接入；真实安装后超分和主体模型探测成功 |
| 下载可取消、可继续且不执行损坏文件 | 流式下载、Range 续传、完整大小/SHA256 校验；服务器忽略 Range 时从头写入；损坏内容不安装；取消后部分下载保留 |
| 失败不破坏当前配置 | 独立版本目录、目录所有权和进程锁、空间预检；全部验证后原子切换。失败、取消、验证失败、并发修改及最终切换时取消均有事务断言 |
| 安装状态可靠 | 共用持久任务、明确重试；关闭等待本次安装进程退出，重启不会自动再次下载安装；完成显示“已安装” |
| 桌面包能安装 | 实际 Windows asar 包执行完整安装，原失败任务继续成功；本批未运行正式安装程序 |
| 跨平台包准备 | Windows x64、Mac arm64/x64 下载清单及带哈希依赖锁；两款 Mac uv 压缩包按生产规则解压，超分文件确为 x64/arm64 双架构；Mac 实际执行仍未验收 |

组件使用应用内独立 uv/Python 环境，不写系统 PATH 或 Python 注册项；图像依赖只装锁定哈希的二进制 wheel。下载和 Python 缓存在用户选择的组件目录中。重试使用原任务的版本与位置，版本或系统变化要求重新安装；正在使用的版本目录不覆盖。

每份 uv、超分和主体模型大文件均按固定清单校验；压缩包拒绝越界、链接、特殊文件、重复文件及超限大小，并拒绝 Windows 保留名和尾随点/空格。主体模型校验改为流式读取，避免一次读入约 489 MB。许可证随组件保存，不在业务界面展示来源介绍。
