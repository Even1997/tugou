# MCP 当前接入与验收

当前源码已补齐覆盖清单中的创作缺口：**179 条命令、26 个领域、7 个顶层工具**。本轮新增 27 条命令，扩展既有图层、选区和笔刷参数；使用同一桌面文档、撤销历史、图像算法及任务队列，没有另建编辑引擎。调用方法见 [MCP 全量创作命令](mcp-creative-commands.md)。

v0.8.12 已公开发布，三平台包体验收通过。现有未保存工作窗口保留运行；保存工程并升级重启应用 / 客户端连接后才能加载新目录。发布结果见 [v0.8.12 验收](release-v0.8.12.md)。

## 本轮补齐

- GIF 图片合并、顺序 / 时长 / 循环设置，画板动画时间轴、GIF 帧范围和指定帧 PNG 导出。
- 生成结果选择，节点 / 组复制并重映射内部引用，统一节点尺寸。
- 配方参考图片与职责排序、单项绑定覆盖 / 重置 / 冲突处理、节点绑定刷新。
- 图层缩放 / 倾斜 / 透视、完整混合模式、剪贴、外部蒙版、直线、选区裁切。
- 魔棒 / 色彩范围、选区加减交 / 羽化 / 扩缩、局部调整蒙版、蒙版独立变换及重新链接。
- 透明绘画层、内容识别填充、仿制 / 修复 / 模糊 / 涂抹 / 液化、压感和平滑。
- 网格、参考线与吸附，素材高级搜索排序，旧工程和历史画布快照迁入。
- 导演台 4 / 12 方位截图、后台 1–60 秒机位录制；独立结果素材和连线节点。

耗时操作通过 taskId 查询、取消和结果读取，requestId 去重；提交版本变化时拒绝覆盖。任务面板与 MCP 共用取消保护，已写回的结果不会在保存回执期间误标为取消。导出遵守受控文件目录和不覆盖规则。像素 / GIF / 3D 预算见调用说明，不把命令数量当作所有平台和参数组合的完成率。

## 保留的产品边界与待确认项

- 安装更新、更新源、组件安装、系统窗口和剪贴板仍由用户控制；工程删除保留桌面确认。首页统计用现有工程 / 素材 / 任务查询组合读取。
- Mac 双架构原生包内验收已通过，详见发布验收；本地真实模型的最新全链路、真实供应商、第三方客户端长流程和大型工程 / 低配置机器仍需补验。
- 图层拖拽专项已复核：隐藏窗口显示后视口变化使测试坐标及截图基线失效；改为先显示并等待布局 / 绘制稳定，完整 29 项通过，含真实拖拽撤销 / 重做和导出。应用撤销逻辑未改动。
- 当前 MCP 连接配置不变，旧客户端必须先加载新桌面代码；未重启当前未保存窗口。
