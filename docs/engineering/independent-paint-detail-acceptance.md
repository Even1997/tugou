# 独立绘画交互补齐验收

## 范围与完成定义

补齐屏幕像素拖绳平滑、抬笔补齐端点、Shift点击连线和直接绘制蒙版。沿用顶部组件与原有存储，每笔一次撤销；原图、图层类型及未知字段保留，预览/导出/新进程恢复像素一致。禁止新增旧版与独立版持续同步；同一工程的模块引用更新不在取消范围内。

## 实现与验证

- `paint-target.js` 统一图像/蒙版坐标，支持蒙版独立偏移、旋转与透视。图像、文字、形状及组可直接绘制蒙版；隐藏/恢复保留反相和羽化配置，不栅格化文字或组内容。
- `painting.js` 按屏幕像素拖绳平滑并在抬笔时补齐端点。直线先显示引导，抬笔后写入；Shift点击连接同一图层和目标的上一笔端点，保存后仍有效，内容变化时失效。
- `use-painting.js` 复用笔触事务、临时蒙版预览和取消逻辑；Esc、失焦取消，不覆盖新文档。顶部继续复用现有参数组件，没有新增全局样式。

## 运行窗口与限制

当前构建已产出，但用户正在操作窗口且有未保存修改。尝试保存时工具报告用户输入，已停止窗口操作；未触发本批热更新，也未强制退出或覆盖用户工程。现有测试不能代替当前窗口加载新构建的验证。

Mac真机、实体绘图板、复杂图像的反相/羽化蒙版组合、大尺寸蒙版和多层长时压力仍待。100MP普通绘画通过不等于100MP蒙版通过。调整图层/特效和完整平台复刻尚未完成。
