# 独立参考图分析：实现与验收

本批接入参考图分析、可编辑草稿、模块选择与配方创建。整体复刻仍未完成；分析实际画质/提示词准确性和 Mac 实机仍待验，不把模拟模型返回的内容称为真实视觉识别成果。

## 行为与验收范围

- 顶部“参考图分析”可选共享素材或导入图片，通过统一连接的视觉模型直接请求 Chat Completions；不经过线上 MCP。仅发送选中的参考图和分析要求。
- 输出公共画风、人物、动作、服饰、背景、装饰、文字、道具、宠物、材质、构图及自定义类别；可以同类多个模块，不要求每种类别都出现。画风与内容拆分，不预设半身/全身，不默认开启任何全局模块。
- 结果先落盘为草稿，可编辑名称/类别/提示词、勾选采用、单独开启全局，可选择同时创建配方。原图作为画风参考默认关闭，不把参考图里的原人物身份自动加入配方引用。
- 草稿修改通过“保存草稿”持久化；加入模块前也保存审阅内容。只追加所选模块，保留当前工程的其他编辑、未知字段与原素材。导入是一次可撤销的工程操作，重复导入拒绝，恢复导入前文档后可重新采用。
- 分析共用持久任务队列，取消后不发布迟到结果。响应异常、截断或过大时不会产生空草稿，不自动重试。已落盘结果可在重启后恢复。生图读取和恢复明确排除分析任务。
- 图片上限 20 MiB、响应上限 1 MiB、最多 40 个模块，每模块提示词最多 4000 字；请求超时为 180 秒。任务日志不含密钥或原始模型错误正文。

最大草稿测试含 40 个模块、每个长提示词 4000 字，切换至该草稿的本机观察值约 59ms；对应 renderer 工作集约 180MiB。只代表此场景，不代表全部图库、长时并发或 Mac 性能。

截图已查看 `analysis-dark.png`、`analysis-light-960.png`。真实桌面检查另外发现并修复：旧条件样式隐藏分析入口；弹窗关闭按钮与无边框标题栏拖动区重叠。新增可见性和几何检查，并实际点击关闭验证。审阅操作固定于弹窗底部。

正式数据对照分两次：正常保存后到正常重启，21 个文件全部一致；随后两次保存式热更新更新了当前工程包装及备份修订，另外 19 文件不变，最近两份保存的 `document` 完全一致。未覆盖原正式版或其他工程，未更换用户 API 密钥。最新文档指纹保存在 `production-fingerprint-latest.json`，供后续批次对照。
