# 独立云端图像工具验收

本批接入云端增强、创意放大、AI 局部修改和 AI 扩图。共用模型连接、顶部参数、后台任务和素材事务；本机处理原图、蒙版和模型返回图，生图直接请求配置的 Images API，不经过 MCP。全量复刻目标继续，真实模型能力尚未通过本批验收。

## 完成定义与边界

- 四类工具可提交、取消、保存结果和恢复处理记录；参数及原图冻结，切换工作区不影响后台执行。
- 局部修改采用矩形和内部线性羽化，矩形以外 RGBA 完整保留；扩图保留原图所在矩形，包括原本透明像素。任意形状蒙版和图层选区联动尚待。
- 增强和放大结果恢复原图 Alpha，放大使用 Lanczos 插值 Alpha；没有把模型重新生成的背景当作原图透明度。
- 返回原始图片先落盘，再处理。尺寸不同进入待确认；仅明确确认后可将较大、同宽高比的返回图缩小，拒绝放大补齐或拉伸比例。原始图可单独导出或入库，离线合成不重复请求模型。
- 成品与原始图分别入库、去重并可撤销；接收记录和未知字段重启保留。取消不发布迟到结果，关闭等待本次原生子进程退出及临时文件清理。
- 凭据不进入快照或任务错误；复用已有响应大小、协议、重定向和资源验证。没有自动付费重试。

处理格式为静态 PNG/JPEG/WebP 解码后的 8 位 sRGB；EXIF 方向规范化。保护区逐字节承诺针对规范化 RGBA，不能外推为原始 JPEG 文件字节、ICC、16 位或 HDR 保真。保留单边 30000 / 总量 100MP 的参数边界、64MiB 单资源限制和内存预检，本批未证明所有极限输入均可完成。

## 实现

`cloud-settings` 管理工具参数和提示词；`cloud-tasks` 管理请求快照、原始结果审阅和本地恢复；`cloud-runner` / `cloud-worker` 在独立进程中调用 `cloud-pixels`。使用标准 sharp 库处理 RGBA，避免浏览器 Canvas 丢失完全透明像素中的颜色值。既有独立生成服务的 Images API 请求抽出为 `image-api`，没有导入旧应用代码。

界面复用共用按钮、数值输入、弹层、弹窗、Checkbox 和任务面板；较长文字及次要参数收进顶部弹层。原始结果审阅明确列出请求/返回尺寸与本地处理说明。960px 隐藏窗口截图已查看并修正复选框排版。

生产依赖锁定 sharp 0.35.5，打包包含原生组件并解包相关原生资源，许可证正文随构建保留。平台可选组件缺失时只跳过未安装的可选包，其他缺少许可正文仍报错。依据 [sharp 安装文档](https://sharp.pixelplumbing.com/install/) 和 [输出文档](https://sharp.pixelplumbing.com/api-output/)；实际 Mac 打包和运行尚未验证。
