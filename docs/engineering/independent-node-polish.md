# 节点样式与交互修整

## 验收范围

修整独立 app 的节点组件和真实交互，沿用现有工程、模块引用、模型连接、任务与素材链路。完成定义：节点内常用操作可用，生成后仍可编辑，错误与取消可见，结果正确入库，深浅主题和缩放无内容溢出，源码及 Windows 包内回归通过后更新预览。

## 本批变更

- 内容节点统一标题、类别、字数／图片尺寸与底部操作；文本直接编辑和复制，图片可预览、替换及设置参考用途。模块更新仍尊重本地覆盖与冲突状态。
- 各生成节点共用生成台组件：输入来源、直接输入提示词、模型、参数、镜头、状态、生成／取消及结果。高级选项放入浮层，接入共享模型连接。
- 生成文本可在节点内继续修改与复制；多张结果可切换下游引用，媒体结果可打开共用详情。生成后不再遮掉提示词编辑入口。
- 参数无效时显示原因并阻止生成；提交、排队、运行、失败、取消状态可见，快速重复点击只提交一次。上游缺少内容时显示待检查的连接数，避免错误显示全部为零。
- 参数继承时展示实际模型与来源，并禁止在当前卡片修改被上游覆盖的参数。原有上游控制语义保留。
- 新结果避开加宽后的生成台；顶部新建节点避开已有卡片。适应画布按全部节点位置计算，修复远处未挂载节点无法找回的问题；用户明确点击的位置保持。
- 复用 Ant Design、现有主题和图标，不增加依赖、UI 库或大资源。内容／生成／结果三个组件按职责组合。
