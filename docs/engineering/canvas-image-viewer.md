# 画布图片查看器验收

画布的双击和预览入口改为全屏图片查看器，不显示详情卡片、名称或提示词。图片本身没有边框、底板、圆角或阴影；支持滚轮与按钮缩放、放大后拖动、适应窗口、100%、Esc／关闭按钮，以及 `+` / `-` / `0` / `1`。查看使用原图地址，不用缩略图。

图片名称、不可编辑的原始提示词、模型与来源放到右侧节点设置。读取仍走既有 `assetDetails`，保留生成记录和处理来源的追溯，不使用后来修改的配方替换原始记录。名称修改沿用工程状态管理，支持撤销、重做与保存。素材库的管理详情及历史媒体详情保留。

## 实现与范围

- 复用已安装的 [Ant Design Image](https://ant.design/components/image/) 的预览、鼠标变换和焦点管理；没有增加依赖或另写图片处理引擎。
- 复用项目 `#dialogs` 挂载点，避免组件默认滚动锁生成无 nonce 样式；不放宽 Content Security Policy。
- 缩放、平移与窗口适配只维护查看器本地状态，不提交文档、改变画布视口或创建撤销步骤。
- 右侧读取请求在切换素材／节点后忽略过期返回，名称编辑不会修改历史生成提示词。
- 改动仅在渲染器及相应验收脚本，没有修改工程格式、生成接口或后端功能。

## 已验证

`app/test/canvas-image-viewer-desktop.cjs` 使用独立数据目录与固定生成素材，24 项通过，零渲染错误；证据 `app/test-results/canvas-image-viewer/report.json`。

覆盖 1115×1410 竖图、2200×700 横图、透明留白、280×280 无提示词图片，以及 1380×900／960×720 窗口、深浅主题。实际 Electron 鼠标输入验证双击、拖动与滚轮；100% 显示宽度与原始像素一致，适应窗口包含整张图片；键盘焦点保留在查看器中，关闭后可继续使用原界面。

查看前后核对工程 revision、dirty、撤销／重做历史和画布视口一致。在有未保存改名的状态下打开查看器，删除与撤销快捷键不会作用于底下的画布，关闭后修改和历史保持。右侧改名后核对节点标题、原提示词、撤销／重做和保存结果；处理图片显示来源提示词，无提示词时明确说明；素材库详情仍可使用。

原有 `canvas-media-desktop.cjs` 图片流程 30 项与重启恢复 7 项回归通过，零渲染错误。覆盖真实任务记录的原始提示词、复制、替换、分析、保存恢复与素材库详情；生成和分析接口使用本机模拟服务。回归脚本同步调整为当前文字导航、共享下拉和侧栏提示词位置；没有改动生产替换／分析流程。证据为同目录下的 `canvas-media-desktop.json`、`canvas-media-restart.json`。

默认 `app/dist` 已构建，`ui.js`、`ui.css`、`index.html` 与上述验收构建逐字节一致。
