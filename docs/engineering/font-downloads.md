# 字体按需下载

当前开发版保留现有 55 个系列、141 个可选字形/字重文件，以及本机字体、自定义发布字体。安装包保留目录、原始许可、来源和 SHA256；不再携带 TTF/OTF/TTC 字形文件。原始字体仍保留在源码，用于资源发布和验证。

## 使用与位置

- 字体或粗细列表中，云朵表示该字重尚未下载。点击云朵或选择该项，即下载并应用；下载中显示圆形真实进度，校验完成后图标消失。
- 每个字重独立缓存。切换字重不会下载整个系列；失败可重试，中断保留部分文件用于续传。下载失败不替换当前文字的字体，也不伪造成功。
- “离线可用”指联网下载成功后可离线排版、重开工程和导出。没有缓存的字体不能在断网时首次下载。
- Windows 默认位置：`%APPDATA%\TugouIndependent\workspace\font-cache`。
- Mac 默认位置：`~/Library/Application Support/TugouIndependent/workspace/font-cache`。
- 自定义 `TUGOU_DATA_DIR` 时使用其下的 `workspace/font-cache`。在「设置 → 文件与存储」可打开实际数据目录。字体缓存不安装到系统，普通浏览器缓存清理不会删除它，软件升级沿用该目录。
- 打开已有工程或预览/导出时，按需获取其中引用的字体。离线缺失会报告错误，不用替代字体悄悄导出。跨机器使用需在目标机器下载相同字体。

## 资源与边界

固定资源源为 [font-assets-v1](https://github.com/Even1997/tugou/releases/tag/font-assets-v1)，以预发布且非 Latest 形式发布，不进入软件稳定版更新通道。141 个资源均保留原始字节，附件名由 SHA256 加原始扩展名组成；`catalog.json` 和 `FONT-LICENSES.txt` 公开完整目录和原始授权。

下载使用固定源、预置大小和摘要，允许 GitHub 的下载重定向；字形加载前核对 SHA256，不信任渲染器传来的 URL 或路径。缓存拒绝链接路径，使用临时文件及原子更名，重复请求复用正在进行的下载。

MCP `font.library` 的 `builtin[].faces[]` 返回 `id`、`weight`、`status`（cloud/downloading/ready/error）及下载信息；`font.download {id}` 下载并校验指定字重，可重复调用，不修改工程。普通字体下载不需要 Python。

## 验证

Windows 本轮全量 Node 检查 360 通过、1 平台限定跳过。源码和精简包内桌面检查分别 17 项通过，覆盖真实控件、圆形进度、独立字重、撤销、离线重载/导出、失败重试和窄窗口；真实匿名 GitHub 完整下载两个字体及新服务实例离线缓存检查通过。另启动实际打包的 Windows EXE，在隔离目录连接 MCP（136 命令）并匿名下载字体成功。

思源黑体的 7 个真实字重通过 22 项额外包内检查，包括离线切换、字形像素差异、撤销/重做、重开工程、PNG 导出和字体淘汰后恢复。字体注册缓存保持在 64 MiB 预算内；本轮字重切换 P95 为 458 ms，不代表所有设备、网络或工程规模的性能保证。

Windows 候选安装包实测 105,724,097 字节，包内字体二进制数量为 0，目录及许可证保留；解包 374,675,446 字节。候选位于 `app/release/font-on-demand/`，未覆盖已发布 v0.8.3 或用户运行实例。Mac 双架构原生构建与验收待本轮 CI 结果补充。

证据位于 `app/test-results/font-downloads-*`。字体资源源可用性取决于用户网络；不提供离线首次下载，也没有修改系统网络或安全设置。
