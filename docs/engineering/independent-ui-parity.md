# 独立版界面对齐与完整复刻清单

## 目标与完成定义

用户要求按旧版完整复刻，先组件体系和所有页面 UI，再功能；不能继续以简化版替代。当前持续目标未完成，下表是逐项对照，不是全量完成声明。

以本地旧版实际截图、交互验收及数据协议为依据：`studio-evidence/ui-workbench-dark.png`、`canvas-ui-final.png`、`relaxed-ui-populated-light.png`、`atelier-tools-ui.png`、`editor-workspace-acceptance.md`。新增实现不导入旧产品代码。基础组件采用锁定版本的 Ant Design、Ant Design Icons 和 React Flow。

验收门槛：入口、布局、状态和真实行为同时存在；原工程/未知字段/素材/加密配置保留；编辑可撤销且保存重开一致；图片操作须像素验证；模型任务须验证请求、取消和结果入库。真实模型画质、大图性能与原生 DPI 不能由模拟接口或 CSS 缩放代替。

## 本批实现与风险处理

语义后续见[类别拆分验收](independent-semantic-acceptance.md)：独立类别建议/方案、逐类蒙版、原像素提取、单类重试和对齐入层已接入。语义剩余差项为真实类别与蒙版质量、100MP/长时性能、供应商协议及双端验证；本地组件安装继续。

任意蒙版后续见[蒙版验收](independent-cloud-mask-acceptance.md)：局部修改新增透明度/亮度/反转与画面选区快照，历史保留原蒙版、顶部云端状态/取消通过。剩余蒙版差项为变换图层坐标映射、大选区前端响应性和 100MP/双端验证；语义拆分与组件安装继续保留。

- 页面职责拆分为 `components`、`shell`、`prompt-workbench`、`recipes`、`connection`、`materials`、`image-tools`、`layer-properties`、`number-field` 等组件。共用主题通过 ConfigProvider 与语义变量统一，工具页样式单独作用域；没有继续叠加旧 UI 覆盖层。
- 配方生成先提交当前节点快照，再异步请求；后续编辑和生成结果按当前工程合并，防止旧快照覆盖新输入。工作台与画布共用同一持久生成队列。
- 导入/图片处理保留当前文档并防止卸载后写入其他工程。处理结果新建素材，原素材不改；素材被引用时禁止移除。保存繁忙时不把未成功入库的结果标为成功。
- 本地图片用原始资源、匿名跨源加载和真实 Alpha 编码；初版发现画布污染导致无法导出，已修复并用逐像素测试确认。处理历史使用缩略图，不批量解码原图。
- 本地工具支持单边 30000、总量 1 亿像素的尺寸校验；单素材文件仍为 64 MiB，整图处理的 100MP 内存/取消尚未验证，不能沿用旧实现的压力测试结论。
