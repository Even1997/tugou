# 照片调色与副本修图验收

状态：源码完成，待用户体验确认；未发布安装包。

## 范围与完成标准

复用图层调整、修图引擎和文档事务，新增七项照片调色、临时对比、原位副本修图，不引入独立编辑器。验收要求：中性参数不改变像素，透明度与选区/蒙版保留；滑块预览不保存、一次操作一次撤销；修图不覆盖原像素；保存重开一致；MCP 参数严格校验；浅深主题、小窗口可用。

## 使用入口

- 图层 → 更多 → 调整 → 照片调色。点击调整层图标或名称，在现有右侧栏左边展开占位式独立参数面板，画布可视区随之收窄、关闭恢复，保持视图中心；原属性区和图层列表不移动；支持冷暖、绿—洋红、曝光补偿、高光、阴影、自然饱和度和饱和度，以及数值输入、强度、重置与停用。
- 拖动滑块预览，松开提交；Esc 取消未提交预览。方向键微调。按住“按住对比”临时隐藏当前调整，释放或窗口失焦恢复，不写文档/历史。
- 更多 → 修图 → 选择修图工具 → 在副本修图。复制图片的变换、蒙版、混合和透明度，原位创建副本、隐藏原层并选中新层，避免半透明叠加。原层像素保留，一次撤销恢复。锁定/隐藏图片及关联蒙版来源拒绝操作。
- MCP：`layer.retouchCopy({id})`；现有 `layer.adjustment` / `layer.adjustmentFromSelection` 接收 `type: "photo"` 及七项参数。沿用 revision 和事务保护。临时预览不是文档动作。

## 边界与待确认

这是 SDR 像素相对调色；冷暖不是开尔文绝对色温，曝光不是 RAW 高光恢复，不承诺 Camera Raw 算法等价或专业色彩管理。自动化主要采用可精确断言的合成像素；真实人像/风景的主观画质、Mac 原生交互、数位笔、低配置大图多调整层仍待用户或对应设备验证。PSD 文件读写仍为界面入口，不属于本轮 MCP 扩展。
