# 文字边缘裁切修复

## 原因与范围

顶部基线使 48px 微软雅黑实际字形上伸 4.421875px，位图从 y=0 开始，导致顶端笔画被裁。使用实际字形上伸高度定位字母基线，保留 2px 边距，并在换行及左右对齐考虑字形外伸。保留固定文本框与行距，不新增自动扩容行为。

## 验证

新包：app/release/text-clipping/win-unpacked/Tugou.exe。原入口与 dist 已更新，当前旧窗口未重启。
