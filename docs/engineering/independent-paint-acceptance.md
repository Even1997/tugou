# 独立绘画工具验收

本批接入画笔、橡皮、平滑、直线、软硬笔刷、透明度和压感输入。仍按完整复刻计划继续；仿制、修复、模糊、涂抹、液化、内容感知填充、调整图层和特效未完成，macOS 尚无真机证据。

## 完成定义与实现

- 统一顶部画笔/橡皮入口；固定参数行显示颜色、大小、透明度和新建绘画图层，硬度/平滑/直线/压感使用共享浮层与 NumberField。深浅主题使用现有变量。绘画时隐藏变换手柄并显示正确操作提示。
- 对图片图层的原始像素绘画；新建绘画层为工程大小的透明位图。现有变换、分组、选区、蒙版和未知字段保留。锁定/隐藏图层不允许落笔。
- 每笔保存为独立 PNG 修订，保留原资源；一次撤销对应一笔。Esc、指针取消、切换工具/工程或编辑状态变化取消未提交笔触，异步结果不得覆盖新修改。未落到图层上的同像素结果不新增历史。
- 透明度按完整笔触应用一次；平滑过滤位置，直线仅保留起终点路径，按原图像素定义笔刷直径。绘图板压力改变半径，鼠标不模拟压力。
- 256px 稀疏覆盖分块，只重绘脏块。工作表面为一张完整输出加笔触覆盖块及共享小画布；选区需要额外原尺寸蒙版。合成器丢弃已不引用的历史位图解码缓存，防止每笔累积原图内存。

100MP 是合成引擎稀疏笔触和 PNG 持久化/重开验证，不代表复杂多图层工程的连续交互、全屏涂满、完整选区或低内存设备已通过。压感输入有参数级像素证据，物理绘图板和 Mac 实机仍待。
