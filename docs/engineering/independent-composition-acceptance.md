# 独立配对透明、材质与素材拆分验收

本批仅生成隔离候选，不操作用户当前窗口、不覆盖正式 `app/dist`，不安装或热更新桌面。完整复刻目标仍在执行。

## 范围与验收标准

- 黑白底提取透明：两张同尺寸、逐像素对齐、主体与光照相同的黑白底图恢复 RGBA；检测不透明输入及通道不一致；支持边缘收缩、羽化和去底色。用已知 Alpha 的合成对校验恢复及重新合成误差。
- 选区材质：顶部参数和预览框选使用同一原图像素矩形；支持强度和边缘羽化，区域外及原 Alpha 不变。以独立标量公式和真实鼠标拖动验证。
- 素材拆分：网格与八连通透明岛；小碎片归入剩余组，不静默丢弃。每张结果保留原图尺寸和坐标，重新叠合须恢复原图；整批入库、整组入层均一次撤销。
- 所有处理保留原素材、工程未知字段和参数历史；取消或失败不产生半批素材条目；保存后由新进程验证结果字节和参数。

计算代码独立实现。配对使用编码颜色通道上的合成方程，透明岛采用双遍连通标记；没有复制旧应用的处理实现。顶部参数、按钮、浮层、数值输入和弹窗使用共用组件。

## 实现与边界

工作线程分块计算配对与材质；拆分逐张编码并等待存储确认，避免同时持有整批 PNG。单边上限 30000、总像素上限一亿，最多 64 个拆分输出（含碎片组）。结果以一次工程事务提交；原图和第二素材的最小快照保留在处理记录，恢复历史不将运行元数据混入参数。

本批工作线程离开工具页即取消，尚未接入跨页面持久队列；本地 AI 超分/抠图已有持久任务，不应混淆。取消时已经暂存的内容寻址 PNG 可能留为未引用资源，素材库不显示半批结果；后续需要保守的资源回收机制。

配对不是对两次独立生图做自动对齐。通道一致性检测不能证明所有错位、颜色变化均被识别。当前为 8 位 sRGB 处理，不承诺 HDR 或广色域精度。透明岛拆分不等同人物、宠物、道具语义识别。

另修复共用弹窗的安全策略冲突：使用固定弹窗容器，禁用与全局关闭动画一致的过渡；保留严格 CSP，不加入 `unsafe-inline`。隐藏测试窗口需刷新合成帧才能得到当前弹窗截图，未显示或聚焦用户窗口。
