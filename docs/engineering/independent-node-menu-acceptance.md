# 无限画布节点入口修复

旧版双击菜单包含文本生成、图片生成、视频生成、音频参考、全景图、3D 导演台和配置节点。独立版此前仅实现 text/module/recipe/asset 四类节点且缺少双击入口；先前将剩余节点工作描述为尺寸等细节不完整。

## 本批改动及验收

- 共用 Ant Design 节点菜单组件，顶部点击和空白双击均可打开。菜单提供文字提示词、图片生成、引用模块、引用配方、素材库和导入图片；只有可执行操作，没有占位假按钮。
- 双击不缩放、不在已有节点上误触；按画布坐标转换插入；靠近窗口边缘自动避让，Escape/点击外部关闭。引用库内容保留点击位置，Escape 可取消定位。
- 图片生成复用真实配方及现有任务链；新配方和新节点同一次历史提交。可在画布编辑生成提示词，并同步工作台对应配方，其他引用仍按既有版本规则显示更新状态。
- 新节点自动选中。保留既有节点/连线/资源及未知字段，图片导入新增定位调用，其他导入入口保持原调用。
