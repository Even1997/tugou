# 独立版本第四批：图层编辑接入

验收日期：2026-10-22。本批交付独立图层编辑的基础工作流，旧正式程序和完整功能保持可用；不代表全部图片工具已经替换。

## 验收范围

| 目标 | 完成定义与结果 |
| --- | --- |
| 统一编辑入口 | 同窗口“图层合成”；添加、编组/合并、排版、变换、选区、蒙版、导出集中在顶部；左右素材和图层属性沿用统一主题，960px可操作 |
| 图层与排版 | 图片、文字、矩形/椭圆/直线；复制/删除、层序、显示/锁定、编组/取消编组、相邻顶层合并；移动/缩放/旋转/翻转/倾斜、四角透视、对齐/等距、网格/参考线吸附 |
| 可编辑内容 | 文字换行、字体/字形/字号、行距/字距/对齐；形状描边/圆角/渐变；修改后保留数据，撤销恢复 |
| 选区与蒙版 | 矩形/椭圆/套索，添加/减去/相交/反选；选区转蒙版、反相/羽化/启停、剪贴；兼容既有位图和锚定/来源蒙版渲染。裁切按普通/相加选区包围盒调整画布，不删除原图 |
| 合成与导出 | 原图而非缩略图参与合成；16种标准混合、分组透明度隔离、PNG透明/原尺寸导出；分块渲染、进度/取消、原子写入用户选择的目标 |
| 数据保留 | 原工程只读导入，未知字段和原素材保留；合并生成新素材，撤销恢复可编辑层；保存重启后全文档一致，渲染像素一致 |

独立实现分为 `app/core/layers.cjs`（几何与数据操作）、`app/renderer/composite.js`（合成）、`app/renderer/layers.jsx`（交互与属性组件）。不导入旧 Web/Go 的运行代码。既有模块、配方、画布、任务和素材仍使用同一个工程存储与历史。

## 验证证据

证据位于 `app/test-results/`，包含个人创作的测试快照仅留本机。

- `npm test`：44/44，包括9项图层几何、锁定、分组、透视、裁切和吸附测试。
- `layers-desktop.json`：28项真实 Electron 操作/合成验证通过，控制台错误0。原生指针验证移动、缩放、旋转、透视及参考线拖动；保存、撤销、合并、裁切、导入与PNG导出通过。
- `layers-restart.json`：独立进程重启，9层、5素材、蒙版/透视/参考线和全部文档字段一致；256×384合成对照最大通道误差0。
- 原蓝白请柬1024×1536合成，与独立Canvas2D基准全像素对照最大误差1/255；合并前后最大误差1/255。
- 1600×300羽化蒙版/文字分块导出对照：Alpha误差0，最大颜色通道误差1/255；预乘颜色最大误差0.4/255。修复了冷启动与读回后Canvas2D切换采样路径造成的预览差异：2D表面使用一致的CPU采样，透视仍用WebGL。
- 4096×4096纯色图形PNG导出实测684ms、332296字节；导出前取消及首块完成后取消均通过。这不是复杂照片性能基准，也不是100MP峰值证明。
- 本轮采样进程工作集约697MiB（含浏览器/GPU/渲染/工具进程，非峰值）；缩放预览仅渲染可见区域。
- `workflow-desktop.json`17项、`desktop-smoke.json`18项、`generation-desktop.json`10项原流程回归通过；`desktop-restart.json`及`generation-restart.json`通过。生图回归使用本地模拟接口，本次未增加收费请求。
- `import-existing.json`：2份原工程只读导入、18份源文件哈希检查通过；实际独立目录2个工程/3个画布的原始字段再次与正式源文件比较一致。
- `source-boundary.json`：21个实现/构建文件导入边界、63项锁文件许可元数据检查通过。构建通过；截图`layers-legacy.png`、`layers-editor-960.png`已目视检查。
- 导出IPC拒绝未知/撤销的目标令牌和无效PNG；沿用主进程校验、资源哈希、受控文件路径和密钥隔离。

## 保留范围与后续

- 高级选区（魔棒/颜色范围/像素编辑）、独立蒙版变换面板、层级拖放/标尺、自定义混合、画笔修图、调整/特效及图片工具仍待分批替换。旧数据保留；遇到尚未支持的调整/特效/混合时提示并禁止PNG导出，不能将省略效果的预览误认为最终成品。
- 合并目前针对相邻顶层、正常混合且未剪贴的层/组；外部蒙版或剪贴关联会明确阻止，避免改变外观。带组透明度/蒙版的取消编组同样阻止；可使用合并保留外观。
- 导出上限是单边32767/总计100MP，素材文件当前64MiB；复杂100MP、多层长时间编辑、跨设备字体/DPI仍需进一步测试。CPU采样优先保证预览稳定，需要在后续大图基准中继续优化性能。
- 独立开发入口已构建更新。当前已有独立预览进程没有可正常关闭的主窗口句柄，因此未强制结束；正常关闭并从`app/启动图构.cmd`重开后加载本批。正式旧程序、原授权及最终打包范围不变。
