# v0.8.11 发布验收

范围见[版本说明](../releases/v0.8.11.md)：GIF 制作、显示、拖入合成、滑动选帧和 PNG / GIF 导出，以及菜单精简、API 连接菜单对齐和画布平移修复。

完成定义：版本文件与源码标签一致，Windows x64 与 Mac arm64 / x64 包体可启动；新 GIF 流程通过包内检查；附件摘要和三平台更新发现一致后公开稳定版本。

实现阶段已有全量逻辑 451 项通过、1 项平台条件跳过；GIF 桌面 20 项、PNG 导出 26 项通过。上述结果不替代本次安装包验证，发布结果随后补充。
