## 默认框选与快捷分组补充

验收目标：空白区普通拖动框选且视口不动，按住空格拖动平移且节点坐标不变，松开空格恢复框选；Ctrl+G 创建组并选中新组，输入框内不触发，组可整体移动、保存及撤销。主要风险为焦点丢失导致快捷键失效、误改输入和拖动位置未持久化。

复用 React Flow 的 `selectionOnDrag`、`panOnDrag={false}`、`panActivationKeyCode="Space"`，不增加全局空格监听或依赖。点击画布非控件区域时聚焦工作区，使框选后可直接使用快捷键；编辑控件保持自己的焦点。菜单和快捷键共用现有 `groupNodes`，新组自动选中，继续限制为至少两个未分组节点。

专项脚本 `app/test/workflow-interactions-desktop.cjs` 新增 9 项检查：普通框选、视口保持、框选整体拖动持久化、输入时不分组、Ctrl+G 创建并选组、组整体移动、撤销恢复、空格平移和松开恢复。源码与 Windows 包内各 35 项通过，报告无渲染错误且更新时间已验证；分组截图 `box-selection-group.png` 已查看。报告为 `interactions.json`、`packaged-interactions.json`。历史 32 项生成回归没有在本补充批次重复运行，不计入本批验证数量。
