# 独立画布节点能力验收

本批按旧画布的节点类型、参数和交互补齐可运行链路，不再仅恢复菜单。真实供应商生成由用户自行验收；本机测试不使用真实密钥、不提交收费请求。Agent 未补发。构建、缓存、测试和候选包均位于 F 盘项目内。

## 完成定义与核对

每项须同时验证入口、编辑/连接、实际操作、结果入库及保存重开；媒体须可播放，截图须为真实渲染，取消不能发布半成品。真实模型效果、供应商特殊协议、Mac 实机不以夹具替代。

| 旧版能力 | 当前独立实现 | 验证 |
| --- | --- | --- |
| 双击/顶部添加 | 共用 13 项组件菜单，坐标/缩放定位、边缘避让、Escape、撤销重做 | 节点菜单 22 项 |
| 文本生成 | Chat Completions / Responses、图片输入、结果编辑和复制、继续作为上游文字 | 任务协议、桌面结果与剪贴板 |
| 图片生成 | 独立提示词、模型/尺寸/质量、1–15 张、参考顺序/职责、主引用结果 | 请求数量、双结果入库、顶部图片工具、替换与多角度核心测试 |
| 视频生成 | JSON / multipart / Sora 通道，图/视频/音频输入、首尾帧、时长、扩展参数、异步任务进度 | 三种请求格式、受保护模型字段、轮询结果、原生播放 |

生成结果节点直接复用顶部裁剪、放大、抠图、替换、提示词、反推与多角度入口。处理结果保留原文件；分组中的生成结果按绝对画布坐标放置。既有图片替换、图层排版、素材流转和配方回归继续通过。

## 交付与边界

- Windows 候选：`app/release/win-unpacked/Tugou.exe`；根目录 `启动图构预览.cmd` 使用独立的 `app/preview-data` 数据目录。预览数据留在 F 盘，原窗口/原数据不覆盖，不建立旧新版同步。
- 用户自行填写共享模型连接并验证真实效果。当前实现面向上述兼容协议，不承诺任意供应商的私有视频接口自动适配；Sora 通道不接受多图、尾帧或音频参考，提交前明确报错。
- 文本目前完整响应后显示，未实现逐字流式输出。语音生成是文字转语音；上传音频作为视频参考，不承诺声音克隆。
- 角色姿势编辑当前针对内置角色。复杂 FBX 骨骼重定向、任意外部贴图资源集及旧导演台全部专业细节未声明等价；本机已验 OBJ，FBX 复杂样本与 12 方位/4K 长时录制仍需专项样本验收。
- 媒体截取使用本机实时编码，非无损帧精确剪辑；默认上限为 256 MiB 媒体、64 MiB 模型，避免无限制分配内存。未再次执行本批无关的 100MP 全套负载测试。
- Mac 实机、复杂模型/长视频、真实模型画质与正式安装发布单独待验。此次不称整个旧版平台已全面等价。
