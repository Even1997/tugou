# 供应商单页多 Key 验收

本轮按用户修正落实「一个供应商 → 一个 URL → 多个 Key」，供应商、URL 和 Key 在同一页管理。后端拒绝同供应商包含多个 URL，默认选择不再展示接口层级。

## 交付行为

- 左侧供应商列表；右侧同页编辑供应商名称、唯一 URL 与多条 Key，一个供应商只对应一个 URL。
- Key 独立测试、获取和管理模型；保存过的密钥不回传明文，空白输入保留该 Key 的原密钥。
- 获取模型不自动视为可用模型：从列表选择或手填 ID，按供应商说明设置图片／视觉／文本／视频／语音用途。
- 默认模型按用途选择完整的供应商／Key／模型组合。不自动轮换 Key，不为未设置的用途隐式回退。
- 修改 URL 或 Key 清除关联模型与默认用途，并提示重新获取。删除模型、Key 或供应商提示受影响用途。
- 全部修改都是草稿；保存统一生效，取消不修改加密配置。旧连接仅在读取时组织成供应商视图，打开窗口不写文件。
