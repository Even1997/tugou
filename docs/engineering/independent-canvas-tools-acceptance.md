# 画布与素材库图片处理联动验收

本批补齐旧画布的图片处理入口，复用独立版现有工具、参数组件、模型连接和持久任务。用户当前窗口未操作，正式桌面未更新；全部验证使用隔离构建、D:/TugouIndependentQA 数据目录和隐藏窗口。

## 验收目标与完成范围

| 目标 | 结果与验证 |
| --- | --- |
| 在当前画布处理选中的原图 | 顶部直接显示裁剪、放大；图片工具菜单接入 AI 超分、主体抠图、局部修改、切图及全部工具。打开共用弹窗，画布仍保留在当前页面 |
| 素材库共用同一处理流程 | 详情“处理图片”、顶部“处理所选”；准确带入素材，原图不变，无另建模型配置 |
| 多选批量无需重新找素材 | 去掉重复引用同一素材的节点，忽略文字等非图片节点；带入批量确认，允许再调整选择。单次 1–64 张，云端仍按现有单图规则提交 |
| 结果方便回到画布 | 单张及本组结果加入画布；画布来源的结果放在来源节点旁，竖图也不重叠。整组插入一次撤销，原节点、未知字段及视图保留 |
| 状态、关闭、取消和恢复可靠 | 关闭处理弹窗后本地任务继续，共用轮询将结果入库；弹窗内可取消云端任务，迟到返回不发布；重启不重新发请求 |

`ImageTools` 和 `ToolBatchDialog` 增加初始来源选择，处理实现没有复制一套。App 统一管理弹窗与结果节点插入，画布/素材库仅提供入口。移除选择器里已经失效的“云端增强／创意放大迁入中”禁用占位，实际已实现工具正常可选。仅增加处理弹窗长素材名省略规则，没有新增 CSS 文件。
