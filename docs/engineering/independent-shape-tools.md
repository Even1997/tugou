# 形状工具与合成性能验收

顶部新增六种可拖拽绘制的形状，支持 Shift 等比、Esc 取消、一次撤销、跨画板归属和锁定保护；顶部直接编辑填充/描边/圆角，图层显示形状缩略图。合并预览重绘，减少离屏图层临时表面分配。198 项逻辑测试、源码与 Windows 包内各 135 项桌面检查通过；已更新实际 dist 和原启动入口，旧运行包与工程保留。

## 范围与使用

- 顶部「形状」菜单：矩形、圆角矩形、圆形/椭圆、三角形、菱形、星形。快捷键 U；拖拽绘制、Shift 等比、Esc 取消，极小点击不创建图层。
- 拖动使用 SVG 预览并显示宽高，松手后一次写入；支持一次撤销、重做和保存重开。
- 可直接在相邻画板绘制，保存为该画板局部坐标。锁定画板拒绝创建；修正锁定画板子图层的属性/不透明度控件禁用状态。
- 绘制前及选中形状后可从顶部编辑填充、无填充、描边和圆角。右侧尺寸/旋转/翻转、渐变和现有图层功能保留；图层树显示形状缩略图。
- 延续旧「更多」菜单中的直线插入；没有增加矢量节点编辑/布尔运算。

## 性能与正确性

预览请求由 requestAnimationFrame 合并，过期请求取消。绘制形状时不修改文档，最终松手才触发文档合成。离屏/隐藏节点在分配大尺寸表面之前判断，透明裁剪基底只需1×1表面。同时修正未裁切画板在屏幕外时，其屏幕内溢出子图层被跳过的问题。

基准：相同121个形状图层，其中120个在屏幕外，1200×800视口，各5次渲染的中位数；比较本轮修改前冻结的合成器与新合成器。此结果不外推为所有操作或大图片场景的加速倍数。

| 指标 | 修改前 | 修改后 |
|---|---:|---:|
| 包内中位耗时 | 180.6 ms | 4.8 ms |
| 每帧临时像素分配量 | 117,160,000 | 1,960,000 |
| 分配量变化 | — | 减少 98.3% |

分配量统计 Canvas 宽高设置产生的表面像素总量，**不是进程峰值内存**。同场景输出逐像素一致。离屏裁剪基底、引用蒙版、裁剪调整层、羽化与混合也与旧合成器逐像素一致。六种形状 PNG 导出与预览像素相同。
