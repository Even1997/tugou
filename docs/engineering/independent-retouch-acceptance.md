# 独立修图工具验收

本批按旧版行为接入仿制图章、修复、模糊、涂抹和液化，并热更新当前独立桌面。完整复刻仍未完成；下一项是内容感知填充，随后调整图层与特效。Windows 本批有实际证据，不能外推为 macOS 真机通过。

## 完成定义与行为

五种工具必须能从统一顶部入口操作，对当前图片图层原尺寸像素生效，遵守选区/锁定/变换；保留源素材及未知字段，一笔可撤销、重做、取消，保存与导出后像素相同。

| 工具 | 当前实现 |
| --- | --- |
| 仿制图章 | Alt 点击或“设置来源”取样；每笔读取开始时的图像，重叠采样不反馈；跨笔对齐可关闭；强度不随同笔重叠次数增加 |
| 修复 | 无指定来源时搜索附近纹理；也可手动取样；按边界颜色均值校正来源亮度，保留目标 Alpha |
| 模糊 | 局部高斯模糊，顶部可调半径；同一笔按强度合成，下一笔继续柔化；透明边缘保持预乘颜色语义 |
| 涂抹 | 沿拖动路径采样已处理图层的邻近颜色并混合，支持大小、硬度、强度与压力输入 |
| 液化 | 圆形渐弱的推移形变，按拖动方向反向映射并双线性采样；未加入膨胀、收缩、旋转或可重调形变网格 |

- 复用现有 `PaintTools`、`NumberField`、`ToolPopover` 和笔触事务。工具选择器、来源按钮、来源十字及按变换显示的笔刷范围已接入。未增加独立侧面参数体系。
- 异步逐段处理队列；像素循环按行让出执行，来源搜索按候选让出执行。取消、切换工程/工具及文档变化不会让旧笔触覆盖新修改。
- 一张工作输出图加局部像素缓冲，固定来源使用源图片，覆盖强度按需记录分块；没有逐点复制完整大图。选区仍需额外蒙版。
- 修正修图提示造成画布位置跳变：信息改为画布浮层；成功取样不插入额外信息行。窗口尺寸变化时保持视野中心，当前缩放不变。

### 100MP 测量

40px 笔刷，两点局部路径；本机本次测量，非长时多层性能结论。

| 工具 | 准备 ms | 笔触 ms | PNG 编码与入库 ms |
| --- | ---: | ---: | ---: |
| 仿制 | 120 | 259 | 472 |
| 修复 | 124 | 65 | 512 |
| 模糊 | 115 | 67 | 498 |
| 涂抹 | 127 | 54 | 453 |
| 液化 | 117 | 55 | 773 |

算法工作表面/覆盖块/峰值局部缓冲估算约400–401MB，不包含图像解码、PNG、GPU、浏览器或历史。真实进程峰值在报告中，各进程峰值不是同一时刻，不能直接相加称为同时总峰值。1000px 模糊计算取消样例约56ms；不据此保证所有设备、笔刷大小或原生输入的响应时间。

## 限制与后续验收

- 当前从同一图片图层取样，不含跨图层合成取样。文字/形状使用已有合并图片流程。
- 修复是邻近纹理与边界颜色校正，适合局部瑕疵；复杂纹理、渐变、发丝、人像和大面积去物体不能据几何样图保证效果。自动来源不足会给出提示，可改手动来源。内容感知填充另行实现。
- 本批Mac路径与Canvas/输入机制没有专属Windows依赖，但Mac构建、Option输入、Retina、实体绘图板尚未实际验证。
- 长时间多笔、多层100MP、低内存、触控和完整辅助技术仍待。当前运算分段执行于渲染线程，未迁入Worker/GPU专用计算。
- 本批更新运行中的独立桌面构建；完整NSIS/DMG正式安装和签名公证仍按总计划验收。
