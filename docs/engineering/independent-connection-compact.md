# 模型连接精简版验收

## 范围与行为

- 一个共享连接弹窗：地址、密钥、常用图片／视觉模型；文本、视频、语音及协议收进更多设置。
- 最新用户意见覆盖之前设计：没有逐模型测试按钮、计费测试提示或生成调用。
- 测试连接和拉取模型均 GET `{base}/v1/models`（已带 `/v1` 时不重复追加）。测试只展示可达情况、耗时；拉取更新候选列表，不改已选模型。列表成功不代表模型生成能力已经验证。
- 当前 Key 非空使用草稿；留空使用已保存 Key。测试／拉取不写配置文件，取消保留原配置。地址、Key、清除密钥选项变化会清掉旧反馈和候选，丢弃旧请求响应。
- 不支持模型列表的服务可手动输入 ID。模型 ID 不自动推断用途，用户按服务商说明选择。
- 保留本机加密保存；移除界面旧版连接导入和 preload／IPC 入口。已有独立迁移脚本仍使用的内部迁移函数未删除。

## 验收标准与证据

1. 当前地址／Key 确实进入 HTTP 请求，未保存配置和已保存密钥互不覆盖；源码自动化断言。
2. API 错误、无列表、超时和格式异常提供可操作提示；拒绝远程 HTTP、携密 URL、跟随重定向，不返回服务端原始错误正文。
3. 实际 Electron 界面验证模型搜索、点击选择、键盘选择、Esc、手填、保存重开、取消、大列表与小窗口，包内同样检查。
4. 源码构建、ASAR 文件哈希、原工程 JSON 不变检查通过，才更新预览入口。

结果：Node 全量 217 项通过；Windows ASAR 桌面检查 27 项通过，无 renderer error。5000 模型使用虚拟滚动，实际列表 DOM 少于 80 个；检查窗口包含 1380×900、940×640 和明暗主题。

证据：`app/test-results/connection-compact/` 下 `unit-tests.txt`、`source.json`、`packaged.json`、界面 PNG、`live.json`、`delivery.json`。14 个代码／构建文件与 ASAR 哈希一致，交付时 21 个原工程 JSON 哈希未变。启动脚本指向独立 `release/connection-compact` 包，未关闭或重启用户原窗口。

真实服务商检查：当前 `preview-data/workspace` 没有配置好的地址和 Key，因此跳过真实外部请求。成功／失败网络验收使用本机隔离 HTTP 服务与测试密钥，不能视为某个真实供应商已兼容。

组件参考：[Ant Design AutoComplete 官方文档](https://ant.design/components/auto-complete/)，复用项目主题与已有 Ant Design 依赖。
