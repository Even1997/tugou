# 独立实现第一批：本地底座验收

## 范围与当前状态

已在 `app/` 建立可独立运行的 Electron / React 入口，不导入旧 Web、Go 服务和原画布实现。此次为本地底座与基础模块编辑，尚不是全功能替代版，正式桌面包未替换。旧版功能及数据保留可用。

已实现：独立数据目录、工程新建/保存/重开、只读旧工程导入、资源校验、模块编辑与全局开关、素材缩略图、统一顶部工具栏、无边框窗口控制、共享模型连接、旧凭据隔离迁移；后台串行任务记录支持取消、迟到结果丢弃和重启中断保护，暂未接入实际生图任务。

现有配方、图层、蒙版、选区、工具参数和未知字段原样保存，不据此宣称编辑能力已经重写。旧画布项目关联明确标记待迁移；独立画布内容仍在旧数据中。

本次发现并修复：连接错误被模态框遮挡、恢复工程没有可保存状态、重复关闭弹窗、跨 profile 凭据直接解密失败。迁移改为使用独立临时 profile 及系统 API，明文仅在主进程与迁移进程 IPC 中传递，不打印、不写明文文件。

系统加密能力使用 [Electron safeStorage](https://www.electronjs.org/zh/docs/latest/api/safe-storage)，实际同账户旧配置迁移以上述本机试验为准，不承诺跨账户或跨机器复制可解密。
