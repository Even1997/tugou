# 蒙版选区黑白编辑

## 行为

蒙版目标独立于当前工具；切换选区工具不再退出蒙版属性面板。MaskInk 为画笔与选区共用的黑色隐藏 / 白色恢复按钮。填充选区写入当前蒙版 bitmap，不创建图像图层，不改动原图。下方操作条保留取消选区 / 完成蒙版。

paint-target.js 共享世界选区到蒙版坐标的投影，复用于画笔和填充。支持普通、旋转、透视、偏移及反相蒙版，保留羽化与浓度；无选区、锁定/隐藏图层、停用蒙版拒绝填充。存储完成前验证工程快照，取消或期间改动不会覆盖新状态。蒙版模式阻止直接运行写图像像素的修图工具。
