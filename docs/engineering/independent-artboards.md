# 合成工作区与多画板验收

2026-10-24，按已确认的 FigCraft 精修工作台版式交付实际 React/Electron 项目。状态：合格、可交付。

## 实际行为

- 左侧保留系统导航；编辑工具横排置顶，工具参数独立一行。右侧为属性和带缩略图的图层树，素材库按需展开。
- 同一个无限工作区显示多个画板。支持预设/自定义尺寸、名称、背景、透明背景、边界裁切、复制、删除、标题拖动、右下角拖拽改尺寸；Shift 拖角保持比例。修改尺寸可选择同时缩放内容，尺寸改变时清除旧选区。
- 点击画板、下拉列表或图层树切换编辑；“所有画板”适应全景，“聚焦画板”适应当前画板。空格拖拽平移，Ctrl/⌘+滚轮缩放。
- 图片、文字、形状、组、选区、画笔、橡皮、修图、调整和图层效果沿用原编辑能力；增加 Ctrl/⌘+G 分组、Ctrl/⌘+Shift+G 拆组。图层可拖入另一画板，或通过“所属画板”移动，保持原画板内相对位置。
- 图片上下文按钮提供替换、编辑蒙版和完成蒙版。蒙版可隐藏/恢复、调整浓度、羽化、反相或停用；图层树显示独立蒙版缩略图。
- 保存、撤销/重做、重开以及 PNG 导出已接入。导出只输出当前画板的准确尺寸，可选透明底，不包含相邻画板。

## 数据与边界

画板保存为 `kind: group, artboard: true` 的顶层容器。每个画板保存自己的尺寸、背景、选区和参考线。旧工程在内存中包入首个画板，只有用户修改并保存时才写入新结构。

编辑器使用当前画板的本地坐标，预览再组合全部画板。跨画板转换同步处理世界坐标蒙版；既有选择、画笔和像素算法不依赖无限工作区的巨大总尺寸。画板不允许嵌套或旋转，最多单边 30000、总计一亿像素。带外部蒙版关联的图层必须一起移动，避免破坏引用。
