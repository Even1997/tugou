# 独立选区映射、云端批量与配方细节验收

本批开发及隔离验收通过；整体目标仍未完成，正式桌面未更新。用户当前窗口未操作，Agent 未补发。新增构建、截图、测试资料及候选包均位于 D:/TugouIndependentQA，复用 shared-build 和 lean-package，不复制多份 Electron。

## 验收口径与实现

| 项目 | 完成定义 | 实际验证 |
| --- | --- | --- |
| 选区映射 | 明确选择来源图层，将画布选区映射到原图像素，保留软边/减选，画布外保护；读取快照不改原选区 | 平移、旋转、缩放、翻转、斜切、父组、透视像素测试；实际旋转缩放选区及减选孔洞；云端合成保护像素验证 |
| 云端批量 | 1–64 张去重，整批预检查后逐张排队；各项独立失败/审阅/取消，手动重试；重启不自动请求 | 本地 HTTP 模型夹具验证请求数量、取消队列、失败继续、尺寸错误审阅、离线合成、重启；结果携带批次顺序，整组入画布一次撤销 |
| 配方细节 | 补齐旧版参考图缩略图、上下排序、职责预设及自由输入；保存、画布引用一致 | 七类职责建议、12 张添加上限；重排和自定义职责保存恢复，送入画布保留参考顺序、全局模块快照 |
| UI 与数据 | 共用组件/顶部工具，原数据及未知字段保留，当前窗口不动 | 深浅主题及 960px 布局检查；正式构建和用户工作区 27 个基线文件 SHA256 不变 |

选区读取复用现有选区渲染（矢量/位图、加减交、反转、羽化），映射计算在 Worker 中执行，按原图像素中心双线性采样；卸载时终止 Worker。来源素材对应多个图层时必须明确选一个。带独立笔刷位图的图层不冒充原素材，需先保存该编辑版本为素材。映射的是画面选区几何，不包含图层不透明度、特效或遮挡关系。

云端批量沿用共享持久队列和模型连接，没有新增自动重试服务。不同来源共用当前数值参数，不按比例猜测局部区域；蒙版须与每张图片等大。批量成功结果逐项入库，整组回填画布可一次撤销；失败项保留任务记录，用户主动点击才会重试。类别拆分沿用已有按类别方案提交入口。

配方只补旧版可见行为，不增加虚构模板库；继续保留现有自定义大尺寸、模块版本/冲突处理及已保存的所有参考图。
