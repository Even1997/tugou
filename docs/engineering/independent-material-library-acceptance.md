# 素材库筛选、流转与图层替换验收

本批补齐素材库来源/比例筛选、自然名称/加入顺序/像素排序、素材拖放流转和替换当前图片图层。保留统一顶部操作及共享替换弹窗；未操作用户当前窗口，未覆盖正式构建。

## 完成标准与证据

| 标准 | 验证结果 |
| --- | --- |
| 筛选与排序不改工程内容 | 查询、来源、横竖方图可组合；最近/最早加入、名称、像素排序仅作用于视图；空结果与重置可用，原素材顺序不变 |
| 替换沿用既有排版 | 保留宽度、旋转、缩放、翻转、透视、分组、蒙版、特效和未知字段，按新比例改变高度并保持四角中心；原素材保留 |
| 替换不能丢失笔刷结果 | 替换前的图层 bitmap 作为素材保留，带图层来源标记；单次撤销同时恢复旧图层及旧素材列表，重做一致 |
| 同一选择跨工作区可用 | 图层选择保持到素材库，选一张素材从顶部替换；图层顶部使用共用替换弹窗；所属分组锁定时两个入口均禁止修改 |
| 素材拖放共享引用 | 素材可拖入图层、画布，悬停顶部工作区切换后继续落点；当前工程编号随拖放携带，不接受其他工程素材引用；已有模块拖放回归通过 |
| 实际结果正确 | 100×100 渲染全部 RGBA 像素与新比例、原蒙版的明确期望完全一致；撤销后的像素与笔刷原稿完全相同 |
| 可恢复且不触碰正式环境 | 单次撤销/重做、保存、新进程恢复通过；正式构建与工作区原有 27 个文件哈希未变，无模型请求 |

## 验证记录

路径相对于 `app/test-results/`：

- `material-library-unit.log`：144/144 逻辑测试通过，新增筛选排序、复杂变换替换、锁定/过期目标等 3 项。
- `material-library-desktop.json`：24 项隐藏桌面检查，包含实际渲染逐像素校验、素材库/图层两入口、模块拖放回归、深浅主题和窄窗口。
- `material-library-restart.json`：6 项新进程恢复检查。
- `canvas-media-desktop.json`：30 项上一批图片替换、原提示词、复制、反推及审阅入画布回归。
- `canvas-tools-desktop.json`：25 项图片工具回归；`cloud-mask-desktop.json`：15 项图层选区/蒙版/共享请求回归。以上合计 100 项桌面与恢复检查。
- `material-library-dark-960.png` / `material-library-light-960.png`：已视觉检查，筛选排序收入顶部浮层，工具栏允许换行。新增全局 CSS 仅一条工具栏换行声明。
- `material-sort-before.json` / `material-sort-performance.json`：一万条乱序名称排序从约 700ms 降至五次测量中位数约 20ms，通过复用标准 `Intl.Collator`，没有改数据顺序或另建索引系统。这是纯排序性能，不代表一万张缩略图的整页渲染。
- `source-boundary.json`：89 个实现文件、433 条依赖许可记录检查；`material-library-production-protection.json`：27 个正式文件哈希一致。

拖放证据为 Electron 隔离页面中真实组件的 `dragstart`、工作区悬停、`drop` 事件与保存结果验证。没有用此替代操作系统文件拖入、实体鼠标跨窗口拖拽或 Mac 原生行为验收。新增测试位于 D:/TugouIndependentQA；既有蒙版回归使用独立临时目录。所有测试窗口禁止显示和聚焦，用户当前窗口不受操作。
