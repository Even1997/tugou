# 生成尺寸与质量选择项

完成标准：节点参数弹窗和侧栏使用相同选项；数量继续使用数字输入；选择结果可保存、重载并进入模型请求；继承上游参数时显示实际值并禁用本地选择；既有自定义值保留。主要风险是显示值与请求值不一致、继承参数被误改、更新时中断用户任务。

采用共享 `GenerationChoice` 组件，沿用现有主题下的 select 与 Input，无新增依赖或全局 CSS。图片提供自动、横竖及 2K/4K 预设，视频提供常用横竖分辨率；尺寸保留自定义入口。质量展示自动、低、中、高、标准、高清，保存原始 API 值；已有非预设质量作为当前值保留。全景的固定 2:1 尺寸维持只读。预设不是模型能力声明，真实供应商支持范围仍需实际连接确认。
