# 图片保存入口与目录记忆

范围：画布图片节点／生成结果、素材库及详情、合成画板的本地保存。

## 行为与完成定义

- 图片节点和素材卡片右键“保存图片…”，也可点击保存按钮；使用系统保存对话框选择目录和文件名。
- 原素材调用现有 `exportAsset`，保存已校验的原文件，保持原始格式、像素及字节；合成单张、批量画板继续按实际尺寸输出无损 PNG。
- `exportAsset`、`chooseExport` 和 `writeExport` 共用应用数据目录内的 `image-export.json`。只有成功写入后才记录目录，不放入工程、不改变撤销或未保存状态。
- 重启后读取上次目录；目录不存在或记录损坏时退回系统图片目录。系统无法提供图片目录时退回用户主目录。
- 取消保存和失败不更新目录；单张覆盖确认交给系统弹窗，批量沿用同名自动编号、不覆盖行为。

## 验证

本次 Windows 共 51 项通过：3 项逻辑、16 项跨页面保存、3 项独立进程重开、29 项现有画板保存回归；桌面报告无渲染错误。已查看画布和素材库菜单截图，菜单与保存按钮沿用现有主题。系统目录无法获取的问题在实测中复现并加入主目录回退。

逻辑测试：`node --test test/image-export.test.cjs`，覆盖目录恢复、失效回退、安全名称及批量覆盖保护。

桌面测试：先以 `TUGOU_BUILD_DIR=test-results/image-save/dist` 构建隔离前端，再运行 `electron test/image-save-desktop.cjs` 和 `electron test/image-save-desktop.cjs --reopen`。真实界面／IPC／文件写入，自动选择本地保存对话框返回值，检查原图字节、跨页面目录、取消／失败、原尺寸及透明度、未保存内容与历史、独立进程重开。证据位于 `app/test-results/image-save/`。

现有 `test/board-export-desktop.cjs` 回归批量画板、原始尺寸、取消、失败重试及历史保护。发布阶段已在 Mac 两架构安装包补验 16 项保存和 3 项独立进程重开，见[v0.8.10 发布验收](release-v0.8.10.md)；系统原生弹窗的手动选目录及覆盖确认仍需用户确认。
