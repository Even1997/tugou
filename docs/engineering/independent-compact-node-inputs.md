# 引用方块与画布排列验收

## 交付行为

- 生成台引用统一为 72 × 72 的圆角正方形，图片保留完整比例；文本仅显示“文本”，悬停可读完整内容，点击定位原节点。
- 引用自动换行，最多显示约两行后滚动。悬停或键盘聚焦显示排序、移除操作；支持拖动和四个方向键调整顺序。
- 选中节点后，通过“整理选中节点 → 按连接整理”按上游到下游排列，同层错列放置。只移动选中节点，整组视为一个对象，保留连线、引用顺序及组内坐标，支持一次撤销和保存恢复。
- 原画布文本节点继续显示正文；既有工程不自动重排。新预览包独立保存，原启动入口已切换并打开新版。
