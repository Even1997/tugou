# 独立本地图像工具验收

## 范围与交付约束

本批接入透明边缘、Cube LUT调色、局部打光、重复图案。共用顶部参数组件、原图/结果对照和共享素材库；处理记录恢复参数，结果可加入图层/无限画布或导出PNG。原素材不覆盖，工程未知字段保留。

用户要求暂不操作当前窗口，后续功能完成后再统一更新。构建输出为 `app/test-results/local-tools-build/`；测试使用独立数据目录，测试窗口不显示、不聚焦。没有热更新、安装或旧版/新版同步。

完成定义：真实组件操作可用，处理/取消/撤销/保存重开有证据，透明与色彩像素可复核，960px与双主题可读，100MP不缩图。未满足的完整产品要求仍留在差异清单。

## 实现和边界

- 透明边缘：灰度收缩、内侧羽化、去白/黑底色。收缩不把半透明Alpha二值化；羽化不能补回已收缩部分；默认不去底色。只处理现有Alpha，不等同主体识别或自动精细抠图。
- LUT：独立1D 2–65536点、3D 2–65点；支持DOMAIN、线性/三线性插值、强度、非法文件拒绝、导入去重。LUT文本在工程中只保存一份，结果保存预设ID。根据Adobe Cube 1.0格式独立实现，红索引变化最快；[规范文档](https://kono.phpage.fr/images/a/a1/Adobe-cube-lut-specification-1.0.pdf)。不支持混合1D+3D或Resolve扩展字段，遇到时明确报错。
- 局部打光：在线性RGB中应用二维平滑曝光场，可调光型、颜色、位置、半径和方向；Alpha与作用范围外像素保留。不是AI深度重打光；正曝光会裁剪超过当前8位输出范围的亮部。
- 图案：重复、镜像、隔列错位；自定义输出尺寸、倍率和透明间距。小重复单元使用CanvasPattern，大单元直接绘制以避免额外巨幅纹理；不补画无缝接缝。
- 计算在Worker执行，按512px取样块处理边缘/LUT/打光；边缘保留邻域，避免接缝。取消终止Worker，离页不延迟写入其他工程。持久后台任务与批量仍在后续范围。
- 单边30000、总量1亿像素；8位sRGB PNG，单素材64MiB。没有宣称HDR/RAW/ICC或专业印刷工作流已完成。

512px分块与整图算法的Alpha完全一致；RGB只在半透明量化范围内允许误差（Alpha≥32时≤8级），零参数处理全部像素一致。图案三种排列逐像素对照，结果导出的PNG与资源文件字节相同。实际查看深浅主题与960px截图；结果标题显示对应操作，避免把历史输出误认为当前参数的新预览。

100MP透明边缘约6.46秒、局部打光约13.62秒、1D LUT约4.67秒；图案耗时见报告。计时含加载/处理/PNG编码，不含样图准备、结果入库与后续解码。样本是大面积色块/孔洞、2×2重复单元，不能推广为复杂照片或高熵PNG性能。25ms渲染器心跳最大间隔约311ms；Tab峰值约1.39GiB、GPU约1.09GiB，峰值不同步、不应直接相加。未做长时间/低内存证明。

首次大图检查发现 `Image.decode()` 的EncodingError，改为与合成器一致的onload加载后通过；收缩后羽化恢复边缘的问题已修复并增加断言。图案大图初始测试把透明间距误判为不透明，修正几何采样预期后通过，未因此改动产品像素逻辑。
