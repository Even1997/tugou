# 独立内容感知填充验收

## 范围与完成定义

按旧版行为规格补齐当前图片的选区纹理填充，独立实现，不导入旧产品代码。完成标准：顶部入口、局部计算、有效来源校验、羽化与变换定位正确；计算可取消且不覆盖后续编辑；一次撤销、保存/导出/新进程恢复一致；旧工程、原图和未知字段保留。

本批 Windows 局部填充可进入评审。完整复刻、macOS 实机和正式安装包仍未完成。

## 实现与修复

- `app/core/content-fill.cjs`：连续纹理块优先，多尺度匹配、邻域传播与随机搜索；仅从未选中且不透明的原图区域取样；边界色差扩散后按选区 alpha 一次混合，不用均值颜色抹平纹理。
- 粗采样曾将相差一像素的棋盘格误判为相同纹理；新增全部边界像素复核，羽化回归的最大通道误差约0.494/255，恢复正确相位。
- `renderer/content-fill.js` 与 Worker：分块读取世界坐标选区，映射至图层原图局部范围；支持矢量/位图选区、反选、羽化、旋转和透视。普通变换使用 Canvas2D，透视复用现有投影。
- 100MP 原图仍按原尺寸保存，选区与周围取样范围最多4MP；超过、没有来源、全部选中、隐藏/锁定等情况明确报错。
- 顶部“修图”和“选区”共用入口；固定参数行显示进度/取消。取消按钮、Esc、离开编辑器或工程变化会中止 Worker，保存前后再次核对源工程。只增加图层位图修订，原素材不改。
- 构建包含独立 Worker；没有新增依赖、网络请求、API 配置或平台专属接口。

## 限制与后续

- 这是局部纹理重建。几何重复纹理和非重复波纹已验证，复杂人像、文字、大物体移除、结构重建仍需真实照片评审，不能据此等同语义生成式填充。
- 局部 Worker 限制不等于整机低内存：100MP测试中 Tab/GPU 的工作集峰值分别约1.61GiB/1.24GiB，包含原图解码、测试夹具、PNG及显示过程；各进程峰值并非同一时刻，不能相加作为同时总峰值。长期多层、低内存仍待验。
- macOS 构建/真机、Retina、键盘和正式签名公证仍待；当前只更新独立桌面运行构建，未发布完整NSIS/DMG。
- 对照旧版时另发现绘画交互仍有差项：屏幕像素拖绳平滑、抬笔补齐端点、Shift点击连接前一笔端点、直接绘制蒙版。当前EMA平滑/拖动直线不能替代这些交互，已回列完整复刻待办；随后继续调整层与特效。
