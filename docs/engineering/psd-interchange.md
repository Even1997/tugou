# PSD 基础文件互通验收

本轮补图层工作区文件互通，版本仍为 0.8.13，未发版。使用 ag-psd 34.1.0（MIT），依赖锁定、构建第三方声明已包含许可；未手写 PSD 编解码器。原工程与普通图片导入导出不换格式。

## 完成定义与范围

支持的 PSD 先解析并展示转换说明，再增加一个新画板；整体撤销 / 重做、保存重开均一致。导出保持原工程可编辑；明确降为像素的内容不宣称保留 Photoshop 原生结构。不兼容内容拒绝分层导入，可由用户改选合并预览。失败 / 取消不提交部分画板，不覆盖处理中出现的其他工程编辑。

| 项目 | 当前行为 |
| --- | --- |
| 导入 | 8 位 RGB，像素图层、名称、顺序、位置、显隐、透明度、普通分组及 16 种映射混合模式 |
| 穿透分组 | 仅不透明度 100%、内部全部为普通合成时转换为普通分组；其他情况拒绝 |
| 文字 / 智能对象 | 使用文件保存的像素，并逐层提示转换；不保留结构编辑 |
| 复杂内容 | Photoshop 原生画板裁切、蒙版、调整层、特效、剪贴、非默认混合颜色带及不支持混合模式拒绝分层导入；解析库不认识的内容开启严格报错 |
| 合并预览 | 用户显式选择，只导入 PSD 保存的合成图；无可用合并图时拒绝，提示预览可能过时 |
| 分层导出 | 当前画板第 1 帧，保留顶层名称 / 顺序 / 显隐 / 透明度 / 支持的混合模式；每组栅格化为一层，文字、形状、特效、蒙版烘焙入图层像素 |
| 跨层关系 | 顶层调整 / 剪贴 / 关联蒙版、不兼容顶层混合模式或组引用外部蒙版阻止分层导出；提示使用合并 PSD |
| 色彩 / 位深 | 仅 8 位 RGB；不做 ICC 转换，内嵌 ICC 导入有明确提示；PSB/CMYK/16/32 位拒绝，不静默降级 |
| MCP | 文件读写为 uiOnly，覆盖清单明确登记；导入后可用原有图层命令编辑，未新增 PSD MCP 命令 |

## 实现与资源保护

- `app/core/psd-format.cjs`：共享格式与预算；128 MiB 文件、128 图层、单边 30000，画板与解码图层合计 32×1024×1024 像素。
- `psd-codec.cjs` / `psd-worker.cjs`：后台解析 / 编码。读入库内分配预算 256 MiB；Worker JS 堆限 384 MiB（不是进程总内存硬上限），120 秒超时，可终止。文件缓冲、原生图像内存仍受输入和像素预算约束。
- `psd-service.cjs`：安全路径、暂存资源、全部转换成功后发布；中途失败清理暂存，不提交半个画板。导入后取消审阅可能留下未引用内容寻址资源，沿用现有资源清理策略，不删除共享资源。
- 主进程只接收原生文件选择结果；导出使用原生保存位置令牌、安全路径及原子写入。普通 PNG 写接口不能绕过 PSD 编码校验。窗口销毁取消后台 PSD 任务。
- 界面沿用 Modal/Select/Button 和主题，显示处理进度、错误及取消；导入审阅绑定工程快照，后台工程已变更则拒绝提交。

### 局部性能基准

`node test/psd-performance.cjs`：2048×2048、2 图层及合并图，合计 12,582,912 像素的合成渐变样稿。Worker 编码约 249 ms、解析约 205 ms；主进程 10 ms 心跳最大间隔约 27.5 ms；进程采样峰值 RSS 247 MiB；取消 Promise 响应约 0.55 ms。仅为此 Windows 机器的一次合成样稿基准，不代表真实照片、Mac、低配机器或预算上限表现，也不是 Worker 退出的绝对耗时保证。
