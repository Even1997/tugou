# 独立实现第二批：配方、引用同步与画布编排

## 交付范围

`app/` 已增加配方完整编辑与本地画布编排，继续共用工程、素材和模型连接；旧程序及正式数据保留。本批没有替换正式安装包，不把旧 `canvasProjectIds` 当作已经迁移的画布内容。

- 配方：新建、命名、删除，选择/排序模块，设置任意输出尺寸文本、构图要求、参考图与各自职责，查看并复制完整提示词。画风放在最终统一约束位置，重复模块与参考图去重。
- 引用：修改共享定义前保留旧内容快照。工作台和节点标记“有新版”；顶部一次更新无冲突引用。本地文字与共享新版冲突时，明确选择保留本地或采用新版。删除来源后保留快照并显示失效状态。
- 画布：同一窗口内的模块/配方/素材/文字节点、库内拖放及点击添加、平移/缩放/适应画布、Shift多选和整体拖动、连线、删除、撤销/重做、保存重开。连入配方的模块与素材参与提示词合成；显式连入的同一模块可覆盖配方副本。阻止自连、重复连线、循环和无效目标。
- UI：工作台选择状态跨工作区保留；画布常用操作与引用更新合并在顶部工具栏，右侧仅显示所选节点的内容。复制通过校验来源的主进程桥接，避免受页面剪贴板权限拦截。
- 数据：新增字段 `moduleBindings`、模块 `revision`、`tugouCanvas`；保留原有字段和未知字段。新画布存储不覆盖旧画布关联。

画布交互采用 MIT 许可的 `@xyflow/react@12.12.0` 基础库，配方、引用语义、数据存储、业务界面和编排逻辑在本入口实现；没有导入原平台源码或启动旧服务。组件接口参考 [React Flow 官方文档](https://reactflow.dev/api-reference/react-flow)。新增依赖声明保持在锁文件中，最终二进制许可审查仍属于交付阶段。
