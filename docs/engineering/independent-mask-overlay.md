# 蒙版预览与画笔参数分层

## 验收口径

- 合成、原图、黑白、叠加四种视图可切换。原图临时忽略所选图层蒙版；红色叠加显示隐藏区域，尊重浓度、羽化、反相和画板裁切。
- 预览状态仅存在于编辑器内，不写入文档；切换不修改图片或蒙版，实际 PNG 导出不含红色提示。停用蒙版仍可查看，但不能误启用。
- 叠加视图可以直接绘制蒙版并撤销、重做；切换图片目标或重新打开工程退出预览。
- 大小、不透明度、颜色／蒙版黑白留在顶部。硬度、平滑、直线、压感和取样对齐进入共享“笔刷设置”浮层；模糊半径仍在对应工具顶部。
- 浮层内外按 Esc 只关闭浮层，保留当前工具。940px／1100px 窗口、浅深主题及 125%／150% Chromium 缩放不裁掉预览入口和常用参数。

## 实现范围

`app/renderer/composite.js` 增加仅供编辑预览传入的渲染选项；叠加临时画布按视口大小分配，使用完释放。普通渲染／导出无此选项，保存格式不变。`layers.jsx` 管理当前预览图层与模式；`layer-properties.jsx` 复用现有 Button；`paint-tools.jsx` 复用 ToolPopover 与 NumberField。公共浮层补充 Esc 捕获，防止同时触发画布退出工具。

## 验证证据

- `desktop.json`：源码专项检查、1200×800 视口合成样本耗时。
- `package-check/packaged.json`：实际 Windows 包的选区／蒙版／快捷键回归、预览切换、真实 PNG 导出、浮层参数、连续 20 笔撤销重开与浅深主题检查。
- `unit.log`：212 项逻辑检查通过。
- `package-hashes.json`：11 个构建文件和 3 个主进程／桥接文件与候选包一致。
- `delivery.json`：交付入口、构建一致性和原工程文件未变校验。

像素验收覆盖隐藏／显示区域、透明与半透明原图、停用、反相、浓度／羽化、缩放平移、画板裁切及正在绘制的蒙版预览。实际图片填色与蒙版填色保持分离；检查保存数据、导出文件及撤销结果，不以按钮可点击代替功能验证。

1200×800 合成样本预览的源码测试中，普通视图中位 6.6 ms、叠加 8.1 ms（各预热 5 次、采样 15 次）。这是渲染调用耗时，不含屏幕呈现，也不代表真实复杂工程的帧率。最终包内独立采样见 JSON。
