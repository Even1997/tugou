# 图片替换、提示词与反推验收

本批完成画布图片替换、原提示词查看/复制、图片反推到模块及画布。功能入口集中在顶部，素材详情和反推复用现有组件、主题、模型配置与持久任务。当前用户窗口未操作；正式桌面尚未更新，等待整体计划完成后统一交付。

## 验收标准与结果

| 标准 | 实际验证 |
| --- | --- |
| 替换仅影响所选节点 | 素材库选择或单文件导入；节点编号、位置、连线、参考角色、未知字段不变，其他引用和原素材保留 |
| 替换形成一个撤销步骤 | 素材库替换和新导入均可撤销/重做；取消导入不发布素材；节点已变化时拒绝覆盖；保存及新进程恢复通过 |
| 提示词来自原始记录 | 生成结果按工程、任务和输出资源核对，修改当前配方不影响原提示词；复制完整多行文本；处理衍生图注明来源；无记录明确提示，禁用复制 |
| 历史提示词不串图 | 导入节点保留原始元数据；替换后不把旧图片提示词归给新图片，换回原素材可恢复原记录 |
| 反推正确使用所选原图 | 请求实际发送至本地 HTTP 视觉接口夹具，核对原图字节、视觉模型和用户要求；不同素材的最近记录不自动混入 |
| 审阅后再入库与入画布 | 编辑、勾选模块后创建模块及可选配方；已加入的分析记录只读，后续到工作台编辑模块；送入画布创建关联节点与边，一次撤销，重复点击不重复创建；不自动生成图片，不默认附带原图参考 |
| 任务和页面一致 | 新分析等待本次结果，取消保留既有审阅结果；素材库与画布共用详情/反推弹窗；模型不重复配置，重启不重发任务 |
| UI 与现有能力不退化 | 960px 深浅主题截图检查，顶部操作及审阅按钮可见；既有图片处理、分析草稿、最大模块数审阅回归通过 |
