# 无限画布对照调研

日期：2026-10-23。目标：减少图构中找节点、整理工作流和比较生成结果的操作成本。调研时仅实施移除全景节点的新建入口；后续已按用户确认接入节点类型搜索与选中节点整理，见[专项验收](independent-canvas-search-layout.md)。移动吸附及其余优化仍为建议。

## 依据与边界

阅读 Figma Weave、FigJam、tldraw、ComfyUI 的官方资料，实际打开 tldraw 工作流演示并检查缩放菜单，同时核对当前 `app/renderer/canvas.jsx`、`canvas-node-menu.jsx`、`canvas-nodes.jsx` 与 `image-tools.jsx`。未登录其他产品完成完整生成流程；优先级是结合图构现状的产品判断，不代表用户研究统计结论。

tldraw 演示截图：`app/test-results/canvas-research/tldraw-navigation.png`。可直接观察到 100%、适应全部、适应选中对象及对应快捷键。文档中的工作流引擎属于演示，不能据此判断生产规模性能。

## 当前已有能力

- 默认框选，按住空格平移，Ctrl+G 分组、Ctrl+Shift+G 取消组合，组合改名。
- 顶部添加、双击空白处和拖线到空白处创建节点；拖线创建后自动连接。
- 搜索既有画布内容、适应画布、小地图、点击引入内容定位来源。
- 引入内容直接显示文本或图片，可排序、移除，并支持撤销与保存。
- 图片工具已有“原图与结果”比较；尚未提供画布上任意两张结果图的直接比较入口。

上述已有能力应复用，不列为待开发功能。图层工作区已有的对齐、锁定等能力也不能当作无限画布已经具备。

## 建议顺序

| 优先级 | 改进 | 参考证据 | 适合图构的做法与验收标准 |
| --- | --- | --- | --- |
| P0 | 创建节点可搜索、主入口收敛 | [Weave 节点说明](https://help.weavy.ai/en/articles/12292386-understanding-nodes)支持菜单搜索和 Tab 唤起搜索 | 将“文字、图片、生成台”作为常用入口，其他功能仍可搜索找到；生成模式在台内选择。Tab 仅在非输入状态生效；双击和拖线菜单共用搜索。能用键盘创建，拖线创建保持正确连接，Esc 退出不新增节点。兼容输入类型筛选应基于现有校验，不能误隐藏合法节点。 |
| P0 | 选中节点自动整理 | [FigJam 排列说明](https://help.figma.com/hc/en-us/articles/1500004292221-Select-move-and-order-objects-in-FigJam)提供对齐、等间距和网格整理 | 先做多选后的左对齐、上下等距、按行整理及移动吸附提示；仅移动所选节点，一次撤销，连线与组内相对关系保持。不要默认重排整张画布；复杂有向图自动布局后置。 |
| P0 | 导航保持上下文 | [tldraw 演示](https://workflow.templates.tldraw.dev/)的缩放菜单已实看 | 缩放数字可点击，提供 100%、适应全部、适应选中；点击引入跳到来源后可“返回上一位置”。验收包含远距离来源、组内节点、切换选择与不同缩放；导航不计入内容撤销。返回位置是本项目建议，并非已观察到的竞品能力。 |
| P1 | 连线可重接、关系易追踪 | [tldraw 工作流文档](https://tldraw.dev/starter-kits/workflow)说明现有连线可拖动重接；[ComfyUI Reroute 文档](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/Reroute/en.md)说明转接用于整理连线 | 先做拖动端点换来源/目标，悬停或选中时突出直接关联线路。重接要同步引入顺序、职责和显式引用；非法连接恢复原状，支持撤销。长线转接点后置，避免先增加更多节点类型。 |
| P1 | 组合便于管理 | [FigJam 分区说明](https://help.figma.com/hc/en-us/articles/4939765379351-Organize-your-FigJam-board-with-sections)支持命名、整体移动和锁定 | 基于现有组合补锁定与折叠；折叠显示名称、节点数量和结果缩略图，跨组连线仍可理解。锁定时不能误拖，取消组合只去掉容器，保存重开状态一致。折叠展示方式是图构建议。 |
| P1 | 任意两张结果快速比较 | [Weave Compare](https://help.weavy.ai/en/articles/14046860-compare-node)提供滑杆和切换比较，并可选择结果继续工作流 | 复用图片工具已有比较视图：选中两张图后直接“比较”，支持联动缩放及选择其中一张继续引用。不同尺寸、透明图和原图保持正确；本阶段无需新增一个比较节点。 |

原建议的“节点搜索 + 选中节点整理”已实施：13 个创建选项可搜索，多选整理支持五种方式、组内坐标、一次撤销和保存恢复。真实工程手感仍待用户确认，再考虑导航；移动吸附线和全图自动布局未纳入本批。

## 本轮全景入口移除

共享创建菜单删除“全景图”一项，顶部、双击空白、拖线新建同时生效。保留旧工程全景节点、素材、连线与查看能力，不做数据迁移或自动删除。旧全景节点测试改为载入既有工程夹具，继续验证可读、查看与生成链路。

## 验证与风险

研究结论已有官方来源和本地代码依据。节点搜索、选中整理现已完成源码和 Windows 包内交互验证，覆盖输入框快捷键、中文输入法、组合坐标、撤销/持久化和连线保留，证据见专项验收；其余建议尚未实施。真实大画布长时操作与 Mac 手感需要单独验证。
