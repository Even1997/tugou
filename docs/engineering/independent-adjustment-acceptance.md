# 独立调整图层验收

## 范围与完成定义

统一顶部入口和参数行接入12类非破坏调整：亮度/对比度、色相/饱和度、色阶、曲线、曝光、渐变映射、黑白、色彩平衡、颗粒、反相、噪点、高斯模糊。参数可以再次编辑、停用、重置、撤销；同组下方/剪贴作用范围、透明度、选区蒙版、保存恢复和原尺寸导出必须有实际证据。6类图层特效仍是下一批，未包含在本批完成范围。

## 实现

- `core/adjustments.cjs` 独立定义参数校验、颜色变换、通道查表、形状保持曲线插值和按文档坐标固定的噪声；未知字段随原图层保留。
- `renderer/composite.js` 共用预览/导出合成。普通调整处理同组下方合成结果，剪贴调整使用对应内容的独立颜色目标，保留输入Alpha。普通剪贴链保持既有透明度和背景混合语义；独立组不把调整扩散到外部。
- 滤镜余量沿连续模糊累积，独立分组取最大需求；实时蒙版来源参与余量计算。导出仍按1024px块执行，滤镜临时内存超过384 MiB时明确拒绝，不隐式缩图。
- `AdjustmentTools` 复用 Button、ToolPopover、NumberField；常用参数在顶部，其余收入弹层。曲线支持主通道/独立RGB、双击加点、拖动、方向键、Delete删点与数值编辑；按键不串到图层。切换图层关闭上一个参数弹层。
- 新建调整将已有选区转为蒙版。拆组或部分合并可能扩大/遗漏调整作用范围时明确阻止，建议先合并完整分组；不静默改变画面。
