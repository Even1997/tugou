# 图像工具顶部导航与素材侧栏

## 行为

- 顶部为“智能工具、基础处理、图像合成”。智能工具先展示 AI 局部修改、AI 扩图、AI 超分辨率、主体抠图；普通进入工作区时默认选中 AI 局部修改。
- 工具搜索跨全部 20 个工具，结果保持智能工具优先；选择结果后回到对应分类。按钮沿用原有样式和原生键盘操作。
- 左侧为当前工程的图片素材，展示缩略图、名称、尺寸与选中状态，可搜索和本地上传。缩略图懒加载，列表独立滚动。
- 原顶部来源下拉移除；预览栏显示当前素材名称、批量处理和对比方式。中间保留同步缩放／平移与并排／滑动对比，右侧保留工具参数和处理入口。
- 点击新素材回到原图，清除上一张的当前结果并重置依赖来源尺寸的参数；上传清除素材搜索，选中新导入的第一张。
- 左下角的处理记录保留，点击可恢复来源、工具和参数，并展示原图与结果对比；不在当前素材库中的历史原图仍可选中查看。撤下的旧工具结果继续按原规则仅查看。
- 从画布的指定入口打开工具弹窗时，保留指定操作和素材，不强制改成智能工具。

仅改界面组织及选择视图，不改算法、下载方式、存储格式或 MCP 工具协议。

本轮开始与结束，用户真实会话的文档 revision、未保存状态、对象数量和撤销记录一致。未强制切换当前工具页。开发预览已准备好界面更新；工具页含局部参数，离开该页后才安全应用，等待顶部更新提示完成再进入工具页即可，无需重启。
