# 生成台外部结果与进度验收

## 验收范围

- 任务提交后立即在生成台右侧创建每张结果的占位及来源连线，完成时更新原节点，不重复添加。
- 生成台保持输入与参数，结果由独立节点承担；提供双向定位、取消、失败状态和重新生成。
- 显示排队、等待模型、下载、保存阶段与耗时；不模拟百分比。视频接口 42% 已由桌面测试确认。
- 保留旧结果、用户移动位置和删除意图；结果同步到撤销／重做快照，避免恢复空占位。
- 下游生成台引用结果节点时不重复引用上一轮输入；文本结果可编辑保存。
