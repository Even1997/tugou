# 独立版本第三批：画布生图、任务、结果与旧画布迁移

验收日期：2026-10-22。范围为本批工作流；完整图层编辑、图片工具与最终安装包仍在后续阶段。

## 验收目标与结果

| 目标 | 完成定义与证据 |
| --- | --- |
| 画布直接生图 | 顶部选择配方后提交，主进程读取共享加密连接；无参考图调用 Images generations，有参考图按职责顺序 multipart edits；不启动旧服务，不使用 MCP。真实 API 1 次通过 |
| 任务生命周期 | 排队、生成、完成、取消、失败、中断可查看；同节点禁止重复提交；取消丢弃迟到结果；失败/重启不自动重试收费 |
| 结果可靠入库 | 原始图片按 SHA256 保存，实际尺寸单独记录；结果清单与工程独立落盘；重启可恢复。前端合并最新编辑，撤销旧编辑不会顺带丢结果，删除结果节点后重开不复活 |
| 旧画布迁移 | 只读复制 IndexedDB 至临时隔离进程，在被拦截的旧 origin 读取数据库，不执行旧应用。源文件前后哈希一致；原始 JSON、节点元数据和连线快照留档；重复迁移不覆盖编辑 |
| 统一界面 | 生图、任务、迁移入口在顶部；素材库与画布共用结果；960px 无溢出，任务错误在面板内显示 |

## 风险与边界

- 供应商当前不遵循请求尺寸；任务面板明确显示请求/实际不符。未再次测试同一供应商2K/4K，也不声称已支持真实高分辨率输出。
- 真实收费验收仅文生图1次；参考图 edits 的字段、顺序和职责通过本地 HTTP 验证，尚未再次收费验收人物换脸效果。
- 当前读取本机正式版的 localhost:3418 IndexedDB。远端账户、其他端口及视频/3D特殊节点不是本次实测数据；不支持的节点保留原数据并显示迁移提示，不静默丢弃。
- 大量历史任务及千节点/100MP峰值尚未压测；普通流程响应通过，不外推专业级极限性能。
- 开发入口仍依赖本地 Electron 安装目录，正式独立打包和全部图层/工具替换继续按原阶段执行。此批没有修改许可证结论。
