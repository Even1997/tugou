## 本批完成定义

- 顶部“图片工具 → 云端 AI”提供云端增强、创意放大、AI局部修改、AI扩图，复用模型连接与持久生成队列；上传前明确原图和要求发送到已配置API。
- 增强/放大保留来源Alpha，放大由模型返回目标尺寸。尺寸不符直接拒绝，不通过普通插值冒充创意超分。
- 局部修改发送原图和PNG透明编辑蒙版，返回后只复制矩形选区内RGBA；选区外逐像素保留。扩图发送扩展画幅和新增区域蒙版，再把原图RGBA精确恢复到指定偏移，包含透明像素。
- 来源尺寸/方向、画幅、偏移、内存与输入快照先校验；来源不可变引用、处理参数、实际提示词、用户原始要求均持久保存。取消/超时沿用队列，不自动重复计费。
- 对比原图/结果，手动存入素材库去重，原素材不替换；生成结果保留来源ID、工具与参数。重开可恢复结果和参数，不因查看历史重复发送请求。

## 风险与剩余项

- 实际通道须支持Images edits、PNG mask及所选输出尺寸；供应商若不支持会报错，当前不自动降尺寸、不改协议和不改用其他模型。
- 真实模型增强/创意放大细节、身份/文字/画风保真、扩图接缝尚未验收。矩形选区当前为本工具范围；任意蒙版编辑、语义类别拆分、供应商异步恢复和更广样本继续在总目标中。
- 暂不支持来源EXIF旋转；会在上传前明确拒绝并要求重新导入，避免保护区域错位。
