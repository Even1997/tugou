# 500 张独立大素材浏览验收

## 验收范围

补足原 500 份小图仅改变 EXIF 的样本边界。`desktop/tests/atelier-large-library.e2e.cjs` 创建 500 张像素内容不同的 2048×2048 PNG，每张由确定性 RGB 图案生成，并检查原始像素哈希、资源 URL 均唯一。使用最新候选 `eNMKEaN7IDIBsYcy8IG7U` 的真实打包服务和默认 GPU 路径 Electron；数据仅在 atelier-qa，未调用模型接口。

完成定义：工程只读资源引用；首屏不请求所有素材或原图；三轮跨列表滚动及一次重开能显示缩略图；仅选中入层后读取完整原图且字节一致；无控制台错误。测试设置 6 分钟期限、1 GiB 剩余物理内存和 3 GiB 合计私有提交内存保护。

## 结果

`atelier-large-library.json` 通过，记录 39 次采样：

| 项目 | 实测 |
| --- | --- |
| 原始 PNG 总量 | 393,633,812 字节，约 375 MiB |
| 全部解码为 RGBA 的理论体积 | 8,388,608,000 字节，约 7.81 GiB；没有全部同时加载 |
| 按需打开 | 31 ms，响应 113,542 字节 |
| 首屏请求 | 36 张缩略图，浏览期间未请求完整原图 |
| 缩略图边长 | 不超过 384 px |
| 三轮共 75 个滚动采样 | 就绪 P95 1,011 ms，最长 1,019 ms，包含冷缓存 |
| 内存采样时段 | 38.086 秒，不含准备素材 |
| 全测试 Electron + Next 私有提交峰值 | 742 MiB |
| UI 心跳最长等待 | 944 ms；空闲阶段约 0–1 ms |
| 选中原图 | 按需加载，保存资源的字节一致 |
| 重开 / 控制台错误 | 通过 / 0 |

前两轮结束的空闲私有提交约 574/564 MiB，重开后第三轮约648 MiB，选中完整原图后的末次约732 MiB。此结果证明这组有限操作下没有失控增长，不证明无限运行无泄漏。采样包括所有测试 Electron 进程和独立 Next 服务，不包括其他用户程序或 Go API；私有提交不是物理内存或显存。准备阶段保留的测试缓冲也可能计入 Electron 主进程。
