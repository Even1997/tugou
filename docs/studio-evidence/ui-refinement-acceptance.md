# 界面组件化与信息精简

## 设计与完成定义

用于长时间编辑、替换提示词模块与组合素材的本地创作工具。重点是清楚的主次与舒适的阅读宽度。

- 色彩：深色底 #15171D、面板 #1D2028、正文 #E8ECF4、雾蓝 #B1C0FF；浅色底 #F3F5FA、面板 #FFFFFF，动作色 #536ACC。所有画布与工作台共用主题来源。
- 字体：Segoe UI Variable / Microsoft YaHei UI；正文 15px、30px 行高，标题 24px，数字使用等宽字体。
- 布局：模块导航 / 有限宽度的编辑纸面 / 配方配置。完整提示词折叠，主操作固定在配方面板底部。去除假步骤编号、重复技术说明与装饰性流程。
- 代码：采用已有 Ant Design；共享主题、字段、面板标题、图标按钮和模块标识。删除被替代样式，保留图层编辑器与素材布局必要规则。没有新增包或外部字体请求。

完成标准：界面层级可辨、主要操作仍可达；编辑、保存、生成、同步不回退；深浅主题和较窄桌面窗口可用；新桌面包启动并保留用户工程。
