# 编辑底座、图层排版与首批选区能力

## 本次范围与完成标准

在当前 Windows 桌面工作区内继续实现，不另开编辑器。保持素材库、提示词模块、无限画布和模型配置共用。

- 文档：兼容旧工程；资源独立存储；写入失败保留上一次工程；保存重开数据一致。
- 编辑：一次鼠标拖动/变换对应一次历史操作；组内外变换不改变世界坐标；输入连续修改可合并撤销。
- 合成：预览、导出和图层合并使用同一渲染器；验证组透明度、混合模式、剪贴与蒙版的实际像素。
- UI：维持主题及组件体系；常用操作直接可见，次要操作放在菜单/折叠区；1100 px 窗口不横向溢出。
- 旧工程：用真实 C 版工程副本检查，不以空白工程代替回归。

## 已接入

1. V4 文档兼容 V1/V2/V3，素材、绘画副本及像素蒙版按 SHA-256 独立存储、去重、读取校验；工程导出仍为完整便携文件。新数据使用版本门禁，防止旧编辑器忽略新效果。写清单之前完成资源写入；Windows 短暂占用时有界重试，绝不删除旧文件以绕过替换失败。
2. 60 步历史与保守的历史资源预算；图片字符串共享，连续属性编辑合并；拖动和变换在结束时提交。
3. 图层组合/拆组、整组复制、跨组拖拽、层级折叠、锁定继承；重算组框时保持内容世界坐标；会损失独立合成效果的拆组被明确拦截。
4. 多选移动/缩放/旋转；非等比缩放、倾斜、翻转；图片、文字、形状四角透视及角点拖动，文字和形状仍可编辑；对齐与等距分布；网格、标尺、可移动参考线、对象边缘/中心吸附。Alt 拖动暂时关闭吸附。
5. 段落对齐、字体、字形、字号、字距、行距；可编辑矩形/圆角/椭圆/直线、描边及线性渐变。
6. 24 种混合模式、隔离组透明度、剪贴层；连续根层的合并为图片，自动裁掉多余透明范围并保留原位置，结果进入同一素材库。组可合并后使用透视，合并可撤销。
7. 画布尺寸、内容随画布缩放、非破坏裁剪、透明修边。
8. 矩形、椭圆、套索、多边形选区；添加/减去/交集；应用到图层或组的非破坏蒙版；反相、停用、羽化。
9. 画笔/橡皮、直径/硬度/不透明度，新建绘画层；在图层副本上绘画，素材库原图不变。每笔一次撤销，历史预算计入像素内容；已有图片可一键还原原素材。
10. 像素蒙版涂抹隐藏/恢复，已有矢量蒙版首次落笔时转成像素蒙版，可撤销。保持反相与羽化语义；旋转、缩放、透视后的落笔通过逆变换定位。Escape/切换工程/失焦取消未完成笔画，异步准备期间改变工程不会写回过期内容。

原生混合使用 Canvas2D；补充混合公式使用同一 source-over alpha 语义。边界公式参考 [W3C Compositing and Blending](https://www.w3.org/TR/compositing-1/#blending)。并非声称与 Photoshop 或 Compositor 的所有色彩空间逐像素等同。

## 仍未完成

这不是 Compositor 全套能力完成声明。后续继续按原阶段顺序：

- 排版补充：保留嵌套组可编辑数据的透视、复杂组与剪贴层的保留效果合并。
- 选区蒙版补充：魔棒/色彩范围、羽化选区扩缩、取消链接及独立变换、实时引用蒙版。
- 绘画修图：压感、平滑/直线、仿制、修复、内容感知、涂抹/液化等。
- 调整图层与特效，随后专业格式、色彩管理、高位深及后台大文件保存。

资源目前保守保留，不自动清理未引用文件。前端保存请求仍包含素材数据；磁盘去重不等于已经实现资源增量传输。复杂合成超出内存预算时会明确报错，保留可编辑数据。隔离 UI 测试未启动模型后端，已有 API 连接提醒单独记录；不当作真实模型生成验收。
