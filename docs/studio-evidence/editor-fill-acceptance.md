# 平滑、直线与内容感知填充验收

2026-10-21。本轮只补齐第 4 阶段指定的三项能力，顶部工具行与参数行保持现有组件和主题。

## 行为与验收标准

- 平滑：拖绳防抖，0–100 屏幕像素，随视图缩放换算；松手补齐终点。直线：拖动时仅显示引导线，松手生成直线；Shift 点击连接同图层、同目标的上一笔。画笔、橡皮、蒙版绘画共用实现。
- 内容感知填充：当前图片的选区内进行多尺度 PatchMatch 与边界色调校正；存在一致纹理块时优先完整复制，避免逐块错相。保留素材原图，写图层位图副本，一次撤销。
- 入口为顶部“修图”及“选区操作”；进度和取消也在顶部参数行。更换工程、编辑图层或离开编辑器取消旧任务，迟到结果不能覆盖后续编辑。
- 原生鼠标、逐像素验证、撤销重做、保存重开、PNG 导出一致性是完成标准；不能仅以菜单存在或构建成功验收。

## 已验证证据

- 49 项模型/存储/选区/算法测试与 11 项隔离 HTTP/导出接口测试通过，类型检查与生产构建通过。
- `editor-fill-ui-results.json`：真实打包 Web Worker 与原生鼠标操作；直线忽略拖动中的折返、Shift 连线、平滑过滤抖动并补终点；一次撤销重做；填充保存重开；PNG 导出整块图层像素一致；选区外像素与素材原图不变；取消和锁定保护。
- `editor-fill-pixel-results.json`：羽化覆盖值合成逐像素比较；旋转/缩放和透视坐标映射；透明洞填充；Worker 取消和无有效来源拒绝。10000×10000 测试图中 24×24 局部选区填充，输出仍为 10000×10000，约 1.1 秒。此为均匀背景合成样图，不代表复杂照片的耗时。
- 非重复起伏纹理测试验证色彩误差和方差，防止简单均值涂平。512×512、128×128 空洞的起伏纹理算法单独运行约 660 ms（本机 Node，未含编码），不作为所有图像的性能承诺。
- `editor-fill-900.png`、`editor-fill-1100.png`：画笔参数行保持 43 px，所有常用控件位于可视边界内，已实际查看截图。
- 原仿制、修复、模糊、涂抹、液化真实 UI 回归通过：一次撤销重做、保存重开、PNG 全图像素一致；原有选区/蒙版回归另行记录在对应结果文件。
- Electron 像素测试使用独立的测试窗口与本地模块，其宽松 CSP 提示来自测试装载环境；生产桌面仍使用隔离、沙箱窗口。没有新增图片外传或模型请求。

## 边界与风险

- 图像仍支持 30000 单边、1 亿总像素；单次内容感知填充的选区与周围取样总范围限制 400 万像素。超出明确拒绝，不会缩小原图或部分提交。
- 只使用当前图层的原始、不透明、未选中区域作为纹理来源；不跨图层采样。源纹理不足会拒绝，不会自动调用收费服务。
- 局部纹理重建无法保证复杂结构、面孔、文字、透视重复图案的语义正确。照片修补仍需视觉审阅；不等同于生成式补图。
- Worker 可立即终止；图片解码和 PNG 编码仍由浏览器完成，取消后不会提交，但已经开始的编码可能需要完成才释放临时内存。长时多笔大图、更多照片和 Windows DPI/辅助技术测试仍待补充。
- 原有其他编辑能力的边界不变，下一阶段是调整图层/特效，之后才是专业文件与色彩能力。
