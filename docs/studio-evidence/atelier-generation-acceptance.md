状态：第六批已更新正式桌面，build 7K7G7cEj46XmJg5foHrJW。真实模型接口由用户稍后配置，本文件不代表云端画质或全计划完成。

## 本批范围与验收标准

- 配方与Studio共享连接的无限画布共用本机生成队列和任务记录。密钥仍留在既有网关/加密配置；任务仅存公开连接信息、提示词和不可变参考图引用。
- 同ID并发提交只执行一次；重用ID更换输入拒绝。最多20个活动任务，远端请求串行；本地GPU处理独立运行。模型连接变化时未发送的旧任务拒绝执行，避免误用新模型。
- 完成图片落本机内容哈希资源；结果按任务ID入库去重。配方入库时保留完成记录，便携工程保留提示词/模型/生成版本快照。
- 页面刷新后结果可再次查看和入库；真正关闭服务后，运行中/排队任务均标记中断，不自动重新提交。当前同步Images API没有供应商任务ID恢复；异步通道需按真实协议继续适配。
- 运行中的“停止等待”中止本机请求，迟到结果不发布；不能承诺停止供应商计费。重新生成需明确确认可能再次计费，使用新ID和原提示词/参考图快照。
- 原有尺寸、质量与Base64响应选项继续传递；“自动尺寸”不发送非法尺寸字符串。完成通知不强行打断其他编辑页面，画布任务避免重复计数。
