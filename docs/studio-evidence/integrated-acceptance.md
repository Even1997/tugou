# 共用模型配置与内嵌无限画布验收

## 交付范围
- 同一桌面窗口提供提示词、无限画布、图层合成和素材库页签。
- 共用 API 地址、加密密钥、生成模型和分析模型；画布“共用连接”与主窗口打开同一设置。已生成的旧节点再次生成时使用当前共用模型。
- 直接嵌入原版画布 React 组件。未使用新窗口或 iframe；页签隐藏时保持组件和任务，快捷键只作用于可见工作区。
- 配方以文字、图片节点和连接进入画布；结果可回收至素材库，不覆盖原图层。保存工程会同时刷新本地画布存储。

## 验证证据
- TypeScript `tsc --noEmit` 通过；Next.js 16.4.2 生产构建通过，无动态文件追踪警告。
- 最终打包资源的隔离实例：17/17 自动化测试通过（约 501 ms）。包括两个工作区同一凭据与模型、更新模型立即生效、参考图 multipart、视觉分析、未授权及跨来源拦截、错误密钥脱敏、不重复请求、工程往返。
- 浏览器操作：一次配置后，提示词工作台与内嵌画布各请求一次本地模拟提供商；两次鉴权正确。画布任务期间切换至提示词页签，回到画布仍有结果。回收后素材 5 → 6，原图层仍为 6；重复回收不重复入库。
