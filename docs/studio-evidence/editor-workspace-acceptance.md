# 顶部工具区与大图编辑验收

日期：2026-10-20。范围：本地桌面图层合成工作区的布局、原尺寸绘画、视野预览与导出。

## 设计依据与完成定义

- 已实际查看 [Graphite GitHub 界面截图](https://github.com/user-attachments/assets/decb7011-18c2-4c68-82af-d1fa5064244a)，采用顶部集中工具参数、侧栏保留图层与对象属性的组织方式。也核对 [Compositor README](https://github.com/robbietilton/Compositor) 中的工具头部参数与内存预算设计；未运行其 macOS 程序。
- 沿用当前灰蓝主题、字体和组件体系。工具行 + 固定参数行横跨整个编辑区；创建文字、形状、画布尺寸与裁剪移至顶部。常用画笔、橡皮直接可见，蒙版与新建绘画层收进更多菜单。基本笔触参数无需再开浮层。
- 验收：工具可操作、切换时画布不跳动、900/1100/1500 像素窗口无横向溢出；原工程往返一致；1 亿像素图片实际导入、原尺寸落笔、撤销/重做、保存重开与导出正确；100% 视图保留单像素细节。
- 主要风险：大图内存、透明边缘拼接、工程迁移。分别以工作表面分配量、逐像素对照、部署前后工程与凭据核对验证。

## 实现边界

- 画布/素材/绘画统一校验：单边不超过 30,000，总像素不超过 100,000,000；图片文件约 150 MB，工程请求/导入 512 MB。不是无上限。
- 绘画从三张完整画布改为一张工作画布 + 256 像素脏区的原始像素与笔迹；单笔透明度只合成一次，重复经过和跨块边缘都校验。
- PNG 使用异步编码，编码成功且工程仍为当前版本才提交历史。失败不提交半成品。
- 预览按可见区域和显示比例重新渲染，100% 可看到原图像素；缩放范围 0.2%–1600%，百分比按钮返回 100%。不再依赖固定 1800 像素的整图预览。
- 导出按不超过 400 万像素/512 行的条带渲染，带羽化重叠区；本机 sharp 合并条带、编码 PNG/JPEG。浏览器不再为导出分配整幅多层大画布。透明修边也分条扫描。
- 四角透视的整图中间表面、复杂多层合并仍受 384 MiB 临时合成预算约束。本轮没有承诺这些操作在所有 100MP 组合下可用；完整磁盘瓦片缓存、PSD/PSB、ICC/CMYK、16 位等仍在后续编辑路线中。

## 验证证据

- 类型检查与生产构建分别执行，不以 Next 跳过类型检查代替 `tsc`。
- 36 项模型、历史、存储、引用同步、透视单元测试。
- 11 项 HTTP 测试：原有 9 项 + 分块导出的跨来源拒绝、尺寸/任务/顺序/完整性校验、取消、PNG 透明像素对照。
- Chromium 渲染测试：24 种混合模式、组/剪贴/蒙版、文本与形状、透视、脏区往返，及羽化分块与整图的预乘色差不超过 2/255。
- `editor-ui-results.json`：真实 React 输入、鼠标拖动/缩放/选区/绘画，撤销重做和重开，窄窗口，顶部工具和 100MP 设置/导出。
- `editor-large-image-results.json`：71 MB、10000×10000 渐变/1000 色块/透明区域测试图，实际文件导入 1.47 秒、绘画与编码 2.01 秒、PNG 导出 5.39 秒、JPEG 导出 5.53 秒。原尺寸绘画、撤销重做、保存重开、局部实时预览、单像素细节、导出尺寸及角点/透明/笔触采样均通过。耗时仅代表该测试图和本机当时负载，不代表所有照片。
- `editor-workspace-visual-results.json`：普通 Chromium 窗口使用真实导出按钮，含文字透视、图片透视和蒙版的 10000×10000 工程导出 9.55 秒；分步记录表明接口分块上传多数为 4–10 毫秒，本地最终编码约 2.89 秒。离屏输入自动化窗口同工程导出 86–103 秒，存在窗口模式相关的异步编码延迟，不能拿它当普通桌面的耗时。普通窗口测试使用独立名称核对输出文件，避免混入其他导出结果。
- 30000×64 长边测试：末端单像素正确，没有截断。C 版原工程全尺寸合成 185 毫秒，6 图层/4 素材保持不变。界面截图为 `editor-workspace-c.png` 和 `editor-workspace-900.png`，均已实际检查。
- 绘画测试记录的 `workingBytes` 仅计工作画布与笔触缓存，不是进程总内存；还存在源图解码、编码、历史字符串和导出进程开销。
- 桌面已更新并启动 `release/editor-workspace/CanvasStudio-win32-x64/CanvasStudio.exe`，原有快捷方式已指向新版本。`editor-desktop-results.json`：前后端均为 200、两份原工程逐项内容一致、加密凭据哈希不变。升级前备份位于 `.tools/before-editor-workspace`；测试数据独立存放于 `.tools/editor-foundation-qa`。
- 当前没有已配置的生图 API 密钥，因此本轮不包含付费模型调用；本轮编辑能力与导出均在本机验收。
