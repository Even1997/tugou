## 方法与预设标准

复用已安装的PyMatting closed-form算法。输入为既有768×768解析薄纱图在浅色、深色、棋盘背景上的合成图；相同标记覆盖外框25px背景、可见头部内部椭圆和身体内部矩形，其余为未知。标记直接由固定几何位置定义；原Alpha只在推理完成后用于评分，未参与标记生成。

预设要求沿用前一基准：整体Alpha MAE≤0.03，半透明区域MAE≤0.12；明确前景／背景标记必须分别保持Alpha=1/0，源文件哈希不得改变。它是标记辅助路线的有限可行性试验，不代表真实照片或用户精细描边能力，也不证明所有trimap算法不可用。
