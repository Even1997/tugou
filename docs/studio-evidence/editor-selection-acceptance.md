# 选区与蒙版验收

范围：按 Compositor 清单继续第 3 阶段，沿用统一顶部工具行和固定参数行。下一阶段仍为绘画与修图，不提前把调色、专业格式菜单算作已完成。

## 本轮交付与验收标准

- 矩形、椭圆、套索、多边形延续已有入口，新增魔棒和色彩范围。魔棒为四邻域连通选择；色彩范围选择同色非连续区域，支持当前图层或所有可见图层取样。容差影响下一次取样；可用添加、减去、交集组合多个样本。
- 选区成为工程内容，支持反选、羽化、扩展/收缩、填色、清除、全选、取消，以及切换画笔/橡皮后继续限制落笔。Ctrl+D 取消选区，Delete 清除选区内图片像素；有选区时不会误删图层。Escape 结束当前工具，保留已完成选区。
- 路径与像素选区均支持转换为图层/组蒙版。像素选区单独存储为内容寻址资源，纳入工程校验和历史内存预算；不把位图塞进浏览器业务存储。
- 顶部对象参数行新增“蒙版”：位置、角度、缩放、取消链接独立定位、反相、启停、移除及实时引用。独立蒙版可超出初始图层框；移动图层时它保持文档坐标，裁剪/改变画布尺寸时跟随文档坐标调整。
- 实时引用使用普通来源图层自身的透明度与不透明度，支持隐藏来源；来源变化会重新合成。拒绝缺失来源、组引用和循环引用。删除来源解除引用，可撤销；来源被外部图层引用时禁止直接合并，避免其他图层外观静默改变。
- 验收必须覆盖真实点击/绘画、选区外像素保持、每步撤销重做、保存重开、预览/导出同源合成、大尺寸原像素和窄窗口可见性。

## 实现与风险边界

- 沿用 Compositor `WandPixels.c` 的扫描线思路，改为 TypeScript，MIT 声明保留。当前实现不是 Apple Vision 的自动主体分割。
- 取样按 64 行渲染读取；画笔只在触及的局部块计算选区覆盖，缓存有界。100MP 不降采样为小预览后再编辑；覆盖层预览单独缩小，不改变实际像素范围。
- 扩缩使用方形邻域的最大/最小值滤波，羽化使用 Canvas 模糊；最多 ±100 px / 100 px。复杂位图组合会生成新的原尺寸选区资源；大规模多轮组合仍有编码和内存开销。
- “取消链接”保留当前位置；“恢复随动并重置位置”会明确重置独立坐标，尚未提供保留任意透视位置的无损重新链接。实时引用取来源自身 alpha，不包含其祖先组最终混合结果。
- 复杂大图透视/多层合成仍受既有 384 MiB 临时表面预算约束。独立蒙版跨透视、超高 DPI、长时间复杂引用链仍需更多样本。专业磁盘瓦片缓存、仿制/修复、调整图层、PSD/高位深不在本轮完成范围。

## 验证证据

- 41 项单元测试通过（原 36 + 新 5）：扫描连通、扩缩与暴力像素基准、透视坐标往返、独立选区资源保存与非法路径、引用循环/复制重映射/来源删除。
- 11 项 HTTP 回归通过：本机 API 模型模拟、工程读写、凭据保护、分块导出约束。没有调用真实付费模型。
- `editor-renderer-results.json`：原合成器回归，以及色彩孤岛、填色/清除、选区内绘画、羽化跨块、蒙版独立移动/反相/实时笔触、来源透明度与移动、裁剪坐标，旋转/透视下蒙版笔触坐标往返。历史 C 版验收样本（6 图层/4 素材）全尺寸合成约 175 ms；不是用户当前工程的图层数量。
- `editor-selection-ui-results.json`：顶部魔棒点击/色彩范围、切画笔与边界像素、撤销重做、选区保存重开、扩缩羽化、蒙版转换、独立坐标、引用来源和真实 PNG 导出。
- `editor-large-image-results.json`：71 MB、10000×10000 文件，原尺寸单像素色彩选择约 2.45 秒；选区内绘画与编码约 2.13 秒，选区外像素保持；PNG/JPEG 各约 5.4/5.3 秒。仅代表该样图与当时机器负载。
- `editor-ui-results.json`：原有分组/排版/原生拖动缩放/透视/合并/绘画回归通过，合并前后像素差为 0；900/1100 窗口与 10000×10000 真实按钮导出通过。离屏自动化窗口该导出约 51 秒；窗口模式会明显影响异步编码耗时，不以它代替普通窗口性能。
- 类型检查与最终生产构建通过，桌面已切换到 `release/editor-selection/CanvasStudio-win32-x64/CanvasStudio.exe`，原快捷方式已更新并启动。隔离测试服务已关闭。
- `.tools/before-editor-selection` 保存本轮升级前的工程、资源、原快捷方式及凭据哈希。`editor-desktop-results.json`：前后端均 200，两份当前工程与本轮升级前语义一致，加密凭据哈希不变。当前 C 版为用户已有的 5 图层/4 素材状态，没有恢复成历史验收样本。
- `editor-selection-toolbar.png` / `editor-mask-toolbar.png` 已实际查看。蒙版参数栏的纵向裁切问题已修复，并增加全部输入框/按钮均在固定行内可见的断言。
