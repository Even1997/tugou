# 主体抠图验收口径

2026-10-21用户澄清：“这个看用户把，正常是要识别到主体然后再把主题抠出来”。本文件作为当前产品验收口径；此前实验数据原样保留。

## 默认目标

识别并提取用户需要的主体，去除背景，输出可用于后续拼图的透明素材。默认验收不要求还原参考PNG中的每个Alpha值，也不要求保留全部外围柔光。

- 主体：人物、宠物或物品的主体部分完整，不误删衣物、肢体、花瓣等，不把明显背景残留当主体。
- 边缘：发丝、细毛、头纱、透明材质属于主体自身的细节；不能为了干净轮廓统一硬切或过度收缩。
- 外围效果：柔光、投影等按用户用途判断。普通主体提取不以保留它们为合格条件；也不能仅凭低Alpha就将真实头纱当柔光清除。
- 多主体：用户指定的提取对象优先。主体选择与细边缘处理是两个问题，不能用边缘阈值解决语义选择错误。
- 输出保护：尺寸/位置符合既有工具约定；原素材保留；结果可对比、入库、撤销及保存恢复；大图资源限制和取消行为继续独立验证。

## 证据解释

原9图基准测量的是“原Alpha还原”，其中情侣、花束的外围柔光也被计入真值。其0/9通过只说明这些模型没有完整还原该Alpha，**不能直接判定普通主体抠图0/9不可用**，不能作为默认主体提取的唯一发布门禁。

既有解析薄纱、真实人像细发丝、猫须和黑白背景边缘检查仍有诊断价值，但覆盖范围有限。固定标记试验的美术8.5/性能9.0属于该实验，不是整个产品或所有主体抠图的评分。改变验收口径不等于任何候选模型自动通过；也不改变已经测得的约11GB显存占用等客观结果。

下一轮主体验收应分别标注明确保留主体、明确去除背景、真实细节与可选外围效果，再检查漏抠/多抠和合成边缘。原始Alpha只在“用户明确要求精细透明度还原”的样本中作为全图真值；不事后修改原实验阈值或将失败记录改成通过。
