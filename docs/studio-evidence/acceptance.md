# 本地首版验收（2026-10-19，历史记录）

> 该记录描述最初的 MCP 版本。当前架构已改为本地桌面直连模型 API，最新验收见 `api-direct-acceptance.md`。

完成定义：可运行 Windows 桌面包，模块化提示词、独立素材、手动图层合成与保存导出形成可操作流程；线上模型必须实际返回结果后才能宣称全流程验收。

## 结果

本地首版可试用，完整平台尚未验收。阻塞是既有 MCP 地址握手返回 404、缺少已验证的图片与视觉分析模型配置。MCP 带参考图及异步结果自动回收仍需联调完善。没有把模拟提供商图片当成真实模型结果。

| 维度 | 自评 / 10 | 验证证据及剩余改进 |
|---|---:|---|
| 功能（全流程） | 8.8 | 本地保存、编辑、撤销、导出、原画布编排通过；真实分析/生图被服务连接阻塞，需有效服务配置后端到端验收 |
| 代码 | 9.4 | 独立 tsc、8 项模型测试、6 项 HTTP 模拟测试、Go 测试、生产构建通过；跨工作区版本回收仍应增加回归覆盖 |
| UI | 9.3 | 打包版两工作区实际截图检查；最小窗口尺寸及更多缩放比例需继续验收 |
| UX | 9.3 | 模块独立编辑、参考图职责、过期提示、版本不覆盖、手动合成；原画布与新工作台连接配置尚需统一体验 |
| 美术 | 9.4 | 使用已有 C 版真实素材进行图层合成，确认透明边缘和文字可编辑；新模型生成的一致性待实际出图检验 |
| 性能（示例规模） | 9.3 | 约 12.4 MB 工程读取 207–247 ms，实际导出 1024×1536；大型素材集和长时运行未压力测试 |
| 安全（本地边界） | 9.3 | 仅 loopback、跨站拦截、ID/工程校验、sandbox/contextIsolation、凭据加密与接口不回传验证；尚未独立安全审计 |

以上为本次实现自评，非第三方认证。全流程功能不达 9.3，不能称为完整平台完成或高质量完成。其余项为本地首版可交付水平；未达 9.5 的改进列在表中。原无限画布 AGPL 与参考项目 MIT 说明已保留，未发布软件或用户图片。
