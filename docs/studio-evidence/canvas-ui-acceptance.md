# 无限画布 UI 统一验收

日期：2026-10-20

## 范围与完成标准

共用按钮、主题、圆角和字体；常用操作直接可见，次要操作收进菜单；编辑、生成、模块更新、连线和撤销正常；浅深主题与窄窗口没有工具遮挡；桌面更新保留原工程。重点风险是菜单事件、浮层位置和窄窗口重叠。

## 变更

- 主栏常驻选择/移动、撤销/重做、文本、图片、导入、素材库；选中时显示删除。视频、音频、全景、导演台、配置、外观和清空收进更多，清空保留原确认。
- 内嵌节点直接提供适用的编辑、生图、存入素材库；信息、下载、字号收进更多，替换、裁剪、局部编辑等集中到图片处理子菜单。
- 节点、生成面板和缩放栏统一轻边框；移除工具条写死的黑色、厚阴影和等宽字体，选中色跟随主题。
- 镜头设置默认折叠；模型、尺寸、生成按钮保留直接入口。顶部去除重复连接入口，画布选择器改为共享组件。
- 复用 IconButton、Ant Design 和主题，不新增依赖或全局 CSS；主工具栏删除了约 200 行手写浮层/按钮逻辑。
- 画布用 overflow-clip，防止输入焦点引起隐藏容器滚动而造成工具条错位，内部文字仍可滚动。
- 画布容器不足 1000px 时，缩放栏移到主工具栏上方。
