## 本批验收范围

1. 正收缩必须是灰度 Alpha 最小值，负收缩必须是最大值；画幅外透明，保留孔洞，默认不改 RGB。用独立暴力像素基准验证。
2. 同一组用户本地照片参考与宠物样本，检查原图保护、输出尺寸、Alpha、白底/深色底边缘和放大细节。没有真值的画质不能由数值断言代替。
3. 一亿像素、嵌套组/图片/文字/旋转翻转/孔洞羽化/投影/调整图层，经真实顶部按钮连续导出并重开；检查像素一致性、耗时、进程内存。短测不等于长期无泄漏。
4. 正式桌面保留完整程序/profile 回滚，验证旧工程、素材和加密凭据。
