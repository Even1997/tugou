# 编辑器代码与功能审查

审查范围：调整图层、特效与图层/分组/蒙版/快捷键/历史/导出的衔接；回归原修图、填充、选区、工程持久化、共用 API 配置及本地访问保护。没有把局部验收扩展为整个产品的无缺陷保证。

## 发现及修复

| 严重度 | 问题 | 修复与证据 |
| --- | --- | --- |
| P1 | 解除分组丢掉组特效，组内调整会影响原组外的下方内容 | 共用 `ungroupLayer` 阻止此类有损拆组并说明原因，保留参数；`studio-review.test.mjs` 修复前失败、修复后通过 |
| P1 | 距离等整数参数允许输入小数，前端状态改变但后端拒绝保存 | 输入按参数精度归整并限幅，特效提交前校验；UI 输入 35.4 后保存/重开为 35 |
| P2 | 选区快捷键在捕获阶段抢走曲线删点；曲线又拦截 Ctrl+Z | 曲线区域与编辑器快捷键隔离，只拦截自己的操作键；带选区时删点及 Ctrl+Z/Y 通过 |
| P2 | 独立图层的特效边距全部累加，普通多图层场景也触发内存拒绝 | 取独立路径的最大边距，沿连续滤镜/嵌套路径累加；100 个独立投影从 8208 降为 90 像素边距，真实合成约 95 ms |
| P2 | 隐藏的实时蒙版来源带特效时，分块导出漏掉依赖边距 | 隐藏来源依赖仍参与计算；真实 Chromium 分块 alpha 最大误差由 95/255 降为 0 |
| P2 | 根层调整影响画布底色，但“合并为图片”忽略底色，改变画面 | 非透明画布上的根层调整合并明确阻止，提示先用背景图层或透明底；不静默烘焙或丢弃底色 |
| P2 | 参数重置与上一笔调参可能合并为同一撤销记录 | 重置作为独立历史事务，UI 验证一次撤销恢复重置前值 |
| UX | 编辑特效后无法直接返回对象工具 | 顶部增加“完成”，退出参数编辑而保留效果；900/1100/1500 窗口仍无溢出 |

核心文件：`layer-operations.ts`、`layer-panel.tsx`、`editor-tone.tsx`、`curve-editor.tsx`、`editor-selection.tsx`、`editor.tsx`、`tone-render.ts`、`editor-renderer.ts`、`image-export.ts`。没有增加运行时依赖或改写无关画布模块。

## 验收标准与结果

- 参数修改必须能保存恢复；非法输入不能使工程持续保存失败。重置、撤销/重做、锁定、特效编辑退出由真实界面验证。
- 分组/合并不能无提示地丢弃参数或改变作用范围；被阻止操作后原图层 JSON 保持一致。
- 隐藏蒙版来源、连续模糊与独立多特效均通过固定像素基准；不能以截图看起来相似代替比较。
- 全分辨率输出保持尺寸；本轮 10000×10000 调整图层 PNG 导出约 25.45 秒，角点、中心和条带边界采样正确。
- 类型检查、生产构建与 57 项本地单元测试通过；新增的分组回归有修复前失败证据。实际 UI、接口及桌面结果见下方最终核对。
- 截图 `editor-tone-shadow-900.png` 已人工查看；新增“完成”按钮和原参数均在顶部完整显示。

证据：`editor-tone-pixel-results.json`、`editor-tone-ui-results.json`、`editor-tone-export-results.json`、`editor-review-ui-results.json`、原修图/填充/选区回归结果，以及桌面核对结果。
