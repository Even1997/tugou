# 调整图层与图层特效验收

日期：2026-10-21。当前桌面：`release/editor-tone/CanvasStudio-win32-x64`。

## 交付范围与验收标准

1. 顶部“调整”增加 12 类非破坏调整图层；同组下方、剪贴、强度、显隐和选区转蒙版符合固定像素基准。
2. 顶部“特效”增加描边、投影、颜色叠加、内阴影、内外发光；支持图片、文字、形状和组，保存参数、再次编辑、停用、重置、移除与一次撤销。
3. 顶部参数行沿用现有组件；900/1100/1500 窗口不溢出。曲线弹层继承主题，键盘操作不会移动/删除图层。
4. 旧工程不被自动改写为新格式；新功能保存为 V5，工程列表、重开和导出完整。真实桌面更新前备份并核对项目与加密凭据。
5. 原尺寸输出；连续滤镜分块无接缝，极端内存负载明确拒绝，不隐式缩图。

## 实现与验证

- `tone-schema.js` 统一参数、默认值及白名单校验；模型只在使用新功能时写 V5。已补齐存储摘要版本识别，防止 V5 保存后被工程列表遗漏。
- `tone-pixels.ts` 使用逐通道 LUT、形状保持曲线插值、按文档坐标固定噪声与线性欧氏距离变换；常见调色不在每个像素重新计算幂函数。
- `tone-render.ts` 与共用合成器处理作用范围、透明度和扩展边缘；内侧特效保持原 alpha，外侧效果扩展范围。分块叠加采样余量涵盖连续模糊，而非只取最大半径。
- 类型检查、生产构建通过；56 项本地单元测试通过，包含固定数值、非法参数、透明度、旧工程及 V5 列表/保存恢复。
- `editor-tone-pixel-results.json`：12 类调整真实 Chromium 像素结果；组内隔离、剪贴、蒙版、调整混合模式、半透明边缘、6 特效；连续模糊和多特效分块最大误差 0。2048² 单曝光合成约 179 ms。
- `editor-tone-ui-results.json`：所有调整入口、色阶扩展参数、曲线加点/方向键/删点、蒙版、真实 PNG、6 特效并存/重开/停用/重置/移除/撤销/锁定；900/1100/1500 参数行高 43 px，无水平溢出。对应 `editor-tone-levels-*`、`editor-tone-balance-*`、`editor-tone-shadow-*` 与 `editor-tone-curve.png`。
- `editor-tone-export-results.json`：真实按钮导出 10000×10000，耗时约 28.6 秒；透明 PNG 输出尺寸和角点、中心、条带边界像素正确。
- 旧合成器、五种修图和内容感知填充像素回归通过：`editor-renderer-results.json`、`editor-retouch-pixel-results.json`、`editor-fill-pixel-results.json`。
- 原修图、填充和选区真实 UI 回归通过：`editor-retouch-ui-results.json`、`editor-fill-ui-results.json`、`editor-selection-ui-results.json`。9 项真实 HTTP 回归通过，含共用模型配置、跨来源拦截、非法路径、密钥不回传和工程往返；本地单元与接口合计 65 项。

## 适用边界

- 当前为 8 位 sRGB；色阶为整体 RGB，曲线支持主通道与独立 RGB，渐变映射为双色。尚未移植 Camera Raw 参数、RAW/16 位/ICC/CMYK，不能据此宣称与完整 Compositor 或专业印前软件等价。
- 画布上限仍为单边 30000、总量 1 亿像素。单次临时合成预算 384 MiB；超大半径、许多嵌套特效可能触发报错。当前滤镜在前端合成，不承诺所有参数组合实时。
- 大图测试是固定色块与单个调整，不代表复杂照片、多层滤镜和长时间操作的耗时。多 DPI、完整辅助技术与长期压力仍待补。
