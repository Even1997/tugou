# 本地修图工具验收

本轮按顺序接入仿制图章、修复、模糊、涂抹、液化；统一位于图层合成顶部“修图”入口，参数在固定第二行。桌面已更新为 `release/editor-retouch/CanvasStudio-win32-x64/CanvasStudio.exe`。

## 交付行为与完成标准

| 工具 | 实际行为 |
| --- | --- |
| 仿制图章 | Alt 点击或顶部“设置来源”取样；同一笔使用开始时的图片，重叠区域不会反复复制新画入的像素；支持跨笔画对齐，也可关闭对齐让每笔从取样点开始 |
| 修复 | 默认从邻近区域自动选取纹理；也可指定来源；用平滑边界色差校正将来源纹理融入目标亮度，保留目标透明度 |
| 模糊 | 局部高斯模糊，可调半径；同一笔按强度合成，新的一笔继续柔化 |
| 涂抹 | 随拖动携带并混合当前图层颜色，支持硬度与强度 |
| 液化 | 沿拖动方向推移像素，圆形范围渐弱，采用双线性采样；本轮是推移模式 |

- 五种工具均在当前图片图层原始像素上处理，与显示缩放独立；保留素材原图，只写图层位图副本。
- 选区限制写入范围；旋转、缩放、透视图层使用统一坐标映射。透明边缘使用预乘颜色运算，避免黑边。
- 一笔一个撤销事务，支持重做、保存重开和相同像素的 PNG 导出；锁定/非图片图层拒绝编辑；Esc 可取消临时笔触。
- 顶部提供直径、硬度、强度及当前工具专属参数，来源位置有十字标记，笔刷显示实际范围。900 px 窗口收起“修图”的文字标签，工具行仍为一行，参数行没有纵向裁切。
- 长拖动拆成笔刷步长，按帧处理队列；局部缓冲复用，不为每个笔刷点复制整张图片。沿用项目 30000 边长、1 亿总像素限制。

## 验证证据

- 41 项模型/图层/选区等单元测试及 11 项接口测试通过；类型检查、生产构建和桌面打包通过。接口测试使用隔离服务及模拟提供商，未调用真实模型。
- `editor-retouch-pixel-results.json`：实际 Chromium Canvas 验证固定来源、重叠取样不反馈、强度不重复叠加、修复黑斑/纹理与亮度匹配、模糊逐笔叠加与透明边缘、涂抹和液化的真实像素变化。五种工具逐像素验证选区外整块区域 RGBA 完全不变，并验证旋转/透视后的原图取样位置。
- `editor-retouch-ui-results.json`：五种工具均通过真实鼠标操作、一次撤销/重做、重开与 PNG 全图像素对照；验证 Alt/按钮两种取样及跨笔对齐、锁定保护、Esc 取消。1000 px 涂抹已观察到画面像素改变后再取消，响应约 23 ms，未提交临时位图。
- `editor-retouch-900.png`、`editor-retouch-1100.png` 已实际查看；自动断言工具行高 52 px，参数控件完全位于 43 px 参数行内，无页面横向溢出。
- `editor-renderer-results.json`、`editor-selection-ui-results.json`、`editor-ui-results.json`：原有混合、分组、排版、变换、蒙版、选区、画笔、合并和导出回归通过。历史 C 版 6 图层样本可渲染；它仅用于隔离回归，不会覆盖用户当前 5 图层工程。
- 原有完整界面回归中，真实导出按钮产出 10000×10000 PNG，通过尺寸检查；本轮离屏自动化窗口耗时约 76.5 秒。这是完整合成/分块提交测试，不能与下表的图层位图 PNG 编码耗时直接等同，也不能用离屏窗口代替普通桌面的性能结论。

### 100MP 原尺寸修图

使用本地 71 MB、10000×10000 彩色测试文件，40 px 笔刷，顺序执行五种工具并将图层结果编码为同尺寸 PNG。以下为本机本轮测量，不代表其他机器或长时多笔性能：

| 工具 | 准备 | 笔触处理 | PNG 编码 |
| --- | ---: | ---: | ---: |
| 仿制图章 | 415 ms | 861 ms | 1834 ms |
| 修复 | 169 ms | 66 ms | 1872 ms |
| 模糊 | 175 ms | 62 ms | 1859 ms |
| 涂抹 | 182 ms | 59 ms | 1860 ms |
| 液化 | 185 ms | 59 ms | 1827 ms |

首次冷读取明显慢于后续操作。工作画布约 400 MB，另加局部像素缓冲；测试的 `workingBytes` 是算法缓冲估算，不含解码图像、PNG 字符串、浏览器合成、历史等内存，不能视为进程峰值。已有预算与图像限制继续生效，并未声称具备磁盘瓦片缓存。

## 边界与剩余项

- 本轮取样来源是当前图片图层；文字/形状需先合并为图片，或使用已有图片层。未实现跨图层合成取样。
- 自动修复是邻近纹理匹配与边界校正，不是大范围内容感知填充或生成式去物体；复杂纹理可通过手动来源调整。透明背景缺少足够自动来源时会提示减小笔刷或手动取样。
- 液化本轮覆盖 Compositor 对应的推移行为，尚无膨胀、收缩、旋转或独立可重调形变网格。
- 1000 px 笔刷长拖动已验证可取消；更长时间连续大图编辑、更多照片、多 DPI/辅助技术仍需补测。当前本地 Canvas 处理尚未迁入 Worker/GPU。
- 后续按原顺序补平滑/直线与内容感知填充，再进入调整图层/特效、专业文件和色彩能力。本轮不宣称完成整个专业编辑器。
