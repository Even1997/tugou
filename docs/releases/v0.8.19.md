# 土狗 v0.8.19

- **自动保存**合并连续修改，后台写入至少间隔 10 秒，并避开正在进行的鼠标和触笔操作。仅拖动对象时，最终位置随下次内容保存、手动保存、切换工程或正常退出写盘。
- **图层属性**默认展开，可以手动收起，切换画板时保留当前状态。
- **文字框**随字号、字宽和行数自动调整，改字号与换行保留原坐标。手动设置宽高后使用固定尺寸，旧稿的定位框贴合可见文字，原排版保留。

## 安装与升级

Windows 下载 x64 安装器，macOS 按芯片选择 Apple Silicon（arm64）或 Intel（x64）DMG。升级前保存工程。Mac 安装后如使用 MCP，请重新连接。 [安装包与校验文件](https://github.com/Even1997/tugou/releases/tag/v0.8.19)
