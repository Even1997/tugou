# 土狗 v0.8.24

- 图层页和无限画布按需读取其他页签。打开工程只读取两个工作区各自的当前页，保存时复用未修改的页面文件。
- 无限画布在远景保留节点和连线，放大后加载预览。图层页按视口加载图片，远景使用缩略图，放近后恢复原图。导出使用原始素材。
- MCP 与桌面共用页签读取流程，支持跨页撤销，并保护仍被其他页签引用的素材。

旧多页工程首次打开时会自动转换，原文件将作为当时的上一版备份。手动备份时请复制整个工作区，以保留页签内容和素材。

## 安装与升级

Windows 请选择 x64 安装器。macOS 的 Apple Silicon 机型请选择 arm64，Intel 机型请选择 x64。 [安装包与校验文件](https://github.com/Even1997/tugou/releases/tag/v0.8.24)
