# 土狗 v0.8.23

- 图层画板支持像素、毫米、厘米、英寸和 PPI。导出的画板 PNG 保留印刷分辨率。
- 支持钢笔路径、锚点和曲线手柄编辑、黑白图片矢量化及 SVG 导出。密集路径可按编号定位、插入和删除锚点，MCP 支持相应编辑操作。
- 图层排版浮条和 MCP 均支持三种对齐参照与等距分布。多选对齐到选区或画布时，原有间距随整体移动保留。大选区的预览和首次测量在后台执行。
- 改善跨画板点选拖动、缩放、滚动和平移，修复画板切换闪白、双击文字重影及仅有备份的工程无法打开或删除的问题。

## 安装与升级

Windows 请选择 x64 安装器。macOS 请按芯片选择 DMG，Apple Silicon 使用 arm64，Intel 使用 x64。 [安装包与校验文件](https://github.com/Even1997/tugou/releases/tag/v0.8.23)
