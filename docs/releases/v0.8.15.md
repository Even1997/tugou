# 土狗 v0.8.15

本版完善 PPT 内容准备、设计流程与 MCP 联动，支持先确认大纲，再选择视觉设计或讲稿。

## 内容与讲稿

- 新增「页面 / 大纲」导航和「内容 / 设计 / 讲稿」面板，页序与实际幻灯片一致。
- 每页一个多行内容输入框，标题、正文、数据和配图说明可以一起写；支持撤销、切页和保存，内容草稿不会直接破坏现有排版。
- 讲稿独立保存在页面备注中，导出进入 PPTX notes，不出现在演示画面。

## AI 与 MCP

- AI 先整理大纲并等待确认，再让用户选择先做设计或先写讲稿；已有确认和选择直接复用。
- 设计分支保留视觉范围确认、方案板展示和选型；讲稿分支不改画面、不触发生图，完成一项后再询问是否继续另一项。
- 24 条 PPT MCP 命令覆盖大纲与内容、讲稿、页面、元素、字体、效果、预览和导出，界面与 AI 共用工程数据。
- PPT 截图直接返回 PNG 图片、页 ID、尺寸与版本信息，制作规则要求逐页看图，修正后重新截图；修复预览截图左侧误裁。客户端需支持 MCP 图片，截图要求窗口可见。

## 圆角与修复

- PPT 矩形圆角采用 0–100 程度，可联动或独立调整四角，缩放保持比例；拖动一次撤销，Esc 取消。
- MCP 与 PPTX 同步支持四角圆角，导出保留可编辑矢量；修正内阴影导出方向。
- 修复草稿回退时的误覆盖、MCP 同步后的错误冲突、内容数量边界，以及远页大纲定位。

安装前请保存工程，升级后重连 MCP。流程规则由 AI 客户端执行，不是应用内自动执行器；土狗截图不代表导出后 Office 显示完全一致。开启自动检查后，启动及每 30 分钟检查新版，跳过旧版本不影响本版提醒。Windows 尚无商业代码签名；Mac 使用 ad-hoc 签名，未经 Apple 公证，下载 DMG 后手动替换。
