# 土狗 v0.8.5

本版集中完善图片工具：本地上传、默认并排对比、同步缩放定位、手动下载离线组件，以及局部修改与抠图。包含画布组边框和更新提醒修复。

## 下载与更新

| 平台 | 安装包 |
|---|---|
| Windows x64 | `tugou-0.8.5-win-x64.exe` |
| macOS 13+ · Apple Silicon（M 系列） | `tugou-0.8.5-mac-arm64.dmg` |
| macOS 13+ · Intel | `tugou-0.8.5-mac-x64.dmg` |

Mac 另提供同架构 ZIP，所有平台附 SHA256 校验清单。Windows 使用 `latest.yml` 与 `.exe.blockmap` 接入检查、下载和安装更新；Mac v0.8.3 起检查并下载对应芯片的 DMG，校验后打开安装包，由用户保存退出并手动替换。更早的 Mac 版本请从发布页手动升级。

安装包体积：Windows 100.86 MiB、Apple Silicon DMG 107.86 MiB、Intel DMG 113.08 MiB；下载的字体与工具组件缓存另计。

## 图片预览与对比

- 处理完成默认进入「并排对比」，可切换「滑动对比」「仅原图」「仅结果」。
- 原图与结果共用缩放比例、中心位置和拖动定位，切换模式保留视图；支持适应窗口、100% 和鼠标滚轮缩放。
- 分辨率调整与超分按相同画面坐标比较，不因结果像素更多而错位；裁剪、扩图按记录的偏移定位。旋转等改变构图的工具保留真实结果，不承诺内容自动配准。
- 保留独立「编辑区域」入口，避免查看结果时误改选区或蒙版。
- 工具页可直接上传本地图片，支持多选；导入后自动选中并加入工程素材库。导入本身不会上传到云端。

## 工具界面与离线组件

- 统一右侧参数区、参数单位、预计输出尺寸和文字设置入口，修复说明浮层越界，改善窄窗口布局；切换工具只保留左侧入口。
- 本地 AI 工具未安装时显示云端图标、下载大小和位置，必须点击下载才开始，打开页面或重启不会自动下载。
- 下载显示圆形进度，支持取消和手动继续；校验完成后显示离线可用。超分与抠图可分别安装并保留彼此配置。
- 默认组件目录位于当前应用数据目录的 `components/tugou-components`；工具内可查看实际路径。首次下载需要联网，已安装组件可离线使用。
- 修复超分被 Python／抠图环境阻塞的问题，使用自动分块与真实推理进度；缺组件、参数错误和内存不足会提前提示。
- 主体抠图增加轻量 CPU 模型，保留精细模型和内存保护；新增边缘收缩、向内羽化。默认不改变边缘，过大参数可能损失发丝或薄纱。
- 轻量模型约 4.6 MB 是模型自身大小；当前抠图组件下载仍包含模型集合与相关环境，不能理解为整套组件只需 4.6 MB。

## AI 局部修改与扩图

- 工具页云端入口收敛为「AI 局部修改」和「AI 扩图」，已有处理结果仍保留。
- 局部修改支持直接涂画、擦除、撤销／重做、清空及保存原尺寸蒙版；只有主动开始处理才调用供应商。
- 手绘和素材蒙版支持向内羽化；预览、上传与本地合成使用一致的保护区域，修改区域外保留原图。
- 扩图上传画布使用边缘颜色延展作为上下文，结果保留原图区域；修复返回图片 EXIF 方向造成的尺寸误判。
- 模型选择、边缘参数、任务重试和结果记录同步接入 MCP。云端结果仍取决于供应商，复杂衣袖、线条与背景衔接需要人工检查，不能保证每次自然延伸。

## 画布与更新提醒

- 组合边框根据节点实际尺寸自动扩展；节点向内移动后自动收紧，保留组内位置和单步撤销。
- 发现新版本后显示全局提醒，包含更新内容、下载进度和完成状态；支持稍后提醒与后台下载，并避开输入、拖拽及其他弹窗。

## 验证与限制

发布前 Node 回归 411 项通过、1 项平台限定跳过、0 失败；运行时依赖审计 0 已知漏洞。Windows 包内页面 37 项、字体 17 项、同步对比与上传 26 项及包体检查 24 项通过。Mac 两种架构各通过基础包 16 项、字体 17 项、页面 37 项、同步对比与上传 26 项以及完整 DMG 下载／挂载 6 项检查。三端实际程序均可连接 MCP，渲染错误为零。详见[发布验收记录](../engineering/release-v0.8.5.md)与[Mac 原生构建](https://github.com/Even1997/tugou/actions/runs/40916980095)。发布回归不调用用户的收费模型。

公开后 23 项匿名更新／下载检查通过：Windows v0.8.4 和 Mac 双架构发现新版，10 个附件齐全，校验摘要一致，安装包与更新文件的公开 Range 下载正常。

- Windows 尚无代码签名，Mac 为 ad-hoc 签名、无 Apple Developer ID 公证，首次打开可能遇到系统提示。Mac 更新不会自动覆盖运行中的应用。
- 更新、首次字体／组件下载依赖网络和资源源可达；离线时使用已缓存字体与已安装组件。
- 原生 CI 与隔离工程测试不等同于全部实体设备、触控板、系统权限、超大图和长期大工程验收。
- 本地抠图精度取决于模型和素材；AI 扩图的细节自然程度仍需人工判断。OCR 字体仍需复核。

保留 Apache-2.0 自有代码许可与第三方字体、模型、运行时的原始许可。重要工程建议备份，保留当前数据目录。
