# 土狗 v0.8.14

本版新增 PPT 创作与 MCP 操作，完善图层修图、PSD 文件互通和设置体验。

## PPT 创作

- 同一工程可管理多份 PPT，支持 16:9 / 4:3、页面管理、文字 / 图片 / 形状编辑、备注、预览和全屏演示，以及可编辑 PPTX 导出。
- 共用字体库，页面元素与图层列表同步选择、排序、隐藏和锁定；文字、图片和形状可设置外阴影、内阴影及边框颜色和粗细。
- 22 条 PPT MCP 命令覆盖文稿、页面、元素、字体和效果、PNG 预览、演示控制与导出；支持批次撤销、实时版本校验和受限目录导出。升级后重连 MCP 客户端。
- 收紧 PPT 字号、图标、卡片和侧栏布局。

## 图层与修图

- 增加七项照片调色、滑块预览、按住对比与副本修图；调整面板在原右侧栏左边占位展开。
- 属性栏增加内外阴影及边框效果卡片，操作按钮统一灰底。
- 基础 PSD 导入支持转换报告与可撤销的新画板；导出支持分层像素或合并图像，后台处理可取消。

## 设置与界面

- 通用、外观、画布、通知、文件存储、模型、MCP、快捷键、更新、关于独立分类，统一卡片和文字层级。
- 新增启动默认页、减少动效、网格间距、拖动吸附、小地图默认状态及滚轮缩放 / 平移偏好。
- 菜单和更新页增加 GitHub 入口及 ⭐️ 支持提示。

PPTX 导入后续提供；PPTX 不嵌入字体，GIF 导出首帧。PSD 为基础互通，不保证复杂 Photoshop 特效和文字原样编辑，导入前请查看转换报告；PSD 文件读写暂未接入 MCP。
