# v0.8.18：更宽敞的工作区与文字选区编辑

本版重点整理图层和 PPT 的编辑空间，让常用工具更易找到，并支持直接在画布修改文字和局部格式。

- **局部文字格式**：双击图层或 PPT 文字进入原位编辑，选中一部分后单独修改字体、字号、颜色和加粗。支持保存重开、撤销和导出；没有选中文字时，格式用于接下来输入的内容。
- **图层工作区**：单列左侧工具栏可滚动，带上下提示；图层列表常驻，点击对应图层可开关属性，调整和导航位于图层上方。画板尺寸通过属性调整。
- **PPT 工作区**：顶部集中插入与常用文字格式，左侧缩略图，右侧属性、图层、内容与讲稿面板可收起。
- **直线与端点**：图层和 PPT 可拖拽画线、编辑端点、约束角度并调整描边；修复水平和垂直粗线裁切。
- **全局整理**：统一主要页面的控件、层次与浅深主题，增加可搜索帮助，补充保存重试和任务恢复反馈。

## 安装与升级

安装包正在准备，待三平台附件与校验齐全后公开。最终下载入口为 [v0.8.18 Release](https://github.com/Even1997/tugou/releases/tag/v0.8.18)。

升级前保存工程；Windows 使用安装器，Mac 下载对应芯片的 DMG 手动替换，升级后重连 MCP。当前 Windows 无商业代码签名，Mac 为 ad-hoc 签名、尚未完成 Apple 公证。

PPTX 不嵌入字体，导出后仍需在 Office / WPS 检查排版；实体 Mac、高 DPI、真实输入法候选窗与复杂长文性能待进一步使用验证。详见[发布记录](../engineering/release-v0.8.18.md)与[待测试](../progress/pending-test.md)。
