# 土狗 v0.8.21

本版接替 v0.8.20 候选版，包含其全部改动及发布验收发现的画布布局修复。

- 大工程切换画板、选择图层、拖动和保存更快。预览会复用已解码的大图，并减少屏幕外 GIF 刷新。
- 图层和 PPT 双击文字时保留原样。点击云图标可下载字体或指定字重，点选字体才应用。
- MCP 支持在图层和 PPT 使用本机、云端及已发布的自定义字体。可用 `font.download` 按名称、字重或目录 ID 下载云字体，下载后可离线使用。
- 画布在连续收到生成结果时合并节点尺寸更新，修复发布测试中出现的布局测量错误。

## 安装与升级

Windows 请选择 x64 安装器。macOS 请选择对应芯片的 DMG，Apple Silicon 用 arm64，Intel 用 x64。升级后如需使用 MCP，请重新连接。 [安装包与校验文件](https://github.com/Even1997/tugou/releases/tag/v0.8.21)
