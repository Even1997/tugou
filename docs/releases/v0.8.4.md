# 土狗 v0.8.4

本版加入同项目多画布与多合成，完善 MCP 的界面检查能力，并将字体改为按需下载。同步发布 Windows x64、Mac Apple Silicon 与 Intel 安装包。

## 下载与更新

| 平台 | 安装包 |
|---|---|
| Windows x64 | `tugou-0.8.4-win-x64.exe` |
| macOS 13+ · Apple Silicon（M 系列） | `tugou-0.8.4-mac-arm64.dmg` |
| macOS 13+ · Intel | `tugou-0.8.4-mac-x64.dmg` |

Mac 另附 ZIP；各平台提供 SHA256 校验清单。Windows 的 `latest.yml` 和 `.exe.blockmap` 用于应用内检查、下载和安装更新。Mac v0.8.3 起支持自动检查和下载对应架构 DMG，下载校验完成后打开安装包，由用户保存退出并手动替换应用；不自动覆盖运行中的程序。更早的 Mac 版本需要从发布页手动升级。

## 多画布、多合成

- 一个工程可创建多张无限画布、多份合成，通过顶部文字页签切换；支持新增、重命名、复制、删除。
- 页面内容和视图独立，素材、提示词与配方共享。复制生成新的对象 ID；每种页面至少保留一页。
- 生成任务完成后将结果放回原画布，避免切页后写错位置；运行任务所在页面受到删除保护。
- 保持工程统一撤销历史，跨页撤销会定位到受影响的页面。保存重开保留页面和内容。
- 修复新增／重命名弹窗“确定”不提交，覆盖鼠标点击、回车提交、空名称禁用与取消行为。

## MCP 与界面验收

- 当前提供 149 个领域命令。新增 `page.list/activate/create/rename/duplicate/delete`，外部 Agent 可管理多页面；编辑前先切换目标页。
- `ui.capture` 直接返回真实界面 PNG，遮挡密码和连接敏感信息。
- `ui.inspect` 返回控件、滚动范围、折叠与加载状态，并明确截图覆盖范围；截图不会包含所有屏幕外内容。
- `ui.navigate` 支持工作区切换、画布定位和长列表滚动；`ui.restore` 恢复原视图与页面，不回滚工程内容。
- 保留实时 revision 冲突保护、编辑现场保护和写请求去重；不确定结果的写入不会盲目重试。

## 字体下载与离线使用

- 保留 55 个字体家族、141 个字重目录、搜索和粗细选择，不再把完整字形文件重复打进安装包。
- 未下载字重显示云端图标，点击后显示圆形进度；校验成功后云端图标消失，可离线排版和导出。
- 首次获取需要网络；离线时只能使用已下载字体、本机字体及已发布的自定义字体。
- 字体保存在应用工作区的 `font-cache`，不安装进系统字体目录；资源来自独立字体 Release，保留原始许可。
- MCP `font.library` 提供各字重状态，`font.download` 支持下载和复用本地缓存。

## 管理与修复

- 增加项目删除、自定义字体删除、取消发布和导入图集移除，提供确认及运行任务保护；共享资源和恢复副本按现有策略保留。
- 修复配方节点传入生成流程时漏掉模块与参考图，保留保存的快照、局部覆盖和参考图职责。
- 窗口标题显示工程名称；完善常用确认、取消和模型配置保存的桌面回归。

## 验证与边界

发布构建会核验版本、安装包、原生模块、MCP、页面操作和字体离线导出；详细结果见 [发布验收记录](../engineering/release-v0.8.4.md)。测试采用隔离工程和模拟供应商，不调用用户的收费模型。

- Windows 尚未代码签名；Mac 使用 ad-hoc 签名，尚无 Apple Developer ID 签名和公证，系统可能出现首次运行提示。
- 更新和首次字体下载依赖 GitHub 可达；离线不能首次获取尚未缓存的字体。
- 未把 CI 检查视为所有实体设备、Gatekeeper 人工放行、长期大工程及全部历史版本升级的保证。
- 本版增加多页面工程数据。旧版本不了解非当前页内容，升级后编辑多页面工程不建议再降级保存；重要工程请保留备份。
- 字体 OCR、特殊设计字形仍需人工复核，字体处理依赖可用的本地运行环境。

保留 Apache-2.0 自有代码许可及第三方字体、运行时的原始许可。
