# 土狗 v0.8.9

本版优化合成页面多图片图层的渲染性能，补齐工具原图缩放，并让运行中的应用定期检查新版本。

## 合成页面更流畅

- 普通图片图层复用临时画布，仅拷贝实际覆盖区域，减少平移和缩放时的分配与拷贝。
- 200 张含透明、旋转图片的本机对照测试中，渲染耗时中位数从约 402 ms 降至 258 ms，减少约 36%；每帧临时画布创建从 200 次降至 1 次。这是特定测试场景的渲染数据，不代表所有工程的整体帧率。
- 保持原尺寸导出的像素一致，验证拖动、撤销、重做；蒙版、混合、剪贴、绘画预览等复杂路径继续使用原有渲染方式。

## 原图也能放大查看

- 图像工具在尚未生成处理结果时，也能缩放、拖动查看原图。
- 新增“查看原图”入口，打开独立图片查看器，支持适应窗口、原始像素和缩放。
- 保留局部修改的框选和涂画操作，不影响原图与结果的同步对比。

## 主动检查更新

- 开启自动检查后，每次启动约 15 秒检查一次；运行期间约每 30 分钟检查，检查失败约 5 分钟后重试，切回窗口时按间隔补查。
- 新版本提示仍会避开正在编辑、拖动或其他弹窗；同一版本选择“稍后提醒”后保留 24 小时缓冲。
- 下载与安装仍由用户控制，安装前保留未保存工程及运行任务保护。
- 旧版应用需先升级至本版，才能使用上述新检查频率。

## 下载与更新

| 平台 | 安装包 | 更新方式 |
|---|---|---|
| Windows x64 | `tugou-0.8.9-win-x64.exe` | 应用内检查、下载，确认后安装 |
| macOS 13+ Apple Silicon | `tugou-0.8.9-mac-arm64.dmg` / ZIP | 应用内检查并下载 DMG，手动替换 |
| macOS 13+ Intel | `tugou-0.8.9-mac-x64.dmg` / ZIP | 应用内检查并下载 DMG，手动替换 |

安装前请保存并关闭土狗。Windows 尚未配置商业代码签名；Mac 使用 ad-hoc 签名，未进行 Apple 公证，首次打开可能遇到系统安全提示。字体和可选工具仍按需下载，已下载内容可离线使用。

## 验证范围与已知限制

Windows 已完成更新逻辑与弹窗、原图查看、合成像素一致及画板导出专项检查。Mac 两种架构随发布执行原生安装包检查。性能提升依赖图层类型和设备；超大图、长期编辑以及大量复杂效果仍需持续优化。此版不改变工程格式，不降低图片导出分辨率。
