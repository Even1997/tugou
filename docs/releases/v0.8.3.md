# 土狗 v0.8.3

本版完善 Mac 免费更新流程，并同步提供 Windows x64、Apple Silicon 与 Intel Mac 安装包。Mac 无需付费 Apple 开发者账号即可检查新版、下载安装包；最后一步保留手动替换，应用不会自行退出或覆盖正在使用的程序。

## 下载

| 系统 | 安装包 |
|---|---|
| Windows x64 | `tugou-0.8.3-win-x64.exe` |
| macOS 13+，Apple Silicon（M 系列） | `tugou-0.8.3-mac-arm64.dmg` |
| macOS 13+，Intel | `tugou-0.8.3-mac-x64.dmg` |

Mac 另附同架构 ZIP；各平台均附 SHA256 校验文件。体积约 1 GiB，主要来自内置中文字库。

## Mac 更新方式

- 「设置 → 更新与关于」默认自动检查稳定版，约每天一次，也支持手动检查。
- 按当前应用架构选择正确的 DMG。默认点击下载，可开启“自动下载更新”。
- 下载显示实际进度和字节数；网络中断后重新检查并下载，可从已有部分继续。
- 下载完成后核对文件大小和 SHA256，点击“打开安装包”前再次检查，损坏或被替换的文件不会打开。
- 打开 DMG 后，先保存工程并退出土狗，再将 `Tugou.app` 拖入 Applications 替换。保持原用户数据目录，不删除工程。
- 不自动重启、不静默安装、不修改 macOS 安全设置；不依赖 `latest-mac.yml`。
- 旧版 v0.8.2 及更早 Mac 应用尚无此下载通道，首次升级到本版需从发布页手动下载安装。安装本版后，才能使用该通道获取后续版本。
- 需要将应用安装到 `/Applications` 或用户的 `Applications`；从 DMG 或源码预览直接运行不启用更新。

## Windows 与界面

- Windows 保留应用内检查、下载、“重启并安装”，以及未保存工程和运行任务的安装保护。
- 同步发布 `latest.yml`、EXE 和 `.blockmap`，供已安装的旧版发现本次更新。
- Mac 下载/就绪/手动替换提示覆盖简体中文、繁体中文、English、日本語、한국어。
- 更新下载期间不再把更新操作显示为“保存中”；清除过期版本提示，下载进度从零重新统计。

## 验证与已知限制

- 发布前对版本比较、双架构选择、错误提示、断点续传、校验失败、缓存篡改及 Windows 更新保护进行回归。
- 设置页检查覆盖真实 IPC、下载进度、手动打开分支、五种语言窄窗口和浅深主题。
- Mac 构建在两种原生架构 CI 上验证包体、程序启动和 MCP，并通过包内控制器完整下载实际 DMG、校验与挂载验证。
- Mac 为 ad-hoc 临时签名，尚未 Apple Developer ID 签名和公证，首次运行仍可能出现系统安全提示。请按系统「隐私与安全性」提供的允许选项操作，不要关闭全局安全保护。
- Windows 尚未代码签名，可能提示未知发布者。公开下载依赖 GitHub 可达；网络/限流/缺失附件会提示失败，不误报最新版。
- 原生 CI 检查不等于全部实体设备、Gatekeeper 用户交互、长时间大工程及所有历史版本数据迁移验收。

保留 Apache-2.0 自有代码许可及各第三方字体、运行时的原始许可。
