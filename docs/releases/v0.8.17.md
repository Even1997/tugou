# 土狗 v0.8.17

本版集中改善工程保存、素材复用、PPT 编辑及导入界面。

- **自动保存**：编辑后自动保存，合并连续操作；工程切换和关闭共用保存队列，保存失败保留编辑现场并提示重试。
- **保存到素材**：画板和图层右键可将当前渲染结果保存为 PNG 素材，继续复用。
- **PPT 视图**：Ctrl＋滚轮平滑缩放，空格＋鼠标左键拖动视图，点击倍率恢复适应窗口；缩放范围 10%–400%。
- **PPT 圆角**：编辑单位改为像素，支持四角联动或独立设置，预览、保存、MCP 和矢量导出共用半径计算。
- **界面整理**：优化新建 PPT 弹窗与下拉、图片 / PSD 导入入口和处理反馈，精简重复说明并上移主要操作。
- **工程菜单**：工程操作集中到左上角，移除右上角更多菜单及重复任务、手动热更新入口。

本版提供源码、Windows x64 安装包、Mac arm64 / x64 的 DMG 和 ZIP，以及更新资源和 SHA256 校验文件。

安装前保存工程，升级后重连 MCP。Windows 使用安装器更新；Mac 下载对应芯片的 DMG 手动替换应用。当前 Windows 无商业代码签名，Mac 为 ad-hoc 签名且未完成 Apple 公证，安装方式与前版一致。

原生安装包、交互和公开更新结果见 [发布验收](../engineering/release-v0.8.17.md)。用户体验确认、复杂大文稿性能、高 DPI 和实体 Mac 触控板等待验证项继续保留在 [待测试](../progress/pending-test.md)。
