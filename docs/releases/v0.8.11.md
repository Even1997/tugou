# 土狗 v0.8.11

本版新增 GIF 动图制作和合成动画导出，指定帧使用滑动器选择，并简化菜单、修复画布平移。

## GIF 制作与显示

- 在“工具 → 动图 → GIF 动图制作”导入多张图片，调整帧顺序、每帧时长、输出尺寸和循环方式，自动合成为 GIF。
- 制作结果可保存、加入画布或合成；素材库和画布支持 GIF 动画显示，保存原图时保留动画。
- 将 GIF 拖入合成页即可添加动画图层；空白合成页会自动创建匹配尺寸的画板。

## 滑动选帧与导出

- 合成页支持播放、暂停和滑动选帧，导出窗口同步预览选中的帧。
- 选择 PNG 可导出指定帧；选择 GIF 可通过开始、结束帧滑动器导出所选范围。
- 合成结果保留可见图层、背景和帧时长；多个动画按最长一轮的时间轴合成。

## 编辑体验

- 精简添加节点菜单，移除冗余的文本生成、图片生成、导入图片入口及底部快捷键提示。
- 模型连接仅保留 API Key 方式，统一左侧菜单对齐；已有 API 供应商配置保留。
- 修复按住空格拖动画布时分组、节点或缩放手柄抢占拖拽的问题；输入框空格和自定义平移快捷键保持可用。

## 使用说明

GIF 最多 240 帧、单边最多 4096 像素、累计最多约 6400 万像素；复杂照片或较长动画建议降低尺寸或减少帧数。GIF 使用 256 色和二值透明；制作工具导入 GIF 时取首帧，合成页可保留原动画。GIF 合成导出默认循环播放。

Windows 未配置商业代码签名；Mac 使用 ad-hoc 签名，未进行 Apple 公证。Mac 更新下载 DMG 后手动替换。用户原有工程不会因安装更新而主动删除。
