# 土狗 v0.8.7

本版让图片生成真正并发执行，提供默认 8 路、可调 1–32 路的共享额度；同时修复更新弹窗和设置页直接显示 HTML 源码的问题。

## 下载与更新

| 平台 | 安装包 |
|---|---|
| Windows x64 | `tugou-0.8.7-win-x64.exe` |
| macOS 13+ · Apple Silicon（M 系列） | `tugou-0.8.7-mac-arm64.dmg` |
| macOS 13+ · Intel | `tugou-0.8.7-mac-x64.dmg` |

安装包体积：Windows 100.90 MiB、Apple Silicon DMG 107.78 MiB、Intel DMG 113.03 MiB。下载的字体与工具组件缓存另计。

Mac 同时提供 ZIP，各平台附 SHA256 校验清单。Windows 配套发布 `latest.yml` 和 `.blockmap`，支持自动检查、下载及确认后安装；Mac 自动检查并下载对应芯片的 DMG，校验后打开，由用户保存退出并手动替换应用。

请先保存工程再更新。字体和本地 AI 工具组件继续按需下载，已有工程、字体和组件缓存沿用。当前已安装版本的更新说明显示方式由旧客户端决定；安装本版后，新版更新说明会正常排版。

## 图片生成并发

- 同一生成台的多张图片拆为独立 `n=1` 请求，同时发往供应商；不同生成台、配方、角度生图和 MCP 共用实际图片请求额度。
- 在「设置 → 模型连接 → 图片生成并发数」选择 1–32 路，默认 8 路。保存立即生效，完整退出重开后保留；支持简体中文、繁体中文、英语、日语和韩语。
- 调高上限立即补充排队请求；调低时已发出的请求继续完成，新请求等待空位。文本与本地工具保持原有串行方式。
- 并发数是所有生成台共享的同时请求上限；单台一次生成数量仍为 1–15 张。多个生成台不会将总请求数相乘。
- 图片按提交顺序编号，供应商返回先后不会改乱节点；保留原结果占位节点、连线和位置。
- 部分失败或请求超时时保留已成功保存的图片，任务面板说明成功／失败数量；全部失败可显式重试，不自动追加收费请求。
- 取消会停止该任务尚未发出的请求，并向正在执行的连接发送取消信号；已提交请求是否收费仍由供应商决定。其他生成台继续运行。
- 同时返回相同内容的图片仍分别入库，资源写入按顺序进行，避免 Windows 同名文件替换冲突。

MCP 沿用现有 `generation.start`、`task.cancel`、`task.retry` 和 requestId 幂等保护，无需修改客户端配置。

## 更新说明显示

- 更新弹窗与设置页共用排版组件，显示 HTML、Markdown 和纯文本，保留标题、列表、表格、代码及换行。
- 清理脚本、事件、样式和外部图片；链接由主进程再次校验，只打开本仓库的 HTTPS 页面，不跳转应用当前界面。
- 保留稍后提醒、下载进度、安装前工程保护和多语言界面。

## 验证与边界

实现阶段的完整逻辑回归为 433 项通过、1 项平台跳过；Windows 隔离桌面与 MCP 24 项、完整进程重启 3 项通过，验证默认值、设置保存、1／8／16／32 路上限、动态调整、取消、部分失败、参考图、结果顺序及未保存内容。更新说明专项 46 项通过。测试使用独立目录与本地模拟供应商，不触发外部模型费用。

Windows 包体／更新文件 36 项核对、包内并发与重启 27 项、更新说明 46 项通过。Mac 两架构各 175 项原生包检查通过，包含并发与设置恢复、说明排版、字体、MCP、真实程序启动、完整 DMG 下载与挂载；意外渲染错误为零。原生流程见 [GitHub Actions](https://github.com/Even1997/tugou/actions/runs/41151121238)。

公开后 23 项匿名检查通过：Windows 从 v0.8.6 发现新版，Mac 两架构选择各自 DMG，校验清单与 GitHub 摘要一致，7 个附件可公开 Range 下载。完整 DMG 下载与挂载在原生 CI 的本地 HTTP 流中验证，没有覆盖安装用户实例。

安装包与各平台原生发布检查见[本版发布验收](../engineering/release-v0.8.7.md)。上述实现阶段结果不等同于全部安装包测试重跑。

- 并发提高的是客户端发请求的能力，实际速度仍取决于供应商的并发额度、限流和排队。请按供应商额度设置，不能承诺按并发数成倍提速。
- 长时高分辨率大批量请求、实体 Mac 输入法／触控板和系统缩放仍需实机检查。
- Windows 尚未代码签名；Mac 使用 ad-hoc 签名，未进行 Developer ID 签名及 Apple 公证。

自有代码采用 Apache-2.0；第三方字体、模型、运行时和依赖遵循各自原始许可。
