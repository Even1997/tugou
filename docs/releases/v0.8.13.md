# 土狗 v0.8.13

本版新增图片节点局部生图，将全部 20 个图像工具接入画布，并同步开放 MCP 操作。

## 画布创作

- 图片节点支持画笔、矩形、圆形圈定修改区域，直接显示蓝色区域与笔刷粗细；连接生成台后随原图和提示词一起生图，结果保留为右侧新图片。
- 全部 20 个工具可创建工具台，设置参数、连接图片并执行；支持双图输入、GIF 多帧排序与逐帧时长，结果可继续串联或分支连接。
- MCP 同步支持工具台创建、参数设置、连线、执行前预览和任务处理；局部区域也可通过 MCP 绑定与清除。升级后重新连接客户端。

## 工具与素材

- 素材库支持右键删除，保留引用保护、确认与撤销，不删除原文件。
- 修复 GIF 制作预览在多帧和窄窗口下溢出、遮挡控件的问题。
- 移除工具中的框选提取、选区替换和 AI 局部修改入口；局部生图统一使用图片节点画笔。

工具流程仍为手动逐节点执行。局部修改效果取决于所用供应商对蒙版的支持；AI 扩图及生图使用配置的模型，可能产生费用。

安装前请保存工程。开启自动检查后，客户端启动及运行中每 30 分钟检查新版本；跳过旧版本不影响本次新版提醒。Windows 未配置商业代码签名，Mac 使用 ad-hoc 签名且未经 Apple 公证，下载 DMG 后手动替换。
