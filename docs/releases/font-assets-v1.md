# 土狗字体资源 v1

这是字体下载资源，不是应用程序更新。包含现有字体目录的 55 个系列和 141 个可选字形文件，保留原有字重；源码目录中另有 5 个未被当前目录引用的文件，不作为可选字体发布。

土狗只在需要时下载对应文件，以 SHA256 和文件大小校验，缓存后可以离线使用。资源名由原始文件摘要组成；不会安装到系统字体目录。已经下载的文件不依赖本发布页持续联网。

`catalog.json` 记录字体系列、字重、原始来源、文件大小和 SHA256；`FONT-LICENSES.txt` 包含原始许可及来源说明。字体文件保持原始内容，各字体使用自己的原始许可证，不由土狗的 Apache-2.0 许可替代。原始授权和来源也随应用分发。

此资源标为预发布且不设为 Latest，仅用于避免进入应用更新通道。以后变更文件将使用新的资源版本和摘要，不覆盖当前文件。
