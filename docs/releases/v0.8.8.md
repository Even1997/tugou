# 土狗 v0.8.8

本版增加合成画板右键菜单、批量原尺寸图片保存，以及独立下载的“可见水印修复”和“元数据清理”工具。

## 下载与更新

| 平台 | 安装包 |
|---|---|
| Windows x64 | `tugou-0.8.8-win-x64.exe` |
| macOS 13+ · Apple Silicon（M 系列） | `tugou-0.8.8-mac-arm64.dmg` |
| macOS 13+ · Intel | `tugou-0.8.8-mac-x64.dmg` |

Mac 同时提供 ZIP，安装包附 SHA256 校验清单。Windows 配套 `latest.yml` 与 `.blockmap`，支持应用内自动检查、下载和确认后安装；Mac 自动检查并下载对应芯片的 DMG，校验后打开，由用户保存退出并手动替换应用。

请先保存工程再更新。工程、字体和组件缓存沿用；可选字体与工具仍按需下载，不随主安装包携带完整资源。

## 合成画板右键与批量保存

- 在画板标题、画板内部或图层列表的画板行上右键，可保存图片、批量保存、编辑、复制和删除画板。
- 保存对应右键目标，支持直接保存当前未激活的画板。删除需要确认，复制与删除可撤销。
- 批量窗口列出当前合成的全部画板及像素尺寸，支持逐个勾选、全选和清空；选择一次文件夹后逐张保存。
- 同名图片自动编号，避免覆盖已有文件。提供进度与取消，已保存图片保留；部分失败后可以继续保存剩余画板。
- 画板保存为无损 PNG，按画板实际宽高输出，保留透明或实色背景；屏幕缩放、预览比例和缩略图不会降低导出分辨率。素材保存仍使用原图尺寸。
- 保存不修改工程内容，不清空撤销／重做记录。超出既有安全尺寸时明确报错，不自动缩小图片。

## 可见水印修复

- 在智能工具中提供独立入口，支持自动检测、框选与涂画修复区域，采用本地 OpenCV 路径处理。
- 自动与框选模式支持批量处理；涂画只应用于当前图片，避免将一个蒙版误用到其他素材。
- 原始素材保留，结果进入共享素材库，可继续同步对比或导出。修复按 EXIF 显示方向定位，保留 alpha 与 ICC。
- 复杂背景上的修复效果依赖水印形态与周边内容，自动模式未发现支持的水印时保留原文件，不承诺所有水印无痕修复。

## 元数据清理

- 独立查看原图可读字段与清理报告，清理 EXIF／XMP／IPTC 等元数据，使用本地 ExifTool。
- 保留原格式，不重绘图片；比较解码像素、ICC、方向及 PNG 显示信息，不一致时拒绝将结果入库。
- ICC、方向等显示必需字段不计为残留；未能清理的可读字段明确展示。不处理像素内的隐形标记。

## 手动下载与 MCP

- 两个工具分别下载，只有点击“下载工具”或“继续下载”才联网安装；查看状态、进入页面或 MCP 调用不会隐式下载。
- 下载提供进度、取消和显式重试，安装完成后可离线处理；首次安装需要网络。组件保存在用户数据目录 `components/cleanup-tools/`。
- 水印组件需要独立 Python 运行环境，Windows 实测环境、解释器和缓存合计约 1.1 GiB，建议预留 2 GiB；元数据组件 Windows 安装约 33 MiB。组件不扩大主安装包到这一体积。
- MCP 增加元数据检查 `image.metadata`，`image.process` 支持 `operation: watermark / metadata`；水印方式为 `auto / region / mask`，复用任务进度、取消和 requestId 去重。`tools.status` 可查询独立工具状态。

## 验证与边界

实现阶段：画板相关逻辑 22 项、隔离 Windows 桌面 26 项通过，实际检查 4096×3072 画板、2048×1024 原素材、透明像素、取消、同名、剩余重试和历史保留；清理工具相关逻辑 52 项、真实组件 37 项、隔离桌面／MCP 17 项通过。以上是实现阶段证据，不等同于本次重新执行完整测试。发布附件和更新文件核对见本版发布验收记录。

水印工具支持 8 位 RGB／普通灰度的静态 PNG、JPEG、WebP，上限 2400 万像素；CMYK、16 位和灰度 ICC 输入需先转换。Mac 新清理组件的真实安装与处理、实体 Mac 输入法／触控板及大批量超大图压力仍待专项验收。

Windows 尚未代码签名；Mac 使用 ad-hoc 签名，未进行 Developer ID 签名及 Apple 公证。自有代码采用 Apache-2.0，第三方工具与依赖遵循各自原始许可；独立下载不免除许可义务。
