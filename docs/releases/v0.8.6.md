# 土狗 v0.8.6

本版优化画布图片查看、生图参数与图像工具布局，修复拉线白屏和中文输入法标点重复。工程、撤销记录和用户提示词继续保留。

## 下载与更新

| 平台 | 安装包 |
|---|---|
| Windows x64 | `tugou-0.8.6-win-x64.exe` |
| macOS 13+ · Apple Silicon（M 系列） | `tugou-0.8.6-mac-arm64.dmg` |
| macOS 13+ · Intel | `tugou-0.8.6-mac-x64.dmg` |

安装包体积：Windows 100.88 MiB、Apple Silicon DMG 107.80 MiB、Intel DMG 113.00 MiB。下载的字体和组件缓存另计。

Mac 同时提供 ZIP，三端附 SHA256 校验清单。Windows 的 `latest.yml`、EXE 与 `.blockmap` 配套发布，支持自动检查、下载和安装。Mac v0.8.3 起检查并下载对应芯片的 DMG，校验后打开安装包，由用户保存退出并手动替换；更早版本请从发布页手动下载安装。

字体和本地 AI 组件继续按需下载，不重新打入完整字库或模型缓存；工具组件仍需手动点击下载。已下载的字体和组件可离线使用。

## 画布图片查看与节点编辑

- 双击画布图片打开无边框图片查看器，查看区域只显示图片；支持滚轮缩放、拖动、适应窗口、原尺寸和 Esc 退出。
- 名称与生成提示词放在右侧节点设置，查看图片不会改动工程或增加撤销记录。
- 从节点拉线到空白处正常弹出可连接节点菜单，选择后自动连线，修复此前白屏；取消和撤销继续可用。
- 生成台张数改为数字输入，支持 1–15 张，保留上游继承和生成中禁用状态。

## 生图比例、分辨率与质量

- 比例、分辨率档位与质量独立设置；提供九种常用比例、自动／1K／2K／4K 以及自定义宽高。
- 根据最终模型筛选可用选项并在提交前校验；节点、侧栏、配方、MCP 与重试共用规则。
- 发送请求时根据用户选择自动附加画幅比例、横竖方向和目标像素说明，选择自动时不追加。用户看到、编辑、复制和保存的提示词仍为原文。
- 同时发送合法的尺寸与质量参数，记录请求尺寸和实际返回尺寸；供应商返回尺寸不符时保留原图并提示，不自动拉伸、裁剪或额外重试。
- 新增只读 MCP 命令 `models.imageCapabilities`，查询模型的尺寸、比例和质量规则；配方创建／更新支持 `quality`。命令总数为 150，不返回供应商 Key。

规则是请求约束，不能保证第三方服务遵守全部参数；4K 档、未知模型和自定义兼容接口仍需按服务商能力验证。画幅说明用于改善构图，不等于精确像素保证。

## 图像工具布局

- 工具改到顶部，按「智能工具、基础处理、图像合成」分类；默认优先进入 AI 局部修改，可跨分类搜索，智能工具优先显示。
- 左侧集中素材缩略图、名称、尺寸、搜索、本地上传和处理记录，移除重复的顶部素材选择下拉。
- 中间保留原图／结果同步对比，右侧保留参数与处理按钮；切换素材回到原图，点击处理记录恢复对应来源、参数和结果。
- 从画布打开指定工具时保留原工具与来源；本地上传不会自行调用云端模型，打开工具也不会自动下载组件。

## 中文输入法

- 修复输入一个中文标点出现两个、组合输入被旧值打断的问题。
- 组合输入保留本地草稿，上屏或失焦提交一次；保留有意重复的标点、光标位置、选区替换和逐次撤销。
- 画布文字、提示词与配方共用修复，不修改已有文本。

## 验证与限制

改动阶段通过工具导航／上传／对比／蒙版流程 193 项隔离桌面检查、输入法专项 29 项、生成界面与 MCP 37 项、画布查看器 24 项及拉线 18 项原生事件检查。测试使用独立工程、本地素材和模拟供应商，不触发用户模型费用。专项证据与边界保留在对应工程文档中。

Windows 包与更新文件 31 项核对、Mac 两架构各 102 项包内检查，以及公开后的 23 项匿名更新／下载检查通过，渲染错误为零。原生 Mac 工作流见 [GitHub Actions](https://github.com/Even1997/tugou/actions/runs/41010398678)，详细结果见[本版发布验收](../engineering/release-v0.8.6.md)。公开下载验证使用 Range 请求，完整 DMG 下载与挂载在 CI 本地 HTTP 流中验证；没有覆盖安装用户当前实例。

- Windows 尚未代码签名；Mac 为 ad-hoc 签名，未进行 Developer ID 签名和 Apple 公证，首次安装可能遇到系统提示。
- Mac 下载后手动替换，不提供无感覆盖安装；Windows 更新也应先保存工程。
- 原生自动化不等于所有实体 Mac 触控板、原生输入法、Retina 与系统权限场景；大量不同大图和长期大工程仍需实机验证。
- 未新增外部供应商收费效果测试；生图尺寸遵循、云端修改衔接、抠图精度和字体 OCR 复核的既有边界继续保留。

自有代码继续采用 Apache-2.0，第三方字体、模型和运行时遵循各自原始许可。
