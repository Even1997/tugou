# 土狗 v0.8.16

本版增加画布多图对比和提示词悬浮预览，方便比较方案、检查细节和查看组合提示词。

## 多图对比

- 在画布选中至少两张图片，点击顶部「多图对比」。支持素材与已有生成结果，混选文字节点时只比较图片。
- 默认近全屏「两列细看」，每行充分展开，其余图片向下滚动查看；可切换「全部总览」快速比较所有方案。
- 「联动调整」同时缩放、平移或复位全部图片；「单独调整」点击某张图片后只调整该图，选中项高亮并显示倍率。
- Ctrl＋滚轮向上统一放大、向下统一缩小，即使处于单独调整模式也作用于全部图片；普通滚轮继续上下浏览。
- 支持 0.25–4 倍缩放、拖动或方向键平移和「适应窗口」。倍率以适应窗口为基准；切换布局与模式保留视角，Esc 关闭。
- 原图保持比例，支持浅深主题、窗口尺寸变化和加载失败提示；仅用于查看，不改工程或提交生成任务。

## 提示词预览与说明

- 提示词模块、画布模块 / 配方列表、配方选择及组合模块支持悬浮查看内容，也可键盘聚焦查看。
- 模块显示完整文字，配方显示编译后的组合提示词和输出要求；长内容可滚动，点击与拖拽保留原有行为。
- 中文默认 README 与英文 README 同步更新功能、操作方式、安装与更新入口，保留居中 Logo 和语言切换链接。

安装前保存工程，升级后重连 MCP。开启自动检查后，启动和每 30 分钟检查新版；跳过旧版本不影响本版提醒。Windows 尚无商业代码签名；Mac 使用 ad-hoc 签名，未经 Apple 公证，下载 DMG 后手动替换。图片原始清晰度、字体效果和导出格式边界仍以各模块说明为准。
