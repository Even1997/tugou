# 土狗 v0.8.25

- 在同一画板选中多张图片后，拖动共同边框的任一角即可等比缩放。对角固定，图片和间距按相同比例变化。松手后可一次撤销。
- 图片图层右键可进入液化，支持推移、膨胀和收缩。有选区时只修改选区内的像素。多帧 GIF 可先导出所需的静态帧，再导入为 PNG 图层进行液化。
- MCP 支持通过 `layer.scaleSelection` 整体缩放选中图层，以及通过 `paint.retouch` 调用三种液化模式。
- 补齐图层、画板、无限画布、页签、PPT、素材和管理列表的右键操作。菜单按对象类型和锁定状态提供删除、复制、重命名、调整叠放顺序等操作。

## 安装与升级

Windows 使用 x64 安装器。macOS 的 Apple Silicon 机型使用 arm64，Intel 机型使用 x64。 [安装包与校验文件](https://github.com/Even1997/tugou/releases/tag/v0.8.25)
