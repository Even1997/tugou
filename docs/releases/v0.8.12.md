# 土狗 v0.8.12

本版补齐 MCP 创作接入，新增画布工具流程，并优化首页、任务界面和更新提醒。

## MCP 创作

- 共 179 条命令、26 个领域、7 个顶层工具，复用桌面编辑与撤销记录。
- 支持 GIF 制作与选帧导出、结果选择、节点复制、配方绑定、精细图层、选区、蒙版和五种修图工具。
- 支持导演台多角度截图、1–60 秒录制、素材搜索及历史工程导入。
- 耗时任务可查询、取消和读取结果；重复请求去重，过期编辑拒绝覆盖。连接方式保持不变，升级后重新连接客户端即可。

## 创作与界面

- 画布新增可连线的超分、抠图节点，结果在右侧形成独立图片，可继续连接多个工具。
- 新增首页统计、工程搜索和分页、MCP 连接引导；任务列表支持状态筛选与长说明折叠。
- 统一圆润图标、控件尺寸与柔和界面；默认窗口 1280 × 800，小屏自适应。
- 主导航“合成”更名为“图层”，工具分类更名为“素材处理”。
- 生图任务完成主动刷新结果，回到前台立即同步，并记录分段耗时便于排查延迟。

## 更新提醒

开启自动检查后，启动时及运行中每 30 分钟检查新版，失败后 5 分钟重试。发现新版弹窗并保留底部入口；“稍后提醒”只暂缓当前会话，“跳过此版本”停止该版本提醒，更高版本仍会提示。安装需用户确认，保护未保存工程和运行中任务。

Windows 未配置商业代码签名；Mac 使用 ad-hoc 签名，未经 Apple 公证，下载 DMG 后手动替换。真实第三方 MCP 客户端长流程及低配置大工程仍需持续验证。安装更新前请保存工程。
