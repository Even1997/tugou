# 土狗 v0.8.2

本版将独立桌面创作工作台统一为「土狗」，完善图片生成、合成、字体工作台、模型连接、MCP 与设置更新。产品聚焦图片，不再扩展视频/音频生成。

## 下载与升级

- Windows x64：`tugou-0.8.2-win-x64.exe`。首次安装或旧版没有更新入口时，请手动下载运行。
- `latest.yml` 与 `.exe.blockmap` 用于应用内发现和下载更新，`SHA256SUMS.txt` 供手动核对。
- 仓库及本版附件已公开，匿名更新客户端已验证可发现 v0.8.2 并访问下载入口；应用不包含 GitHub 发布令牌。
- 保存并关闭土狗再安装；安装器不会强制结束其他窗口，不删除用户数据。
- 「设置 → 更新与关于」支持检查、下载和确认安装；默认自动检查、手动下载，可开启自动下载。未保存工程或运行任务会阻止安装。
- Windows 包尚未代码签名，系统可能提示未知发布者。完整内置字库使安装包体积较大。
- 本次不提供正式 Mac 包：Mac 13+、Apple Silicon / Intel 源码适配与 DMG/ZIP 配置已具备，签名、公证和真机升级待验收。

## 图片生成与无限画布

- 生成台在右侧输出独立结果节点并自动连线，启动即显示结果占位、阶段和耗时；供应商提供百分比时展示真实进度。
- 支持定位结果、取消和显式重试，保留上游提示词、参考图和参数来源。
- 输出提供 1:1、2:3、3:2、3:4、4:3、4:5、5:4、9:16、16:9；分辨率按比例过滤，另有自动及自定义宽高。
- 尺寸面板向下展开，空间不足时内部滚动；自定义使用宽度、高度两个数字框。
- 节点放大后提示词输入区伸展，模型、尺寸和生成按钮向下排列；缩小时仍可滚动操作。
- 精简新增菜单中的 3D 导演台、引用模块、引用配方和素材库选择入口，已有节点与其他工作区内容保留。
- 移除视频/音频生成节点、模型用途和新建入口，已有媒体仍可读取/保存；保留图片生成、视觉分析和文本辅助。

## 图层、画板与蒙版

- 多画板独立尺寸/背景、复制删除、跨画板移动、图层分组和单画板 PNG 导出。
- 画板预设扩为 41 项：常用 4、社交 7、网页 7、手机/平板 7、印刷 10、照片 6；按名称或像素尺寸搜索。
- 预设列表独立滚动，保留自定义、应用/取消、撤销及内容缩放。印刷/照片按 300 PPI 换算像素，不含出血或完整印前管理。
- 修复拖动分组内容后选框错位及文字边缘裁切，统一下拉和图层图标尺寸。
- 图片/蒙版编辑目标独立于选区，切换保留选区和工具；支持黑白填充、画笔、反选及蒙版载入选区。
- 删除按选区、蒙版或整层目标执行，统一取消选区、复制等快捷键，明确蒙版停用状态。
- 蒙版提供合成、黑白单独查看和红色叠加预览，预览不改变保存/导出内容。
- 图片缓存加入容量预算，PNG 后台编码支持连续笔画；画笔常用与次要参数分层展示。

## 字体项目与内置字库

- 独立字体工作区，每个字体管理自己的字符库、素材、映射、修订和输出。
- 导入图集后自动识别、裁切匹配，支持自由顺序映射和快速人工复核，不要求固定批次或字符数。
- 支持逐字重心、等比大小、分类基线和字重校正，以及边缘磨平、加粗；保留原图和处理记录。
- 修正后可直接保存，字符库显示已有字形样式；导出 TTF、WOFF2 或源包。
- 发布后可在文字字体下拉中选择，支持搜索、优先显示自定义字体及选择真实可用字重。
- 内置霞鹜文楷等 55 个家族、141 个字重文件，附原始许可、来源与修改声明；不同字体的中文覆盖范围不同。
- 字形处理需额外配置本机 Python/Potrace 环境；四个设计字不能自动推导成完整中文字库，OCR 和特殊字形仍需人工复核。

## 供应商与模型

- 一个供应商一个 URL，同页管理多个命名 Key；每个 Key 独立测试连接、获取模型及配置用途。
- 模型可搜索或手动填写，设置外层直接选择图片、视觉、文本的默认供应商/Key/模型。
- 删除或修改凭证后清理受影响的默认用途，不静默切换到其他 Key。
- 移除旧版连接导入和逐模型付费测试入口。

## MCP 与 AI Agent

- 接入实时桌面工程，覆盖画布/连线、图层/画板、选区/蒙版、绘画、图片工具、任务、模型管理和字体项目。
- 提供命令发现、对象查询、预览、事务批处理、实时版本冲突保护、共享撤销和幂等请求。
- 改善启动、断线重连、进度通知、取消等待及连接诊断；更新前释放客户端对旧程序的占用。
- 设置中查看本地 stdio 信息，复制通用 JSON、VS Code JSON 或 Codex TOML，不限定单一客户端。
- 不提供远程 HTTP MCP 地址；供应商 Key 不写入工程或客户端配置，付费生成需明确请求。

## 设置、平台与开发体验

- 七个分区：通用、外观与画布、文件与存储、模型连接、MCP、快捷键、更新与关于。
- 设置提供简体中文、繁体中文、English、日本語、한국어和跟随系统语言；部分专业编辑器文案尚待翻译。
- 深浅主题、缩放、网格、恢复工程、通知、目录查看及缓存清理。
- 18 项可编辑快捷键，支持冲突检测/恢复默认；Win/Mac 分别保存，Mac 使用 Command 等原生按键标识。
- Mac 窗口、菜单、字体枚举与运行环境的源码适配已补充，真机验证仍单独列为待办。
- 开发预览的安全热更新保留未保存工程和撤销；主进程/preload/依赖变化提示保存后重启。
- 更新品牌图标，统一侧栏、空状态、配方和画布菜单布局。

## 验证与边界

- 发布前 Node 回归：348 项通过，1 项 POSIX 链接检查因 Windows 环境跳过。首次默认高并发运行出现一次文本任务失败，单项及限制并发后的全量回归通过，未放宽断言。
- 本轮画板预设：13 项逻辑、22 项真实 Electron 检查，41 个尺寸逐项核对，覆盖取消/撤销/新建/保存与浅深主题小窗口。
- 生成尺寸、节点布局等已完成独立 Electron 验收，运行时 npm 依赖审计无已知漏洞。打包及更新资源验收另见同版本发布记录。
- 正式包内设置页 32 项通过；隔离 NSIS 实际升级 11 项通过，含下载 SHA512、未保存拦截、工程/资源/设置保留及 MCP 重连。安装器拒绝覆盖仍运行的测试程序，该进程存活。
- 原有 ResizeObserver 偶发通知仍待排查；Mac 真机、长时间大工程压力、专业编辑器完整翻译及所有真实供应商组合并未全部验收。
- 预设尺寸不保证供应商接受；取消云任务不保证停止计费，重试由用户明确发起。
- 自有代码为 Apache-2.0，第三方字体、模型、运行时及历史内容保持原许可；历史源码权属逐项复核仍待完成。
