# 图构 Studio（Windows 本地版）

用于把参考图拆成可替换的提示词模块，生成独立素材，再由使用者自由拼合。基于 infinite-canvas，图层交互参考 Compositor；将无限画布集成到同一个桌面窗口。

主体抠图提供“精细识别”和“轻量识别”。精细组件安装后，新任务优先精细识别；旧任务保持原模式，模式随任务保存。运行桌面包中的 `setup-image-tools.ps1 -IncludeDetailCutout` 可安装固定版本的 BiRefNet 通用 FP16 模型（约490MB，SHA256校验，DirectML）；无需API密钥。RTX3060本机测试约占9.9GiB专用显存，资源紧张时选轻量识别。结果保留原图尺寸/RGB和已有透明区域；精细识别不等于所有发丝或薄纱都能无损还原。

## 启动

双击工作区的 `图构 Studio.lnk`，或 `release/editor-review/CanvasStudio-win32-x64/CanvasStudio.exe`。该目录需要整体保留，不能只移动 exe。首次启动内置蓝白花园 C 版示例。

桌面使用无边框窗口：拖动顶部空白区域移动窗口，右上角提供最小化、最大化/还原和关闭。未保存或生成中关闭时保留确认。

桌面程序启动自带的 Next.js 和 Go 服务，仅监听本机。前端固定使用 127.0.0.1:3418，后端使用空闲本机端口。原画布的 IndexedDB 随固定地址保留。平台本地运行，生图直接调用用户配置的模型 API，不连接线上 infinite-canvas 或 MCP。

## 工作流程

1. 导入参考图片，点击“分析参考图”，先审阅模型返回的模块与配方，再导入。未配置视觉模型时可以手动创建。
2. 在“提示词工作台”独立编辑公共画风、人物身份、动作、服饰、场景、宠物、道具等模块。类别可自定义。公共画风自动参与所有配方，输出与构图单独编辑。
   无限画布的“提示词库”直接显示同一工程的模块，可搜索、点击或拖入为独立文本节点；把公共画风及内容模块连到目标图片节点后生成。插入节点和发送配方会记录模块来源；工作台修改后节点标记“有新版”，点击“模块更新”可一键更新当前画布无冲突的旧版，保留位置和连线，支持撤销。画布内也改过的节点单独对比、手动确认覆盖。旧节点先点“关联模块”指定来源；来源删除或清空时不会覆盖节点。节点内提示词库的直接追加仍为普通文本，需要跟随模块更新时请插入独立文本节点并连线。
3. 给配方选择模块和参考图，写清每张图的职责。可以直接调用兼容图片 API，或送入“无限画布”页签继续生成。生成按钮会产生服务方费用；编辑提示词不自动生成。
4. 素材库保留每次结果及生成信息。无限画布侧栏和选图弹窗共用当前工程的素材库：任一入口导入后立即互通，点击素材可插入画布，节点“存入素材库”将图片加入同一库；重复保存相同图片不新增副本。从无限画布回收的不同结果也保留版本。改变画风后已有素材会显示过期提示，不会自动替换图层。
5. 在“图层合成”移动、缩放、旋转、翻转、排序、隐藏、锁定、分组；编辑文字、透明度、混合模式和矩形裁切蒙版。可拖素材入画布或替换所选图层素材。
6. 自动保存到本机；可导入/导出 `.studio` 工程、单独导出素材、导出 PNG / JPEG。导出文件写入工程目录下的 `exports`，界面显示完整路径。

## 连接设置与数据

- 桌面数据位于 `%APPDATA%/CanvasStudio/projects`；`STUDIO_DATA_DIR` 可指定其他目录。
- 新工作台连接凭据由 Electron safeStorage 加密，位于 `%APPDATA%/CanvasStudio/credentials.enc`；不会写入 `.studio` 工程，也不会由配置读取接口返回密钥。
- 提示词工作台与内嵌无限画布共用一份 API 地址、密钥、生成模型和视觉分析模型。画布只持有无敏感信息的连接标记，实际请求由本机服务附加密钥。
- 兼容 API：模型列表 `/models`，文生图 `/images/generations`，参考图编辑 `/images/edits`（multipart `image[]`），视觉分析 `/chat/completions`。不同提供商的参数支持仍需实际验证。
- 在“连接设置”填写 API 地址（通常以 `/v1` 结尾）、API 密钥、生成模型；需要自动分析参考图时再填写视觉分析模型。点击“保存并读取模型”可检查连接。模型列表可用不保证该模型支持图片生成。
- 请求路径：桌面页面 → 本机 API 服务 → 配置的模型 API；生成结果直接返回本机素材库，工程自动保存。选择“发送到画布”直接切换到当前窗口的画布页签。切换页签保留画布任务，画布中的“共用连接”打开同一个设置窗口。
- 两个工作区的共用连接支持直接返回图片的 Images API（Base64 或 HTTPS 图片 URL）；仅返回任务 ID 的异步供应商协议尚未适配，不会回退到 MCP 或线上画布。未配置有效 API 前，模拟测试不等同于真实生图成功。
- 工程含嵌入式图片，便于备份；较大的素材集会增加保存时间与内存使用。本版尚未做大型工程压力测试。

## 当前边界

图层合成已接入图层组、排版、透视、矢量/像素蒙版、选区、画笔与本地修图；尚无 PSD/CMYK、高位深和专业印前。分析和生成结果需人工审阅，人物相似度与风格一致性不能由程序保证。

顶部“调整”可添加 12 类非破坏调整图层：色相/饱和度、色阶、曲线、曝光、渐变映射、黑白、色彩平衡、反相、颗粒、杂色、高斯模糊、动感模糊。参数在第二行，扩展项在“更多参数”。调整作用于同组下方内容，“仅下层”可剪贴；当前选区自动转为调整蒙版。曲线支持 RGB 与独立通道、加点/拖点和方向键微调。

选中图片、文字、形状或组后，顶部“特效”可叠加描边、投影、颜色叠加、内阴影、内发光和外发光；再选同一项即可重调、停用或移除。原素材保持不变，参数随工程保存并支持撤销。尺寸以文档像素计，导出保留原分辨率；超大模糊半径与多重特效可能触发临时内存预算，明确报错而不缩图。色阶目前为整体 RGB，渐变映射为双色；工作空间仍是 8 位 sRGB，Camera Raw 参数、RAW 解码及其他高级滤镜尚未接入。

画笔顶部可调“平滑”（屏幕像素，0 关闭），开启“直线”后拖动预览、松手落笔，也可 Shift 点击连接上一笔。平滑和直线适用于画笔、橡皮和蒙版绘画，不改变涂抹/液化等修图笔刷。

在图片图层创建选区后，从顶部“修图 → 内容感知填充”或“选区操作 → 内容感知填充”执行。当前图层周围的原始不透明像素作为来源，保留选区外像素，支持羽化、取消和一次撤销。计算在本地后台线程进行，不调用模型 API。单次选区与周边取样合计最多 400 万像素，超过时需要分区处理；原图仍支持总量 1 亿像素、单边 30000。它适合纹理修补，无法凭空重建缺失的语义对象；复杂纹理可能需要手动修整。

## 开发与验证

```powershell
# web 目录
npm ci
npx tsc --noEmit
node --test tests/studio-model.test.mjs
npx next build --webpack

# 项目根目录：限制并发可避免本机分页文件不足
$env:GOMAXPROCS='2'
go test -p 1 ./...
go build -o desktop/bin/canvas-server.exe .

# desktop 目录
npm ci
node package.cjs
```

`web/tests/studio-api.test.mjs` 使用本地模拟模型端点，验证真实 HTTP 路由、参考图表单、分析 JSON、密钥不回传、跨站请求拦截与工程保存。仅对隔离测试实例运行：会暂时覆盖该实例的连接配置。设置 `STUDIO_TEST_URL` 指向测试服务。

开源许可与来源见 `THIRD-PARTY-NOTICES.md`。用户提供的婚礼素材仅用于本地示例，不能当作开源授权资产公开分发。
