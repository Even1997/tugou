# 土狗 · Tugou

面向图片创作的本地桌面工作台。把提示词、参考图、AI 生图、无限画布、图层合成和字体设计放在同一个工程里，也让外部 AI Agent 通过 MCP 操作这些工具。

**当前版本：v0.8.6** · [下载安装](https://github.com/Even1997/tugou/releases) · [版本说明](docs/releases/v0.8.6.md) · [开发文档](app/README.md)

## 功能

| 工作区 | 主要用途 |
|---|---|
| 提示词 | 管理模块与配方、参考图分析、组织可复用的创作要求 |
| 画布 | 编排文字、图片和生成台，连接参考内容；生成结果在右侧形成独立节点并自动连线 |
| 合成 | 多画板、文字/形状/图片图层、分组、选区、黑白蒙版、绘画、变换与 PNG 导出 |
| 工具与素材 | 导入、预览、搜索、处理图片，管理生成及处理结果 |
| 字体 | 每个字体一个项目；导入图集、识别映射、快速复核、校正轮廓、导出并发布字体 |
| 设置 | 主题、语言、存储、模型连接、MCP、可编辑快捷键及更新 |

- 专注图片创作，保留视觉分析和文本辅助；不再提供视频/音频生成入口，旧工程已有媒体仍保留。
- 图片生成支持 9 种固定比例与对应分辨率、自定义宽高；节点放大时提示词输入区随之伸展。
- 画板提供 41 个预设，分为常用、社交、网页、手机/平板、印刷、照片，支持搜索和自定义。
- 工具页支持本地上传，结果默认并排对比，也可滑动对比；两图同步缩放与定位。本地 AI 组件需手动点击下载，校验后可离线使用，首次获取需要联网。
- 字体下拉支持搜索本机字体、内置字体和已发布自定义字体，以及可用字重。提供 55 个家族、141 个字重的下载目录，许可与覆盖范围见[字体目录](app/assets/fonts/CATALOG.md)。

## 下载安装

在 [Releases](https://github.com/Even1997/tugou/releases/tag/v0.8.6) 按系统下载，保存并关闭正在运行的土狗，再安装。首次使用无需克隆源码或启动 Web 服务。

| 平台 | 当前发行范围 |
|---|---|
| Windows x64 | `tugou-0.8.5-win-x64.exe`；支持应用内检查、下载和安装更新 |
| macOS 13+ · Apple Silicon（M 系列） | `tugou-0.8.5-mac-arm64.dmg`，另提供同架构 ZIP |
| macOS 13+ · Intel | `tugou-0.8.5-mac-x64.dmg`，另提供同架构 ZIP |
| Linux | 当前没有正式支持或安装包 |

当前 Windows 包未代码签名，系统可能提示未知发布者，请核对下载仓库及 Release 附带的 SHA256 校验文件。字体文件按需下载，安装包保留完整目录和授权；下载后可离线使用。

Mac：打开对应芯片的 DMG，将 `Tugou.app`（土狗）拖入 Applications 后运行。Mac 包目前只有临时签名（ad-hoc），没有 Apple Developer ID 签名和公证，系统可能阻止首次打开。确认下载来源和校验值后，可按 macOS「系统设置 → 隐私与安全性」显示的选项允许打开；不需要关闭全局安全保护。若系统没有提供允许选项或设备受组织管理，请勿绕过策略。

Mac 支持自动检查和 DMG 下载，最后由用户保存退出后手动替换，保留原用户数据目录。Mac CI 原生运行检查不等于所有实体 Mac、输入法和系统权限场景均已验收。

Mac 下载支持进度、断点续传及完整性校验，完成后点击“打开安装包”。v0.8.2 及更早版本没有此通道，首次升级到 v0.8.3 或更新版本仍需手动安装。

## 第一次生成图片

1. 新建工程，打开「设置 → 模型连接 → 管理供应商与模型」。
2. 添加供应商并填写 API URL。一个供应商共用一个 URL，可添加多个命名 Key；不同 URL 请创建不同供应商。
3. 每个 Key 单独测试连接、获取模型并指定模型用途；也可手动填写模型 ID。
4. 在设置外层分别选择图片生成、视觉分析、文本辅助的默认「供应商 / Key / 模型」。模型服务由你自己的供应商提供，土狗不附送额度。
5. 在画布添加文字提示词、参考图片和生成台，连接输入后生成。结果在右侧出现并连线，任务面板可查看进度、取消或手动重试。
6. 在合成工作区继续排版、编辑文字和蒙版，保存工程或导出 PNG。

供应商支持的尺寸、模型和协议各不相同。软件预设不保证每家接口都接受；取消本地任务也不保证供应商停止计费。

## 字体工作台

创建字体项目 → 选择参考字符并获取图集提示词 → 导入字形图片 → 自动识别与自由映射 → 人工复核 → 校正、磨平/加粗 → 导出 TTF、WOFF2 或源包。

- 图片中的字不必严格按字符库顺序排列；识别不确定的结果应人工复核。
- 发布自定义字体后，可在文字字体下拉中选择。
- 四个设计字不会自动变成完整中文字库；只有已导入、映射并保留的字形会成为字体内容，缺字可能回退到其他字体。
- 识别与字体编译需要额外的本地 Python/Potrace 环境，安装包不自带整套环境，见[配置方法](app/README.md#字体环境)。普通排版和内置字体不需要该环境。
- 印刷画板预设只按 300 PPI 换算像素，不包含出血、CMYK 或完整印前管理。

## MCP：让 AI 使用土狗

1. 启动土狗，在「设置 → MCP 与 AI 调用」启用服务。
2. 查看连接信息，复制通用 JSON、VS Code JSON 或 Codex TOML 到对应客户端。
3. 保持土狗运行并打开工程。Agent 先调用 `get_state`，再用 `list_commands` 发现具体命令。

MCP 覆盖工程、画布与连线、图层/画板、选区/蒙版、图片工具、模型与任务、字体项目等领域，支持实时版本检查、事务批处理、撤销、请求去重和预览；不代表所有界面功能均可自动操作。

连接方式是**本机 stdio**，不是远程 HTTP URL；支持标准 stdio 的客户端均可按其规范接入，不限 Codex。连接配置按本机路径生成，请勿照搬别人电脑的路径。付费生成需要明确请求；供应商 Key 不会包含在复制出的 MCP 配置中。

## 自动更新

Windows 和 Mac 安装版均通过 `Even1997/tugou` 的公开 GitHub Releases 检查稳定版。Windows 使用更新清单自动安装；Mac 下载对应架构 DMG 后手动替换，不依赖 `latest-mac.yml`：

此功能要求仓库及稳定版附件可公开访问。仓库仍为私有时，授权成员可以在 GitHub 手动下载，但普通客户端无法自动检查/下载；应用不会内置 GitHub 发布令牌。

- 默认自动检查：启动后检查，以约 24 小时为间隔节流；也可在「设置 → 更新与关于」手动检查。
- 默认不自动下载，可在设置中开启。下载显示进度，完成后由你确认安装。
- Windows：未保存工程或运行任务会阻止安装；安装前等待数据落盘，释放 MCP 连接后升级并重启。
- Mac：下载完成后打开 DMG，保存并退出土狗，再拖入 Applications 替换；不会自动退出或安装。
- 源码开发版和未安装的解压运行目录不走安装更新，请更新源码或使用安装包。
- 没有更新入口的旧版本需要先手动安装此版；GitHub 不可达时可从 Releases 手动下载。

## 数据与备份

工程、资源、字体项目和任务保存在本机。安装版默认工作区：

- Windows：`%APPDATA%\TugouIndependent\workspace`
- macOS：`~/Library/Application Support/TugouIndependent/workspace`

可在「设置 → 文件与存储」打开实际目录；开发预览使用独立数据目录，以界面显示为准。备份时先保存并退出，再复制整个用户数据目录，不要只复制工程 JSON。

模型 Key 由桌面主进程通过系统加密接口保存，不应提交到 Git。调用模型时，提示词和参考图会发给你配置的供应商；下载本地 AI 组件也会联网。土狗不是完全离线的云模型替代品。

## 从源码运行

需要 Node.js 22 LTS 或更新的兼容版本及 npm。仓库含内置字库，首次克隆和安装可能较慢。

```sh
git clone https://github.com/Even1997/tugou.git
cd tugou/app
npm ci
npm run dev
```

开发预览支持安全界面热更新，保留工程、撤销和未保存内容；输入、绘画、弹窗或任务繁忙时延后应用。主进程、preload 或运行依赖变化仍需保存后重启。

```sh
npm start          # 构建并运行普通源码版
npm test           # Node 回归
npm run dist:win   # Windows x64 安装包，在 Windows 构建
npm run dist:mac   # Mac DMG/ZIP，须在 Mac 构建；正式自动升级另需签名、公证与验收
```

前端产物默认在 `app/dist`，安装包在 `app/release`。不要提交用户数据、API Key、测试产物或本地运行环境。[开发和发布细节](app/README.md) · [已知待办](docs/progress/todo.md)
